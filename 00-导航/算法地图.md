# 算法地图

> 机器人算法五大族：建图 → 定位 → 规划 → 控制 → 学习，外加感知与调度。

## 算法流水线全景

```
传感器数据 ──→ [[SLAM总览]] ──→ 地图
                │                 │
                ↓                 ↓
        [[激光SLAM]]/[[视觉SLAM]]   [[多传感器融合定位]](+[[卡尔曼滤波]])
                │                 │
                └────────┬────────┘
                         ↓
   [[路径规划算法]](全局) ──→ [[局部规划与避障]] ──→ [[轨迹优化与运动控制]]
                         │
     [[视觉感知算法]](识别/检测)   [[多机协同与调度算法]](多机器人)
                         │
     [[学习型机器人算法]](RL/VLA/大模型,新兴主线)
```

## 算法族笔记

| 算法族 | 笔记 | 代表算法 |
|---|---|---|
| 建图 | [[SLAM总览]] · [[激光SLAM]] · [[视觉SLAM]] | Gmapping、Cartographer、FAST-LIO2、ORB-SLAM3、VINS-Fusion |
| 定位 | [[多传感器融合定位]] · [[卡尔曼滤波]] | EKF/ESKF、AMCL、NDT、ICP、图优化 |
| 规划 | [[路径规划算法]] | A*、D* Lite、RRT*、Hybrid A*、Theta* |
| 避障与局部 | [[局部规划与避障]] | DWA、TEB、MPC、VFH |
| 控制 | [[轨迹优化与运动控制]] | PID、纯跟踪、LQR、MPC |
| 感知 | [[视觉感知算法]] | YOLO 系列、语义分割、点云聚类、障碍物融合 |
| 学习 | [[学习型机器人算法]] | 深度强化学习、模仿学习、VLA（π0、GR00T）、Sim2Real |
| 调度 | [[多机协同与调度算法]] | 匈牙利算法、拍卖算法、CBS/MAPF、交通规则 |

## 关键指标对应

每族算法的验收指标见 [[性能指标体系]]：建图回环精度、定位误差(±cm 级)、规划成功率、控制跟踪误差等。
