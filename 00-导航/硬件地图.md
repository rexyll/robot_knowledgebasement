# 硬件地图

> 机器人硬件全景树：感知 → 计算 → 驱动 → 能源 → 安全。

## 感知层（机器人如何"看世界"）

| 器件 | 解决什么 | 关键参数 |
|---|---|---|
| [[激光雷达]] | 2D/3D 空间轮廓、SLAM 主传感器 | 点频、精度、探测距离、线数、波长 |
| [[深度相机]] | 视觉避障、物体识别、VSLAM | 深度精度、视场角、帧率、工作距离 |
| [[IMU]] | 高频姿态/加速度，融合定位的粘合剂 | 零偏稳定性、量程、带宽 |
| [[毫米波雷达与超声波]] | 近距离防碰撞、恶劣天气冗余 | 探测距离、波束角 |
| [[编码器与里程计]] | 轮式里程计（航位推算基础） | 分辨率(PPR)、精度 |
| [[安全防护器件]] | 触边、急停、防撞条、安全扫描 | PL 等级、响应时间 |
