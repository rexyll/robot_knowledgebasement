## v12｜Relative-degree-two exponential CBF 公式复核（2026-11-14）

### 已完成

- [x] 固定上游审查基线：`rexyll/MotionControlAlgorithms` main `c11091bd2bb3ce001eb09f2664c1ff5076f8a73b`。
- [x] 读取 `include/mca/control/relative_degree_two_cbf_filter.hpp`，确认当前漂移项为 \(L_f^2h+\alpha_1\dot h+\alpha_1\alpha_2h\)。
- [x] 读取 `include/mca/control/multi_input_cbf_filter.hpp`，确认其将输入漂移项与 \(L_gL_fh\,u\) 转为仿射半空间并投影名义控制。
- [x] 读取 `tests/control/multi_input_cbf_filter_test.cpp`，确认现有核心级联条件测试使用 \(\dot h=0\)，非零导数安全测试未落在公式差异边界。
- [x] 按 \(\psi_1=\dot h+\alpha_1h\)、\(\psi_2=\dot\psi_1+\alpha_2\psi_1\) 推导标准条件为 \(L_f^2h+L_gL_fh\,u+(\alpha_1+\alpha_2)\dot h+\alpha_1\alpha_2h\geq0\)。
- [x] 构造解析反例：\(\alpha_1=2,\alpha_2=3,h=0.1,\dot h=-0.2,L_f^2h=0,L_gL_fh=1\)。当前公式漂移项为 +0.2，标准公式为 -0.4；当前实现允许 \(u=0\)，标准条件要求 \(u\geq0.4\)。
- [x] 将复核结论、推导、反例、边界和修复验收建议追加至 `knowledge/algorithms/轨迹优化与运动控制.md` §23。
- [x] 更新 EXT-001 登记、第14章执行记录、根 TaskPlan 至 v11.91。

### 结论

**P0 数学实现缺项已确认**：若该 API 意图实现标准二阶 exponential CBF 级联条件，漂移项需要使用 \((\alpha_1+\alpha_2)\dot h\)，当前实现少了 \(\alpha_2\dot h\)。若意图采用其他定义，需给出独立推导并明确 API 契约。初始安全集合、相对阶、模型误差及离散实现假设仍需单独说明。
