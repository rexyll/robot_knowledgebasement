# 标准与法规

> 机器人行业的"交通规则"。选标准 → 写安全需求 → 验证 → 认证，是产品化的最后一公里（执行方法论见 [[功能安全体系]]）。

## 移动机器人（AMR/AGV）核心标准

| 标准 | 范围 | 核心要求 | 状态 |
|---|---|---|---|
| **ISO 3691-4:2023** | 无人工业车辆（含 AMR 叉车） | 人员检测防护装置、速度控制与制动、多操作模式；安全功能须达 **PL d**；完整安全架构+故障检测+验证方法 | 2023-10 发布替代 2020 版，AMR 安全球事实标准 |
| **ANSI/A3 R15.08** | 工业移动机器人（美国） | Part1（2020）单机：传感/安全功能/停止控制；Part2（2023）集成与车队管理；Part3（定稿 R15.08-3-2026）用户侧：风险评估、变更管理、培训、周期检查 | 北美市场准入，三部曲齐备 |
| **ISO 13482** | 个人护理/服务机器人 | 人机接触力限值、稳定性、急停；修订版已入 **FDIS**，更名"服务机器人安全要求"，扩展至专业/商用场景（含物理接触） | 修订版 2025-2026 发布 |
| ISO 12100 | 机械安全风险评估通用方法 | S×F×P 风险矩阵 | 所有安全工作起点 |
| GB/T 国标 | 国内对应体系 | GB 11291（工业机器人）、移动机器人国标在编 | 国内认证（CR/CQC） |

**ISO 3691-4 落地要点**（→ [[安全防护器件]] 的分区模型）：
- 安全功能 PL 等级要求（通常 PL d, Cat.3）
- 速度-保护距离联动（field sets）
- 声光警示（转向灯/蜂鸣）
- 与"人员密集区"的速度限制

## 工业与协作机器人标准

| 标准 | 要点 |
|---|---|
| **ISO 10218-1/-2:2025（新版）** | 2025-02 发布，2011 年以来最大修订：① 显式化功能安全要求；② 术语从"协作机器人"转向"**协作应用**"（安全取决于整机应用而非本体），整合原 ISO/TS 15066 协作内容；③ 新增**网络安全**要求（威胁考量与攻击可行性评级）；④ 强化风险评估与人机交互安全；⑤ 预期纳入欧盟 CE 新机械法规；美国对应采用为 ANSI/A3 R15.06-2025 |
| ISO/TS 15066 | 协作机器人：四大协作模式 + 人体部位接触力/压强限值表（功率与力限制模式的量化依据），内容并入 10218:2025 |
| ISO 9283 | 机器人性能指标测试方法（位姿精度/重复性/轨迹精度——验收实验标准） |
| SEMI F47/EMI | 半导体洁净室机器人附加要求 |

## 软件/数据/接口标准

| 标准 | 内容 | 机器人应用 |

## 医疗机器人监管（→ [[医疗机器人]]）

- 中国：NMPA 三类医疗器械（手术机器人注册 3-5 年）；YY/T 可用性工程
- 美国：FDA 510(k)/De Novo；欧盟：MDR
- 标准：IEC 60601（医用电气）、IEC 80601-2-77（手术机器人专用）

## 认证机构与流程

- 国际：TÜV（莱茵/南德）、BV、SGS、UL
- 国内：CQC、CR 认证、特种设备（叉车资质）
- 通用流程：风险评估 → 安全需求 → 设计验证（故障注入）→ 型式试验（制动/撞击力/EMC）→ 文档存档 → 量产例行检验
- 出口注意：CE（欧盟）/ UL（北美）/ KC（韩国）各自独立
