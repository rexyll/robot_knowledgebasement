# 产业链与市场

> 机器人产业的价值分布与玩家地图。数据快照：2024-2025 年公开数据（详细来源见 [[发展趋势]]）。

## 产业链全景

```
上游(核心零部件)          中游(本体制造)           下游(系统集成/应用)
├─ [[减速器]] 谐波/RV   →  ├─ 工业机器人           →  ├─ 集成商(汽车/3C/锂电产线)
├─ 伺服[[电机与驱动器]]  →  ├─ [[协作机器人]]        →  ├─ 行业方案(物流/清洁/巡检)
├─ 控制器                →  ├─ [[移动机器人]] AMR    →  ├─ [[调度系统RMS]]/WMS 软件
├─ [[激光雷达]]          →  ├─ [[人形机器人]]        →  ├─ 运营服务(租赁/运维)
├─ [[电池与电源]]        →  └─ 特种/服务             └─ 终端客户(工厂/仓库/商场/医院)
└─ [[计算平台]]/芯片
```

价值分布规律：核心零部件占工业机器人 BOM 60-70%（减速器 ~35% + 伺服 ~20% + 控制器 ~15%）；AMR 的 BOM 则以 LiDAR+算力+电池为主（~50-60%）；人形机器人关节模组占 ~50%。

## 竞争格局要点

1. **AMR 集中化**：CR5 >40%，头部打"融资-价格战-出海"，尾部淘汰 → [[主要厂商]]
2. **国产替代三条线**：减速器（绿的/双环）、LiDAR（禾赛/速腾，AMR 市占 >65%）、控制器（汇川/埃斯顿）
3. **激光雷达价格雪崩**：主雷达 ~200 美元级、补盲 ~100 美元级 → 驱动 AMR 渗透
4. **人形入局者**：车厂（Tesla/小米）、AI 公司（Figure/智元）、机器人老将（优必选/宇树）三路合流
5. **盈利模式分化**：卖硬件 → RaaS（机器人即服务，按月租）→ 数据/运营增值

## 中国区政策环境（2023-2026）

- 《"机器人+"应用行动实施方案》（2023）：2025 制造业机器人密度较 2020 翻番
- 人形机器人创新中心（北京/上海/杭州）：平台公司+开源数据集
- 各地机器人产业基金与首台套补贴；具身智能写入 2025 年多地政府工作报告
