# 流程架构地图

> 机器人系统级流程：部署期流程（建图）与运行期流程（导航/调度/OTA/安全）。

## 流程清单

| 流程 | 笔记 | 阶段 |
|---|---|---|
| 部署期 | [[建图流程]] | 场景勘测 → 手动/自主建图 → 回环优化 → 地图评审发布 |
| 运行期 | [[导航流程]] | 定位 → 目标下发 → 全局规划 → 局部避障 → 底盘控制 |
| 运行期 | [[多机调度流程]] | 任务池 → 任务分配 → 交通管制 → 执行反馈 |
| 运维期 | [[云端协同与OTA流程]] | 设备注册 → 数据上报 → 远程指令 → OTA 分包升级 |
| 全程 | [[功能安全体系]] | 风险评估 → 安全功能(急停/触边/区域限速) → 等级认证 |

## 系统总架构
