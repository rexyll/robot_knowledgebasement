# 学习型机器人算法（RL / IL / VLA / 具身智能）

> 2023-2026 机器人算法的主叙事：从"手写规则"转向"数据+学习"。三条已落地的线：**RL 运动控制**（足式/人形步态）、**模仿学习操作**（抓取/灵巧手）、**VLA 大模型**（任务级理解与泛化）。

## 1. 深度强化学习（运动控制已工程化）

- 范式：策略 π_θ(观测→动作) 在仿真中与奖励交互训练 → Sim2Real 部署
- **奖励设计**（足式步态模板）：前进速度跟踪 + 能耗惩罚 + 姿态正则 + 足底冲击惩罚 + 平滑项
- 训练：**Isaac Lab** 4096 环境并行，1 亿+ 交互步，数小时 GPU → [[仿真平台]]
- Sim2Real 三板斧：**域随机化**（质量/摩擦/延迟/PD 参数 ±20-30%）、**师生蒸馏**（特权信息→部署策略）、**在线自适应**（History encoder 估计地形/负载）
- 成果：宇树 Go2/H2 步态全 RL 化（倒地自起、抗推搡）、四足越障 >ZMP 传统法 → [[足式与无人机]]
- 局限：奖励 engineering 仍是手艺活；安全约束难显式保证（与 [[功能安全体系]] 冲突需外挂约束层）

## 2. 模仿学习（IL，操作任务主力）

| 方法 | 思路 | 特点 |
|---|---|---|
| **BC（行为克隆）** | 监督学习模仿演示轨迹 | 简单，分布漂移问题 |
| Diffusion Policy | 动作生成=去噪扩散 | 多峰动作分布表达好，当前操作学习 SOTA 之一 |
| ACT（Action Chunking Transformer） | 预测未来动作块+CVAE | ALOHA 双臂系统配套，遥操作数据采集（单台日采数百条） |
| VQ-BeT | 离散动作 token 化 | 与 LLM 范式对齐 |

数据采集三路线：遥操作（VR/主从臂）、动捕/视频学习（人体视频→重定向）、仿真合成（RL/脚本策略）

## 3. VLA 大模型（Vision-Language-Action，任务级大脑）

| 模型 | 机构 | 架构要点 | 开源 |
|---|---|---|---|
| RT-2 | DeepMind(2023) | 55B VLM 直接出动作 token | 否（开创者） |
| **OpenVLA** | 斯坦福等 | 7B，OpenX 数据 | ✓ |
| **π0 / π0.5** | Physical Intelligence | flow matching 动作生成；π0.5 异构数据开放世界泛化 | ✓（openpi，可跑 Jetson Thor） |
| **GR00T N1.x** | NVIDIA | 双系统（System2 VLM 推理 + System1 高频动作），N1.7 现行 | ✓（Isaac 生态配套） |
| **Helix** | Figure | System1(200Hz 上身控制)+System2(7-9Hz VLM)，双机协作 | 否 |

- **双系统架构成为共识**：慢系统做语义推理（秒级），快系统做连续控制（50-200Hz）——正好映射 [[AMR整体架构]] 的"大脑-小脑"分层
- 部署现实（2026 初）：VLA 推理仍需 Thor 级算力，任务成功率在高频重复任务 80-95%，长尾任务仍是演示品

## 4. LLM 在机器人系统的非 VLA 用法（当下已可用）

- 任务编排：自然语言→任务计划（调 [[调度系统RMS]] 的 API）
- 交互层：服务机器人对话（ASR→LLM→TTS）→ [[服务机器人]]
- 故障辅助：日志+错误码→诊断建议（RAG 知识库——本 Obsidian 库可作为 RAG 语料）
- 语义地图查询：3DGS/开放词汇地图 + LLM 导航（GaussNav 类）→ [[SLAM总览]]

## 5. 与传统算法栈的集成模式（务实主义）

```
传统栈为主 + 学习模块替换痛点:
  感知层: 检测/分割全 DL(已默认)
  预测层: 行人轨迹 DL 预测 → [[局部规划与避障]]
  控制层: RL 步态(足式) / 传统 MPC(轮式仍主流)
  任务层: LLM/VLA 做编排与长尾(新兴)
```

## 数据闭环（具身智能公司的核心资产）

真机遥操作采集 → 数据管理（版本/质量标注）→ 训练 → 仿真评测（Isaac Lab）→ 灰度真机 → 失败案例回流。存储 1 条 1 分钟轨迹 ≈ 100-500MB（多相机+关节流），10 万条 = 10-50TB → 数据基础设施成本被低估。

## 细节加深（V2）
- **开源三强**（台账 #76-#78，快照 2026-11-01）：Isaac Lab（BSD-3，训练基础设施）· LeRobot（Apache-2.0，HF 数据集+模型+真机工具，28.6k star）· openpi（Apache-2.0，π0/π0.5 权重可微调）。三者皆宽松许可——学习型算法生态的商用门槛反而比传统感知低。
- **NVIDIA Isaac ROS**（#79）：ROS2 + Jetson 的高性能感知包组织（立体深度/视觉 SLAM/AprilTag GPU 版）——传统栈与学习栈的现成桥梁。
- **LeRobot 是初学者进 RL/IL 的最低门槛入口**：`lerobot` pip 包 + 开源数据集 + 廉价主从臂（SO-10x）协议齐全。
