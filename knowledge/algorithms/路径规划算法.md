# 路径规划算法（全局规划）

> 已知地图+起终点 → 找一条可行/最优路径。分**图搜索**（栅格上最优）与**采样**（高维/运动学约束）两族，外加 AMR 特有的**全覆盖规划**（清洁机主用）。

## 图搜索族（栅格地图上）

| 算法 | 思想 | 复杂度 | 用途 |
|---|---|---|---|
| BFS/DFS | 无权图遍历 | O(V+E) | 教学 |
| **Dijkstra** | 代价一致扩散，保证最优 | O(E log V) | 权重不均匀地图 |
| **A\*** | Dijkstra + 启发 h(n)（欧氏/曼哈顿），h≤真值则最优 | 通常快 10-100× | 全局规划默认 |
| **D\* / D\* Lite** | 增量重规划，环境变化只修复受影响部分 | 动态环境 | 探测车、动态障碍多 |
| **Theta\*** | 任意角视线连线（line-of-sight） | 同 A* 量级 | 路径更短更直 |
| **JPS（Jump Point Search）** | 跳点剪枝均匀栅格 | 快 10-30× | 2D 大地图 |

启发函数要点：h 可采纳（不高估）保证最优；weighted-A*（h×ε，ε=1.3-2.5）牺牲少量最优换速度——工程默认。

## 采样族（运动学/高维）

| 算法 | 思想 | 特点 |
|---|---|---|
| PRM | 撒点连边建路图，多次查询复用 | 多目标查询 |
| **RRT** | 随机树快速扩展 | 快但路径歪 |
| **RRT\*/Informed-RRT\*** | 渐近最优+椭圆采样 | 收敛慢于图搜索 |
| **Hybrid A\*** | 栅格 A* + 状态含航向+Reeds-Shepp 解析扩展 | 无人叉车/汽车级运动学可行路径（Nav2 SMAC Hybrid 即此） |

## 运动学约束与成本设计

- **约束**：差速可原地转（SE2）；阿克曼最小转弯半径 R（Reeds-Shepp/Dubins 曲线）；舵轮全向
- **成本函数**（A* 的 g 定义决定行为风格）：
```
cost = 距离 + α·离墙代价(inflation) + β·转向代价 + γ·倒车/掉头惩罚 + δ·限速区穿越成本
调 α 大 → 机器人走走廊中间(安全感/安规)；调 β 大 → 少扭动(平稳)
```

## 全覆盖规划（清洁机器人主战场，→ [[清洁机器人]] · [[项目-清洁机器人]]）

1. **区域分解**：Boustrophedon 细胞分解（沿长边切弓字形带）
2. **遍历顺序**：Traveling-Salesman（TSP）近似求区段访问顺序（贪心/2-opt/Or-opt）
3. **弓字形参数**：行距 = 清洁宽度×0.9（重叠 10% 防漏）
4. **实际难点**：障碍切割区段→回接策略；动态行人穿越→暂停续扫记录断点
5. 覆盖率验收 ≥95% → [[性能指标体系]]

## 与下游的接口（→ [[局部规划与避障]]）

- 全局路径（米级，10-50cm 分辨率）不是轨迹——局部控制器沿路做时序化与动态避障
- 路径发布：`nav_msgs/Path`；Nav2 里 Planner Server 通过 Action 被 BT 调用 → [[Nav2导航框架]]
- 全局重规划触发：偏离路径 >阈值 / 静态障碍堵路 / 周期性（5-30s）

## 细节加深（V2）
- **OMPL 是采样族总库**（台账 #63，BSD-3）：RRT*/PRM/KPIECE 40+ 算法；机械臂规划（MoveIt 后端）也用它——学一个库通吃两类机器人。
- **Nav2 SMAC 三模式**（台账 #64 官方文档）：2D / Hybrid-A*（Dubins/RS）/ State Lattice——叉车与阿克曼必须 Hybrid-A* 系。
- **工程默认**：weighted-A*（ε=1.5）+ inflation cost + 转向惩罚——99% 室内 AMR 够用，别上来就 State Lattice。
