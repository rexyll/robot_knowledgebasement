# 视觉 SLAM（VSLAM）

> 以相机为主传感的 SLAM。便宜、信息丰富（可语义化），但依赖纹理与光照、纯视觉有**尺度不确定性**（单目）——所以实际都是 VIO（视觉惯性）形态。

## 视觉 SLAM 分类

| 类型 | 传感器 | 尺度 | 代表 | 特点 |
|---|---|---|---|---|
| 稀疏特征法 | 单目/双目/RGB-D | 单目无尺度 | **ORB-SLAM3**（词袋回环+多地图 Atlas） | 精度高、成熟稳定 |
| 直接法 | 单目/RGB-D | 单目无尺度 | LSD-SLAM、DSO | 弱纹理可用、对光照敏感 |
| 稠密/半稠密 | RGB-D | 有尺度 | RTAB-Map（ROS 生态常用） | 直接出稠密地图，算力高 |
| **VIO 紧耦合** | 相机+IMU | 有尺度 | **VINS-Fusion**（滑窗优化+初始化）、MSCKF（滤波派） | 主流工程形态 |
| 学习派 | 任意 | — | DROID-SLAM（深度学习光流+BA）、Gaussian Splatting SLAM | 研究前沿 → [[学习型机器人算法]] |

## 核心流水线（以 VINS-Fusion 为例）

```
1. 前端: KLT 光流跟踪特征点 + IMU 预积分
2. 初始化(最难的 10%): 视觉-惯性联合初始化(尺度/重力/速度/陀螺偏置 可观性分析)
3. 滑窗优化: 窗口内 10-15 关键帧, 重投影误差+IMU 预积分残差 联合最小二乘(Ceres)
4. 边缘化: 最老帧移出, 其信息保留为先验(舒尔补) — FEJ 保持一致性
5. 回环: DBoW2 词袋检索 + PnP 位姿恢复 + 四自由度位姿图优化(yaw/x/y, 不优化 roll/pitch/尺度)
6. 输出: 位姿 @10-30Hz + 关键帧点云地图
```

## 关键模块细节

| 模块 | 关键点 |
|---|---|
| 特征 | ORB（快、免费、旋转不变）；学习特征 SuperPoint（更稳但吃算力） |
| 重定位 | 词袋+几何校验；丢失后 PVFO 兜底（IMU+里程计推）→ [[多传感器融合定位]] |
| 双目标定 | 内参+畸变+右相机外参，stereoCalibrate → [[视觉软件栈]] |
| RGB-D 深度使用 | 深度直接给尺度+稠密地图，但玻璃/黑面是洞 → [[深度相机]] 局限 |
| 滑窗参数 | 窗口长=精度↑算力↑；边缘化策略决定一致性 |

## VSLAM vs 激光 SLAM 选型

| 维度 | VSLAM | 激光 SLAM |
|---|---|---|
| 成本 | 低（¥100-3000） | 高（¥1500-3万） |
| 尺度 | 单目无尺度（VIO 解决） | 直接有 |
| 纹理依赖 | 强（白墙死） | 无 |
| 光照 | 敏感（补光/曝光策略） | 不敏感 |
| 语义扩展 | 天然（图像即语义载体） | 需融合相机 |
| 典型应用 | 家用扫地机（成本第一）、巡检、AR | 商用 AMR、叉车 |

> 家用扫地机从 LiDAR 回归 VSLAM（成本+基站视觉功能），商用 AMR 以 LiDAR 为主+相机为辅——两条路线按场景各取所需。

## 细节加深（V2）
- **仓库许可证地图**（台账 #55-#58）：ORB-SLAM3/VINS-Fusion 均 **GPL-3.0**（商用闭源注意）；**RTAB-Map = BSD-3**（ROS2 集成最顺，商用友好）；stella_vslam = BSD-2（OpenVSLAM 延续，鱼眼支持）。
- **产品化建议**：要商用闭源闭环 → RTAB-Map（BSD-3）或 stella_vslam（BSD-2）起步；ORB-SLAM3 用于研究与验证。
- **词袋回环的工程真相**：误回环比不回环危害大——几何校验（PnP+重投影）必须做，验收时人为制造"相似场景"测试回环误判率。
