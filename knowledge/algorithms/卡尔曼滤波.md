# 卡尔曼滤波（KF / EKF / ESKF / 粒子滤波）

> 融合定位与 LIO 的重要数学工具：在线性高斯模型及相应假设成立时，KF 给出最小均方误差状态估计；非线性、非高斯、多峰或含离群值的问题通常需要扩展模型、鲁棒估计或其他方法。SLAM、VIO、SOC 估计和目标跟踪会使用 KF 家族或相关估计方法，但并非全部都使用标准 KF。

## 基础 KF 五公式（线性高斯假设）

```
预测: x̂ = F x + B u;    P = F P Fᵀ + Q
修正: K = P Hᵀ (H P Hᵀ + R)⁻¹     ← 卡尔曼增益(信谁多一点)
      x̂ = x̂ + K (z - H x̂)        ← 残差加权
      P = (I - K H) P
Q=过程噪声(模型多不可信), R=观测噪声(传感器方差)
```

直觉：**预测把不确定性吹大（+Q），观测把不确定性压小（×K）**，K 由双方不确定度比例决定。

## 非线性扩展（机器人全是非线性）

| 变体 | 思路 | 用途 |
|---|---|---|
| **EKF** | 一阶泰勒展开雅可比 | 简单融合、robot_localization |
| **ESKF/误差状态 KF** | 主状态(流形上的真值)+小量误差状态估计 | VINS、IMU 融合标准姿势（避免旋转角过零/万向锁） |
| **UKF** | Sigma 点无迹变换采样传播 | 强非线性、难求雅可比 |
| **粒子滤波（PF）** | 非参数贝叶斯滤波，以带权样本近似后验；不是 KF 的线性/高斯变体 | **AMCL**、Gmapping（RBPF-SLAM） |
| **迭代 EKF / iEKF** | 围绕最新估计反复线性化 | **FAST-LIO2 的 iEKF**，残差在地图上迭代 |

## IMU 预积分（VIO/LIO 关键积木）

- 问题：IMU 200-1000Hz、图像 10-30Hz，逐帧积分状态不可行
- 方案：Forster 等人的流形预积分——将关键帧间高频 IMU 测量压缩为相对运动约束，避免优化变量随 IMU 采样数增长；预积分量在给定线性化点下计算，并通过偏置的一阶雅可比进行偏置变化修正，不能理解为对任意初始状态/偏置都严格无关
- 实现：GTSAM `PreintegratedImuMeasurements`、VINS 自实现
- 深入场景 → [[视觉SLAM]]（滑窗因子）· [[激光SLAM]]（LIO-SAM 因子图）

## 可观性分析（为什么有些状态估不出来）

- 单目纯视觉的全局尺度存在规范自由度；加入 IMU 后，在足够的非退化平移/旋转激励、正确时间同步和传感器模型等条件下，尺度可变为可观。具体可观性取决于运动与测量配置
- 匀速直行：IMU 零偏与速度耦合不可分 → 需要机动
- 工程含义：初始化阶段的"8 字晃动"不是玄学，是可观性激励

## 调参经验（Q/R 治百病也坑百人）

1. **Q 过大**：信观测过头，输出抖动跟着噪声走
2. **R 过大**：信模型过头，修正迟钝漂移累积
3. 实操：先依据传感器数据手册、静态/动态数据和噪声模型建立 Q/R 初值；静止数据只能估计特定静态条件下的噪声，不能代表动态、温漂、振动和相关噪声。随后用独立数据与创新序列检查模型，不应只靠“调到响应跟上”
4. NIS/NEES 一致性检验：残差应服从理论分布，否则模型错了
5. 粒子滤波：粒子数、重采样策略和触发阈值由状态维数、场景、多峰程度、计算预算及具体实现决定；不存在适用于所有 AMCL/PF 系统的 500–5000 或 ESS<1/2 通用规则。应记录所用实现与参数，并用代表性数据评估

## 2026-11-03｜P1 主张定向复核补充

本轮复核仅处理本页中影响概念边界和调参方法的高风险表述，不代表全文 claim-level 验收。

- **KF 与 PF 分类**：粒子滤波是非参数贝叶斯滤波方法，不是 KF 的线性/高斯变体；AMCL 与 Gmapping 可使用粒子滤波/RBPF。
- **IMU 预积分**：预积分把关键帧间高频 IMU 测量汇总为相对运动约束；在给定线性化点下计算，并用偏置雅可比修正。不能简化为“与初始状态无关”。
- **可观性**：单目视觉的尺度规范自由度、VIO 的尺度可观性取决于传感器组合与充分激励，不能把“加速度激励”写成无条件保证。
- **Q/R 与一致性**：静止样本不能覆盖动态噪声、温漂、振动和相关噪声；NIS/NEES 需要在模型假设、自由度和统计检验条件下解释，不能只用一句“残差应服从理论分布”作验收。
- **PF 参数**：粒子数与 ESS 重采样阈值不是跨实现通用常数；AMCL 的运动模型参数也不等同于 EKF 的 Q 矩阵。

## 2026-11-05｜P1 数值稳定性、创新检验与异常观测处理

本节补充滤波器从“公式正确”走向“数值实现可诊断”的工程要求。它是算法设计与离线审查清单，不代表已在目标机器人上运行或验证。

### 1. 协方差更新：简式与 Joseph 形式

标准线性 KF 的测量更新可写为：

\[
\hat{x}^{+}=\hat{x}^{-}+K\nu,\qquad
\nu=z-H\hat{x}^{-},\qquad
S=HP^{-}H^{T}+R
\]

在理想精确算术及相应滤波假设下，协方差常写为：

\[
P^{+}=(I-KH)P^{-}
\]

实际浮点实现中，舍入误差可能使该简式产生轻微非对称，甚至破坏半正定性。常用的 Joseph 稳定形式为：

\[
P^{+}=(I-KH)P^{-}(I-KH)^{T}+KRK^{T}
\]

实现注意事项：

- Joseph 形式通常比简式需要更多矩阵乘法，但显式保留先验协方差与测量噪声的贡献，有助于降低有限精度运算导致的协方差失真。
- 更新后可监测 \(P\) 与 \(P^{T}\) 的对称误差、最小特征值或 Cholesky 分解是否成功；对称化 \((P+P^T)/2\) 只能作为数值卫生措施，不能修复错误模型、错误单位或不合法噪声协方差。
- 不应通过任意给对角线加常数来掩盖协方差失效；若使用 jitter/floor，必须记录触发次数、幅度、状态维度及其对估计结果的影响。
- EKF 中还需检查雅可比线性化点、角度残差的 wrap 规则和状态流形的误差定义；不能把欧氏空间的直接相减机械套用到四元数/旋转状态。

### 2. 创新与创新协方差是在线诊断入口

对一次观测，定义创新（残差）与创新协方差：

\[
\nu_k=z_k-h(\hat{x}^{-}_k),\qquad
S_k=H_kP^{-}_kH_k^T+R_k
\]

非线性观测模型应使用当前线性化点处的观测雅可比，或相应滤波器定义的等价统计量。创新不是“越接近零越好”的单一指标：其均值、协方差、时间相关性和分布形态都与模型假设有关。

建议记录并分层观察：

- 创新均值是否长期偏离零：可能涉及坐标/外参偏差、时间偏移、未建模偏置或传感器安装变化。
- 创新自相关：显著时间相关可能说明运动模型、噪声模型或延迟处理不充分。
- 创新协方差与实测统计是否一致：必须考虑样本量、自由度、非线性近似及数据筛选过程。
- 分传感器、分轴、分工况统计：把所有观测混成一个总体指标，可能掩盖单个传感器或特定工况的异常。

### 3. NIS 门限与异常观测门控

归一化创新平方（NIS）定义为：

\[
\operatorname{NIS}_k=\nu_k^TS_k^{-1}\nu_k
\]

当观测维数为 \(m\)，且线性高斯模型、协方差正确、观测未经过基于同一残差的选择/截断等条件成立时，NIS 可与自由度为 \(m\) 的卡方分布比较。工程中可按预先定义的显著性水平设置统计门限；不能把某个固定 NIS 数值作为所有传感器、维数和工况的通用阈值。

异常观测处理至少要区分：

1. **拒绝/门控**：观测明显不符合模型时跳过本次更新；记录拒绝原因和连续拒绝时长。
2. **降权/鲁棒更新**：对离群值采用有明确统计或优化依据的鲁棒损失/权重；需说明其对协方差解释的影响。
3. **故障判定**：连续异常可能来自传感器故障、遮挡、时间戳错误、外参变化或模型失配；门控本身不是故障诊断。
4. **安全降级**：若定位/姿态质量低于任务要求，交由系统级状态机采取限速、停止、切换独立定位源或请求人工介入。滤波器不应自行把“拒绝观测”解释为机器人仍然安全。

门控可能产生选择偏差：只保留通过门限的残差，再用这些残差评估原始未截断分布，会低估尾部异常。验证报告应同时记录原始观测、门控结果、拒绝比例和连续异常段。

### 4. NEES 与 NIS 不可互相替代

若有可信真值 \(x_k\)，归一化估计误差平方（NEES）可写为：

\[
\operatorname{NEES}_k=(\hat{x}_k-x_k)^TP_k^{-1}(\hat{x}_k-x_k)
\]

NEES 直接利用估计误差与估计协方差，通常需要可用的真值或可接受的参考轨迹；NIS 则只使用观测创新，不要求直接获得真实状态。二者适用条件和统计自由度不同。姿态误差、状态约束、相关样本、真值不确定性和滤波器非线性都会影响检验解释。

### 5. 工程验证最小记录集

| 类别 | 至少记录 | 不能据此直接宣称 |
|---|---|---|
| 数值健康 | P 对称误差、正定性/分解失败、NaN/Inf、求解器状态 | 估计精度已达标 |
| 创新统计 | 每类传感器的创新、S、NIS、自由度、门控标记 | 所有噪声均为高斯白噪声 |
| 估计误差 | 有真值时的 NEES、APE/RPE 或任务误差及真值来源 | 单次轨迹代表长期性能 |
| 时间行为 | 时间戳、乱序/延迟、队列积压、更新耗时和丢帧 | 平均耗时代表最坏执行时间 |
| 故障注入 | 遮挡、偏置漂移、跳变、丢包、时间偏移、传感器失联 | 门控机制等同独立安全功能 |
| 可复现性 | 数据集哈希、软件 commit、参数、标定、运行环境 | 文档示例等同目标平台验收 |

### 6. ROS 2 实现配置的特别边界

robot_localization 的官方文档区分 EKF 与 UKF：EKF 使用运动模型与雅可比线性化，UKF 通过 sigma points 传播状态和协方差，计算代价通常更高。其传感器配置向量按输入消息的 frame_id 解释；differential 会把连续位姿差分为速度，relative 则相对首个观测值；两者不是可互换的“清零开关”。融合全局绝对位置且允许离散跳变时，官方文档要求 world_frame=map，并确保另一个来源提供 odom→base_link，避免 TF 权威冲突。

这些是该软件包的配置语义，不应直接外推为所有 EKF/UKF 库的通用 API。部署前必须锁定 ROS 发行版、包版本/commit、RMW、传感器消息定义和实际 TF 树。

## 2026-11-05｜P1 ESKF 误差状态定义、协方差传播与 IMU 预积分边界

本节将 ESKF 的“名义状态在非线性状态空间演化、误差状态在局部切空间线性化”的做法写成可审查的工程模型，并区分滤波器逐时刻传播与因子图关键帧间 IMU 预积分。以下公式采用明确约定作为一个可复现例子；其他左/右扰动约定会改变误差定义、雅可比和符号，不能混合摘取。

### 1. 名义状态与误差状态：先锁定扰动约定

以 IMU/body 坐标系 B、世界坐标系 W 为例，定义名义状态：

\[
\hat{x}=(\hat R_{WB},\hat v_W,\hat p_W,\hat b_g,\hat b_a)
\]

其中 \(R_{WB}\) 将 B 系向量旋转到 W 系；速度和位置在 W 系表达；陀螺仪与加速度计偏置在 B 系表达。重力向量 \(g_W\) 是已知模型参数或单独估计的状态，不能在推导中悄悄省略。

本节采用右乘姿态扰动、世界系加性速度/位置误差：

\[
R_{WB}=\hat R_{WB}\operatorname{Exp}(\delta\theta_B),\quad
v_W=\hat v_W+\delta v_W,\quad
p_W=\hat p_W+\delta p_W
\]

\[
b_g=\hat b_g+\delta b_g,\qquad
b_a=\hat b_a+\delta b_a
\]

误差向量按 \(\delta x=[\delta\theta_B^T,\delta v_W^T,\delta p_W^T,\delta b_g^T,\delta b_a^T]^T\) 排列，共 15 维。姿态误差是 SO(3) 切空间中的 3 维局部量，不是四元数四个分量直接相减；名义姿态可用单位四元数存储，但误差协方差仍按所选三维切空间定义。

**必须同时记录：** 旋转矩阵映射方向、误差是左乘还是右乘、姿态误差在哪个坐标系、速度/位置误差在哪个坐标系、状态排列顺序、偏置单位和重力方向。若更换左扰动、Invariant ESKF 或不同状态排列，必须重新推导并验证 F/G/H，不能只改变量名。

### 2. IMU 连续时间名义传播

设测量为角速度 \(\omega_m\) 和比力 \(a_m\)，偏置估计为 \(\hat b_g,\hat b_a\)，则一组常见名义动力学为：

\[
\dot{\hat R}_{WB}=\hat R_{WB}[\omega_m-\hat b_g]_\times
\]

\[
\dot{\hat v}_W=g_W+\hat R_{WB}(a_m-\hat b_a),\qquad
\dot{\hat p}_W=\hat v_W
\]

偏置常建模为随机游走：

\[
\dot{\hat b}_g=0,\quad \dot{\hat b}_a=0
\]

随机游走噪声进入误差/过程噪声模型，而不是把偏置估计每个采样周期随意抖动。以上模型假定 IMU 测量已完成必要的单位、轴向、重力/比力语义和时间戳处理；若驱动输出的是已经去重力的线加速度或内部融合姿态，必须按消息定义重建模型，不能再次重复补偿重力。

### 3. 误差动力学与协方差传播

在上述右乘姿态误差、世界系速度/位置误差约定下，连续时间一阶误差动力学可写成：

\[
\delta\dot x=F\delta x+G n
\]

其中状态转移矩阵的非零结构（令 \(\hat\omega=\omega_m-\hat b_g\)、\(\hat a=a_m-\hat b_a\)）为：

\[
F_{\theta\theta}=-[\hat\omega]_\times,\quad
F_{\theta b_g}=-I
\]

\[
F_{v\theta}=-\hat R_{WB}[\hat a]_\times,\quad
F_{v b_a}=-\hat R_{WB},\quad
F_{p v}=I
\]

其余块在该简化模型中为零。噪声向量至少区分陀螺白噪声、加速度白噪声和两类偏置随机游走；G 的符号/坐标映射必须与所选噪声定义一致。若将速度误差也定义在机体系，或改用左乘姿态误差，上述块矩阵会变化。

离散传播写为：

\[
P_{k+1}^{-}=\Phi_kP_k^{+}\Phi_k^T+Q_{d,k}
\]

\(\Phi_k\) 是连续误差动力学在采样区间上的离散状态转移矩阵，\(Q_{d,k}\) 是同一区间累计的离散过程噪声协方差。可通过矩阵指数/Van Loan 方法或经过验证的数值积分得到；一阶近似 \(\Phi\approx I+F\Delta t\) 仅在步长和动态条件允许时使用。不得把连续噪声谱密度直接当成离散样本方差，也不得不考虑采样周期就照搬噪声参数：连续 PSD、采样/滤波带宽、样本保持模型和离散噪声协方差之间必须保持量纲一致。

### 4. 测量更新、误差注入与 reset Jacobian

对测量模型线性化后，在误差空间执行 EKF 更新，得到局部误差估计 \(\widehat{\delta x}\)；然后将其注入名义状态：

\[
\hat R^{+}=\hat R^{-}\operatorname{Exp}(\widehat{\delta\theta}),\quad
\hat v^{+}=\hat v^{-}+\widehat{\delta v},\quad
\hat p^{+}=\hat p^{-}+\widehat{\delta p}
\]

\[
\hat b_g^{+}=\hat b_g^{-}+\widehat{\delta b_g},\qquad
\hat b_a^{+}=\hat b_a^{-}+\widehat{\delta b_a}
\]

注入后，误差坐标原点已经从旧名义状态移动到新名义状态。必须把协方差从旧切空间转换到新切空间：

\[
P^{+}\leftarrow G_{reset}P^{+}G_{reset}^{T}
\]

其中 \(G_{reset}\) 是由具体左/右扰动和注入定义推导的 reset Jacobian。小角度下某些分量可近似为单位阵，但姿态块一般涉及 SO(3) 右/左 Jacobian；不可无条件省略 reset，也不能从不同论文复制一个符号相反的公式。实现应通过有限差分/自动微分与解析雅可比对照，并在多次姿态更新后检查协方差一致性。

### 5. IMU 预积分：与逐时刻滤波传播的关系

预积分通常用于关键帧 i 到 j 之间，将高频 IMU 测量压缩为相对旋转、速度和位置增量：

\[
\Delta R_{ij},\quad \Delta v_{ij},\quad \Delta p_{ij}
\]

这些增量定义在起始关键帧附近的局部参考系中，可作为因子图中的相对运动约束，避免为每个 IMU 样本都建立一个优化状态。它不是“与初始状态完全无关”：预积分构造依赖选定的线性化偏置和噪声模型，且姿态/速度/位置残差会依赖两端关键帧状态及重力。

工程实现至少需要保存：

- 预积分区间起止时间、原始 IMU 样本及缺样/重复/乱序处理记录。
- 线性化偏置 \(\bar b_g,\bar b_a\)，以及对偏置的一阶修正 Jacobian。
- \(\Delta R,\Delta v,\Delta p\) 的联合协方差和交叉协方差；不能只分别保存三个对角块而默认互相独立。
- 预积分残差定义、坐标系、旋转 Log/Exp 约定、重力项和两端状态排列。
- 当当前偏置偏离线性化点较大、线性修正不再可信时，重新对原始 IMU 数据预积分；偏置阈值由误差预算和实验确定，不设跨平台常数。

经典 on-manifold 预积分把旋转放在 SO(3) 上处理，推导噪声传播、解析 Jacobian 和后验偏置修正，并将其用于因子图优化。它主要是关键帧间约束构造方法；ESKF 则常逐时刻传播名义状态与协方差。两者共享 IMU 运动模型和误差传播基础，但不能把因子图预积分因子直接当成 ESKF 的离散状态转移矩阵，除非明确证明其变量、线性化点和噪声定义一致。

### 6. 容易造成“看似能跑、统计却不一致”的实现错误

| 错误 | 可能后果 | 建议检查 |
|---|---|---|
| 左/右姿态误差混用 | F、H、注入和 reset Jacobian 符号/坐标错 | 固定单一约定；有限差分检查 |
| 四元数直接加减 | 破坏单位范数与局部误差几何 | 在 SO(3) 切空间更新并归一化名义四元数 |
| 把比力当作世界系线加速度 | 重力方向/姿态变化时速度持续偏差 | 核对 IMU 消息定义、轴向和重力补偿位置 |
| 连续噪声密度当离散方差 | Q 随采样频率错误缩放 | 核对 PSD 单位、带宽、采样周期和离散化 |
| 只传播 P 对角块 | 丢失姿态-速度-位置-偏置相关性 | 保留完整协方差及交叉项 |
| 注入后不 reset | P 与当前误差坐标系不匹配 | 推导并测试 reset Jacobian |
| 偏置修正无限线性外推 | 预积分残差失真 | 监测偏置偏离量，必要时重积分 |
| IMU 时间戳/积分边界错误 | 积分时长、运动补偿和协方差均偏离 | 检查首尾样本、插值、时钟域和丢包 |
| 忽略饱和、振动、温度和安装误差 | 白噪声模型不足以解释真实误差 | 标定、温度/振动分工况建模与故障注入 |

### 7. 最小验证计划

1. **几何单元测试：** 验证 Exp/Log、四元数与旋转矩阵互转、正交性、单位行列式、接近零角与接近 π 角的数值行为。
2. **雅可比验证：** 对 F、G、H、预积分 bias Jacobian 和 reset Jacobian 做有限差分/自动微分交叉检查，固定扰动方向和坐标系。
3. **协方差传播验证：** 与高精度数值积分或 Monte Carlo 样本统计比较；检查对称性、半正定性和经验覆盖率。
4. **预积分一致性：** 同一 IMU 序列下，对比逐样本状态传播与关键帧预积分重建的相对运动、协方差和偏置修正。
5. **边界/故障注入：** 覆盖不同采样周期、丢样/乱序、时间偏移、饱和、温漂、偏置突变、强角运动和长积分区间。
6. **统计一致性：** 在具有可信真值及其不确定度的数据集上报告姿态/位置/速度误差、NIS/NEES、协方差覆盖率和失败样本；样本相关性及自由度必须说明。
