# 人形机器人

## 1. 定义与统计口径

IFR 的人形机器人调查定义强调：机器人具有类人的外观，并能在为人设计的环境中执行任务而不需要改造环境；统计问卷列出人形躯干、手臂、移动能力（腿或轮）、类人感知和自主运行（非遥操作）等条件。IFR 问卷优先报告客户现场开始生产运行的安装量，不能提供时才报告出货量。来源：链接台账 #177。

因此，人形机器人市场统计必须先明确高度门槛、是否自主、是否允许遥操作、是否纳入研发/娱乐用途，以及使用销量、出货量还是现场安装量。

## 2. 市场快照：不能把工厂下线量写成客户部署量

IFR《World Robotics 2026 Service Robots》估计，2025 年全球售出约 **7,000 台全尺寸人形机器人（身高超过 140 cm）**。报告指出，当前不少应用仍然专门化，部分需要人工遥操作；安全标准、训练与维护成本、商业案例仍限制广泛部署。该数字不是所有尺寸人形机器人的总产量，也不是所有公司自报下线数量。来源：链接台账 #176、#177。

## 4. 系统技术组成

| 系统层 | 关键子系统 | 设计与验证问题 |
|---|---|---|
| 结构与运动 | 躯干、头部、双臂、腿/轮式移动机构、关节模组、末端工具 | 质量分布、刚度、运动范围、稳定性、疲劳、维护与碰撞 |
| 执行与驱动 | 电机、减速器、编码器、驱动器、制动与关节控制 | 连续/峰值扭矩、速度曲线、热、惯量、背隙、故障响应 |
| 能源 | 电池包、BMS、供配电、充电/换电 | 能量预算、峰值电流、热失控防护、充电互锁、续航工况 |
| 感知 | RGB/深度/全景相机、IMU、力/力矩、触觉、关节反馈 | 标定、时间同步、遮挡、漂移、环境适应和故障诊断 |
| 运动控制 | 状态估计、全身控制、平衡、步态、抓取和轨迹规划 | 稳定性、接触切换、约束处理、实时性和故障降级 |
| 智能与应用 | 任务规划、VLA、模仿/强化学习、遥操作和数据平台 | 任务成功率、人工接管率、泛化边界、数据许可和版本回归 |
| 安全与维护 | 物理防护、风险降低措施、急停/保护停止、维修与安全状态 | 具体应用风险评估、独立安全功能、验证和维护隔离 |

以上是系统分解，不表示某一厂商完整采用相同架构。各子系统的实际边界应由准确产品资料和项目需求确认。

## 5. 工程评估重点

1. **任务与 ODD：** 明确产品用途、目标用户、操作环境、对象、地面/坡度、人员接近方式和禁止场景。
2. **负载与运动：** 把末端工具、物体、连杆、加速度和跌倒/冲击工况纳入动力学与结构预算。
3. **自主程度：** 分开记录全自主、监督自主、远程操作和人工接管，不能用演示视频判断。
4. **安全：** 将机器人本体、末端工具、工作空间、用户流程和维护状态作为完整应用进行风险评估；不能由“人形”或“具身 AI”标签推导安全等级。
5. **可靠性与经济性：** 记录运行小时、无故障任务数、任务成功率、人工干预、维修工时、备件、停机和单位任务成本。
6. **制造与服务：** 记录关键模组版本、供应商、批次、校准、出厂测试、安装培训、售后和软件更新回滚。

## 6. 从零开始的学习路径

- 数学和物理：坐标系、向量/矩阵、刚体运动、力矩、功率和能量。
- 机械与电气：材料、关节、传动、执行器、电源、电池、保护和热。
- 机器人基础：运动学、动力学、状态估计、轨迹规划和反馈控制。
- 软件与 AI：Linux、ROS 2、仿真、视觉、数据工程、VLA/强化学习；先掌握确定性控制和测试，再研究学习型策略。
- 产品工程：需求追踪、接口控制、风险评估、DVP&R、NPI、质量、追溯和售后。

学习本页不能代替机器人调试培训、安全资格、专业设计审核或真实产品测试。没有专业人员、场地、防护和能源隔离时，不应自行进行带电带载双足机器人试验。
