# 服务机器人

> 面向非制造业、直接服务人的机器人（IFR 分类：专业服务 + 消费服务）。2024 年全球专业服务机器人销量约 20 万台，年增 30%+。

## 主要细分

| 细分 | 场景 | 技术要点 | 代表 |
|---|---|---|---|
| 配送机器人 | 餐厅/酒店/写字楼送餐 | 荤素精确定位、乘梯对接、人机交互 | 擎朗 T5、普渡 BellaBot |
| 迎宾讲解 | 展厅/政务大厅 | 语音交互(ASR/TTS/LLM)、主动迎人 | 科大讯飞、猎户星空豹小秘 |
| 商用清洁 | 商场/机场 | → [[清洁机器人]] | 高仙 |
| 医疗配送 | 医院药品标本运送 | 院内门禁对接、消毒等级 | → [[医疗机器人]] |
| 安防巡逻 | 园区/景区 | 夜视、热成像、喊话 | 优必选、万为 |
| 教育陪伴 | K12/养老 | 情感交互、安全设计 | 小度、优必选 Alpha |
| 展演娱乐 | 文旅/舞台 | 群控编排 | 宇树春晚集群 |

## 与 AMR 的技术同源性

服务机器人 ≈ [[移动机器人]] + **人机交互栈**：
- 交互层：ASR（语音识别）→ LLM/NLU → TTS + 表情屏 + 手势 → 多模态
- 导航层与 AMR 完全同构：[[激光SLAM]] · [[路径规划算法]] · [[局部规划与避障]]，但需**社交导航**（绕人距离 0.8-1.2m、不贴人后方穿行）
- 云端：乘梯模块（电梯 IoT 对接）、多楼层地图切换 → [[云端协同与OTA流程]]

## 核心参数（配送类典型值）

| 参数 | 典型值 |
|---|---|
| 托盘层数/负载 | 3-4 层，每层 10-15kg |
| 速度 | 0.5-1.2 m/s（可调，餐厅 0.8 稳态） |
| 定位精度 | ±5cm（送餐桌位） |
| 续航 | 10-12h（6000-8000mAh×2） |
| 屏幕 | 10-13 寸触摸屏 |
| 语音 | 6 麦阵列、AEC 回声消除 |
| 乘梯对接 | 4G/蓝牙/WiFi 与电梯协议转换盒 |

## 商业模式特征

- 直销/租赁（月租 1500-3000 元）两种模式；回本周期测算依赖替代人效
- 单点盈利的关键：**递送频次 × 替代人工成本 − 租金与运维**

## 细节加深（V2）
- **社交导航参数化**：绕人距离 0.8-1.2m、不贴人后方穿行、电梯口排队——实现上是 costmap 加"社会力层"+局部规划代价项（→ [[局部规划与避障]] 的动态障碍节）。
- **乘梯对接是服务机器人最重工程**：电梯 IoT 盒子协议（RS485/CAN→MQTT）、光幕确认、超时降级——占服务机器人现场问题单的 30%+（行业交付共识）。
