# 移动机器人（AGV / AMR / IGV）

移动机器人（Mobile Robot）是能够在自身控制下移动的机器人。它可以是仅承担移动任务的平台，也可以搭载输送模块、升降机构、机械臂或其他作业装置。工业场景中的移动机器人通常承担物料搬运、牵引、货物转运、上/下料或移动操作任务，但“移动机器人”并不自动等于“工业车辆”，也不自动适用同一套安全标准。

选型和设计时必须区分三个层次：

- **移动机器人本体**：底盘、驱动、转向、制动、能源、车载控制器、传感器和保护装置。
- **移动机器人系统/应用**：本体、载荷/附加装置、任务、人员、工作区域、设施接口、充电设施、其他机器和运维流程共同形成的系统。
- **车队与设施系统**：任务调度、交通协调、充电管理、门/电梯/输送线接口，以及 WMS/MES/ERP 等业务系统集成。

IFR 引用 ISO 8373 的定义：移动机器人是“能够在自身控制下移动的机器人”；它可以带或不带机械臂，也可以具备远程控制方式。工业物流中，沿标记或外部引导指令的预定路径运行的平台，也常被称为 AGV 或无人驾驶工业车辆。该定义并不意味着所有移动机器人都必须自主建图，亦不意味着带机械臂的平台就不属于移动机器人。

## AGV、AMR 与 IGV：先定义技术特征，再使用名称

行业资料、厂商产品线和招标文件对 AGV、AMR、IGV 的使用并不完全一致。名称可以用于沟通，但工程评审必须把真正影响设计和安全的能力写清楚。

| 常见名称 | 常见用法 | 应核验的技术特征 | 不应据此推断 |
|---|---|---|---|
| AGV（Automated Guided Vehicle） | 常指沿磁条/磁钉、地面标记、反光板或其他引导设施运行的自动导引车辆；部分产品也具备车载定位和避障 | 导引设施类型、路线/分支控制方式、定位来源、障碍检测、人工介入与故障恢复模式 | 不能一概认定只能沿磁条运行，或不具备避障能力 |
| AMR（Autonomous Mobile Robot） | 常指依靠车载感知、定位与规划在环境中自主导航，并能在约束内调整行驶路线的平台 | 自主定位范围、地图依赖、动态重规划边界、禁行区/单行区、定位退化处理、远程接管和恢复流程 | 不能推断其可以在任意未知环境自由行驶，或只靠导航软件就满足人员安全要求 |
| IGV（Intelligent Guided Vehicle） | 不同厂商和市场语境下可能指智能导引车辆、AGV/AMR 混合产品或某种产品系列名称 | 厂商如何定义导引/定位、自动化模式、运行区域、障碍应对、接口及安全功能 | 不是可直接替代产品技术规格、风险评估或标准适用性判断的统一能力等级 |

因此，不以“AGV 逐渐被 AMR 取代”“AGV 固定路径、AMR 自由路径”作为无条件行业结论。实际产品可能使用反光板定位、自然特征定位、二维码/地面标记、磁导航、视觉、激光或多种技术融合；固定路线、动态绕行、区域限速和人工接管也可能在同一系统中并存。

## 移动机器人系统架构

一个完整移动机器人系统通常由以下层次组成。具体部署可合并或拆分组件，但接口责任必须清楚。

| 层次 | 主要职责 | 典型组成/接口 |
|---|---|---|
| 机械与移动平台 | 承载负载并在地面环境中运动 | 底盘、驱动轮/舵轮/脚轮、转向、悬挂、制动、支撑轮、载荷接口 |
| 能源与充电 | 供给驱动、计算、感知和附属设备能源 | 电池组、BMS、接触式/自动充电、充电桩、连接器、热管理 |
| 传感与状态估计 | 获取环境和车辆状态 | LiDAR、相机、深度相机、IMU、编码器、超声波、毫米波、GNSS（适用时） |
| 定位与导航 | 估计自身位姿并规划可行运动 | 地图/定位、全局路径、局部控制、重规划、恢复行为 |
| 车辆控制 | 将运动目标转换为驱动、转向和制动命令 | 底盘控制器、驱动器、运动学模型、速度/转角接口、状态诊断 |
| 保护与安全控制 | 降低人员、财产和设备暴露于危险的风险 | 安全相关扫描/检测、保护停止、速度监控、制动、安全控制器、急停、警示装置 |
| 车队与交通管理 | 跨车辆安排任务、路线和共享资源 | 任务队列、交通协调、路权/区域预约、死锁处理、充电调度、状态监控 |
| 设施与业务集成 | 连接真实物料流和生产流程 | 自动门、电梯、输送线、货架/站点、WMS/MES/ERP、通信与设备身份 |
| 运维与网络安全 | 保持系统可维护、可诊断和可控 | 日志、告警、配置管理、OTA、访问控制、备份/回滚、故障记录和变更管理 |

**导航与安全必须分层。** SLAM、定位置信度、全局/局部规划、Nav2 Costmap、keepout 区域或普通碰撞检查属于导航/应用软件能力；除非某个软硬件链路被明确设计为适用的安全相关功能并完成相应验证，否则不能把它们当作安全额定人员检测、保护停止或防碰撞装置的替代品。普通导航地图中的禁行区也不等同于经验证的安全区域边界。

## 按作业和附加装置分类

移动平台的类别通常由实际搬运任务、机械结构和附加装置决定，而不是只看导航算法。

| 形态 | 典型任务 | 重点工程问题 |
|---|---|---|
| 潜伏/顶升式搬运平台 | 潜入料架、托盘或专用载具下方，顶升后转运 | 顶升机构锁止、载荷重心、货架间隙、载具兼容、抬升/下降期间的人员隔离 |
| 牵引式平台 | 拖带多个料车或工装车 | 牵引质量、连接器、列车转弯内轮差、拖车制动、路径占用和脱挂流程 |
| 叉举式/无人叉车 | 托盘取放、堆垛、货架存取 | 货叉与托盘兼容、视野盲区、载荷稳定、提升高度、重心变化、坡道和货物坠落风险 |
| 滚筒/输送式平台 | 与输送线或工位直接交接货物 | 滚筒高度/速度匹配、夹点、交接联锁、物料偏移和输送线故障 |
| 移动操作平台 | 移动底盘搭载机械臂、协作臂或其他操作机构 | 移动底盘与机械臂的组合运动、稳定性、载荷偏心、伸展状态下的倾覆/碰撞风险及集成安全 |
| 户外/特定环境平台 | 园区、港口、农业、矿区或其他室外任务 | GNSS/视觉可用性、坡度/地面承载、天气、粉尘/水、通信覆盖、人员/车辆混行和专项法规 |

在美国 ANSI/A3 R15.08-2 的分类语境中，IMR Type A 指不带附加装置的 AMR 平台；Type B 指带非机械臂附加装置（如滚筒、输送或升降装置）的 AMR；Type C 指以 AMR 或 AGV 底盘为移动平台、并搭载机械臂的系统。该 A/B/C 是特定标准系列中的工业移动机器人分类，不是全球通用的机器人分类法。

## 导航、定位和引导方式

导航技术应根据环境特征、运行区域、可维护性和任务精度选取。定位结果、站点对接误差和安全保护区域是不同指标。

| 技术路线 | 主要原理 | 优势与限制（需结合现场验证） |
|---|---|---|
| 磁条/磁钉/导线引导 | 车辆检测地面磁性或电磁引导设施 | 路线约束清晰、基础设施可控；改线需要调整地面设施，交叉口/分支需要专门控制逻辑 |
| 二维码/地面标记 | 通过相机或专用传感器识别离散标记 | 可在特定环境提供位置参考；依赖标记安装、可视性、磨损/污染控制和维护 |
| 反光板/激光定位 | LiDAR 观测已知反光标志或环境几何特征 | 可在设施规划好的环境中建立定位基础；受遮挡、反射条件、几何重复性和标志维护影响 |
| 自然特征 LiDAR SLAM | 依据环境点云特征估计位姿并构建/匹配地图 | 可减少专用地面标记；长走廊、重复货架、动态遮挡、玻璃/反射和环境改变可能导致退化 |
| 视觉/视觉惯性定位 | 相机特征与 IMU 等信息估计位姿 | 可利用视觉纹理和环境语义；对光照、动态物体、遮挡、纹理和相机安装标定敏感 |
| 多传感器融合 | 融合编码器、IMU、LiDAR、视觉、GNSS 或其他传感器 | 可在部分传感器失效/退化时提高可观测性；收益取决于标定、时间同步、噪声模型、故障检测和冗余设计 |

不要直接将“反光板 ±5 mm”“自然导航 ±10 mm”“货叉对接 ±2–5 mm”写成跨产品通用精度。比较定位/导航性能时，至少区分：

- **定位误差**：车辆估计位姿与测量参考之间的误差；应说明测量基准、环境、时间窗口和统计分位数。
- **站点对接重复性**：多次到达同一站点时，实际停靠位姿的离散程度；应说明负载、方向、速度、地面及停靠流程。
- **绝对对接误差**：停靠位置相对于工装/输送线/货架基准的偏差；受地图、标定、机械公差、底盘间隙和工装共同影响。
- **货叉/机构对接能力**：除底盘位姿外，还取决于托盘孔位、货叉尺寸/间距、高度感知、升降机构和载荷变形。

导航系统可能需要通过视觉标志、机械导向、浮动机构或站点传感器完成最终对接；不能把地图定位精度直接当作工艺交付精度。

## 选型：建立统一任务与验收口径

不使用一张跨车型“典型负载、速度、精度和续航”范围表直接作采购决策。先定义任务和运行设计域，再按同一测试条件比较候选平台。

1. **物料与工艺**：明确货物/托盘/料架/料车尺寸、总质量、重心、接触面、取放高度、抓取/顶升/牵引方式和工位接口；识别易碎、易倾倒、锐边、温度或其他危险载荷。
2. **地面和环境**：确认地面材质、接缝、坡度、门槛、排水、坡道、转弯、地坪承载、照明、粉尘、水、温度和电磁环境。
3. **路线与空间**：核查通道宽度、会车/超车、交叉口、盲区、货架突出物、人员通道、消防/疏散路线、动态障碍和安全区域。
4. **车辆动力与稳定性**：根据载荷重心和工况核对驱动/制动能力、加减速、转弯半径、坡道能力、轮胎抓地、悬挂和载荷变化下的稳定性；最大速度不能脱离载荷/地面/运行区单独比较。
5. **导航与对接**：定义定位覆盖、站点对接、地图更新、定位丢失、动态障碍、远程接管和恢复流程；对实际最难路线和最差环境做测试。
6. **安全与法规**：根据产品和使用场景确认 ISO 3691-4、ANSI/A3 R15.08 或其他标准的适用范围；完成风险评估，验证人员检测、保护停止、制动、急停、告警和故障响应。
7. **电池与充电**：基于任务循环、实际负载、行驶距离、待机功耗、温度、电池老化和充电策略估算能量需求；在真实班次下测量续航和充电恢复，不用额定容量简单推算产能。
8. **车队与系统集成**：核验任务分配、交通协调、拥堵/死锁恢复、充电排队、通信丢失、设施互锁、业务系统接口、日志和权限。
9. **生命周期**：评估备件、维保、轮胎/电池寿命、软件升级、地图/配置变更、供应商服务和停产替代方案；比较总拥有成本而非单机报价。

### 建议记录的关键指标

| 指标 | 必须注明的条件/口径 |
|---|---|
| 额定负载与承载接口 | 载荷重心/偏心、升降高度、托盘/料车接口、动态工况及厂家负载曲线 |
| 最大/额定行驶速度 | 空载/满载、直线/转弯、坡道、限速区、测试地面及速度设定方式 |
| 加速度/制动/停止距离 | 载荷、地面、速度、制动状态、电池/温度、测量起止点和重复次数 |
| 定位与停靠性能 | 环境、地图版本、入站方向、速度、负载、测量基准、重复次数和统计方法 |
| 最小通道/会车能力 | 车型尺寸、载荷/附加装置、转弯/倒车策略、其他车辆及人员占用条件 |
| 爬坡/越障能力 | 坡度、坡长、载荷、坡面材质、起停/转向工况和防滑要求 |
| 能耗/续航/充电 | 任务循环、负载、路面、温度、待机比例、电池健康度、充电窗口和可用率口径 |
| 任务吞吐/车队能力 | 任务定义、距离、工位服务时间、拥堵、充电、人工干预和异常恢复是否纳入 |
| 安全检测与保护响应 | 探测对象/速度、传感器视场、遮挡、保护区域配置、响应链路、停止距离、失效模式和现场验证 |

参数应来自具体 SKU 的当期数据手册、集成手册和安全手册；“最大值”不能直接当作持续产能指标。厂家测试值、实验室值和现场验收值应分列。

## 人员共域运行与安全边界

工业移动机器人在人员工作区域运行时，存在撞击、夹困、挤压、碾压、载荷/部件抛射和环境相关危险。风险不仅来自车辆本体，也来自牵引车/料车、叉举载荷、货架、门、电梯、输送线、机械臂、设施联锁和任务变化。单车安全并不自动保证多车车队或完整工厂应用安全。

应将以下内容纳入应用级风险评估和验证：

- **运行区域**：通道宽度、地面缺陷、坡道、交叉口、门/电梯、盲区、行人路线、消防出口和其他移动设备。
- **车辆和载荷**：车辆轮廓、转弯扫掠空间、制动能力、载荷稳定/坠落、托盘/料车突出部分、牵引连接和机械附加装置。
- **人员检测与停止**：检测设备覆盖、遮挡、人员接近方向、运行速度、系统响应时间、制动性能、停止距离、停止后保持和意外重启。
- **模式和故障**：自动/手动/维护/示教、定位失效、传感器故障、网络中断、电池低电量、驱动/制动异常、控制器重启和人工恢复权限。
- **车队和设施**：多车交叉/拥堵、死锁恢复、区域预约、门/电梯状态、输送线交接、通信故障、远程操作和配置/地图变更。
- **全生命周期**：部署、调试、运行、清障、维护、软件更新、路线/载荷/设施变更和退役。

导航用激光雷达或深度相机不一定是安全额定人员检测设备；传感器有数据输出、成本地图或碰撞停止动作，也不能证明其安全功能达到所需性能等级。必须依据安全手册、认证/性能数据、配置和系统验证确定功能边界。安全扫描仪的型号、安装高度、保护字段、反射/遮挡、响应时间及制动距离均须按现场配置验证。

## 工业移动机器人标准与互操作边界（核验日期：2026-11-04）

### ISO 3691-4 与产品范围

**ISO 3691-4:2023** 是《Industrial trucks — Safety requirements and verification — Part 4: Driverless industrial trucks and their systems》，第二版于 2023-06 发布。其范围针对 ISO 5053-1:2020 所定义的无人驾驶工业车辆及其系统，例子包括 AGV、AMR、bots、automated guided cart、tunnel tugger、under cart 等；也涵盖规定条件下的自动模式、部分手动模式和维护模式。

适用性不是只看厂商是否称产品为 AMR。ISO 官方摘要指出，该标准不适用于仅由机械方式引导（如轨道/导轨）的车辆，也不适用于不属于无人驾驶车辆定义的远程控制车辆；公共区域、公共道路、潜在爆炸环境、极端/特殊环境、军用、特定卫生要求等危险或场景也有排除边界，须识别并评估其他适用要求。标准还指出运行区域状况会显著影响安全运行，需处理运行区域相关危险。电源要求不在该标准范围内，电池/充电安全还需单独核验。

ISO/DIS 3691-4 第三版截至 2026-11-04 仍处于开发阶段，官方页面显示 2026-09-10 投票截止、当前状态为“Close of voting”。在正式发布前，它仍是草案，不能当作已发布替代版或合规声明依据；项目应记录采用的正式版、合同要求及草案变化对设计的影响。

### 美国 ANSI/A3 R15.08 系列

| 标准 | 范围摘要 | 状态/边界 |
|---|---|---|
| ANSI/A3 R15.08-1-2020 (R2026) | 工业移动机器人本体要求，强调制造商定义的指定运行环境（SOE）、迭代风险评估和传递给集成商/用户的使用信息 | 2026 版为重新确认，官方说明与 2020 原文无技术差异 |
| ANSI/A3 R15.08-2-2023 | 工业移动机器人系统和应用要求；包含 Type A/B/C 分类 | Type C 涵盖 AMR/AGV 移动底盘加机械臂的系统；项目仍需核对实际标准文本和适用范围 |
| ANSI/A3 R15.08-3-2026 | IMR 应用使用阶段的安全要求/指导 | 强调使用方风险评估、应用与当前运行环境变更管理，以及全生命周期人员安全 |

这些是美国工业移动机器人安全标准系列，不意味着所有服务机器人、消费机器人或室外公共道路设备都自动适用。OSHA Technical Manual 可作为工业机器人系统和 IMR 危险识别的技术参考，但 OSHA 明确将其定位为技术手册/指导，不能替代 OSHA 法规或适用标准的正式文本。

### 车队协议不是安全或导航标准

- **VDA 5050** 是 VDA/VDMA 发布的车队控制与移动机器人接口建议，需锁定规范版本、消息结构、通信行为和厂商兼容能力。
- **ISO 21423:2026** 面向工业移动机器人、车队管理器以及共享工业环境中的设备/应用通信互操作；标准明确不包含安全要求，也不包含导航要求。
- 协议互通不能证明车辆停止性能、人员检测、任务安全、交通无冲突或故障恢复安全。身份/权限、重复消息、通信丢失、任务状态恢复、地图/区域版本、资源预约和网络分区都要在实际系统中验证。
