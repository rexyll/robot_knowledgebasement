# 工业机器人（Industrial Robot）

> 工业机器人不是某一种固定外形的机械臂，而是面向工业自动化应用的自动控制、可重复编程、多用途操作机。按照 ISO 8373:2021 的定义，工业机器人是**可自动控制、可重新编程、多用途、可在三个或更多轴上编程，并可固定在地面或移动平台上用于工业自动化的操作机**。是否属于工业机器人，需结合定义、使用环境和标准适用范围判断，不能只看产品名称是否含“机械臂”。 

## 1. 工业机器人与相邻概念

| 概念 | 主要含义 | 与工业机器人的关系 |
|---|---|---|
| 工业机器人（Industrial Robot） | 面向工业自动化应用的多用途、可编程操作机 | ISO 8373:2021 定义的类别 |
| 工业机器人本体（Manipulator） | 连杆、关节、驱动、传动、线缆/管路与末端法兰等机械/机电部分 | 本体是工业机器人系统的重要组成部分，但不等于完整应用单元 |
| 工业机器人系统/工作单元 | 机器人本体、控制器、末端执行器、工装、工件、传感器、外围设备、安全防护和集成控制等 | 风险和性能取决于整个系统及具体任务；系统集成和使用方也承担相应责任 |
| 协作机器人（Cobot） | 面向协作应用设计或配置的机器人产品/系统类别 | 不是一种独立的运动学构型；协作安全评价对象是完整应用 |
| 服务/个人护理机器人 | 面向非工业或个人护理任务的机器人 | 不因外形类似机械臂就自动适用工业机器人标准 |

工业机器人本体可以安装在地面、倒挂、壁挂、龙门架或移动平台上。安装方式会影响可达空间、载荷方向、基础结构、线缆布置、维护和安全防护。

## 2. 按机械构型分类

IFR 基于 ISO 8373 对工业机器人常见机械构型的定义，包括直角坐标、SCARA、关节型、并联/Delta、圆柱坐标和球坐标等。

| 构型 | 典型运动副/机构特征 | 常见优势 | 典型应用 | 工程限制 |
|---|---|---|---|---|
| 直角坐标/龙门（Cartesian/Gantry） | 通常由三个相互正交的移动轴构成笛卡尔坐标系；也有增加旋转轴的配置 | 工作空间直观、结构易于模块化、长行程和负载可按龙门结构定制 | 机床上下料、码垛、板材搬运、测量/点胶 | 占地和结构支撑要求可能较大；跨梁刚度、热变形、线缆拖链和多轴同步需设计 |
| SCARA | 两个平行转动关节提供平面运动，常配合垂直移动轴及可选末端旋转轴 | 水平面内快速移动、垂直方向刚度较高，适合平面装配 | 电子装配、锁螺丝、拾放、插装 | 工作空间和姿态自由度受构型限制；偏心负载、插装力和末端方向需核对 |
| 关节型（Articulated） | 三个或更多转动关节；常见六轴，也有四/五轴或七轴冗余结构 | 可绕障碍接近工件，姿态灵活，适合多方向作业 | 弧焊、点焊、喷涂、机床上下料、装配、打磨 | 需处理奇异位形、关节限位、腕部惯量、碰撞、线缆干涉和复杂逆运动学 |
| 并联/Delta | 多条运动支链形成闭环并连接动平台；Delta 是常见并联构型之一 | 可获得较高的动态响应和较低移动部件质量 | 食品/药品/消费品高速分拣、包装、轻载拾放 | 工作空间通常受限；载荷、惯量、末端姿态和动态轨迹条件对性能影响显著 |
| 圆柱坐标 | 至少包含转动和移动关节，形成圆柱坐标特征的工作空间 | 可用于特定环绕/插入/搬运工作空间 | 专用上下料和历史/专用自动化工位 | 现代产品应用相对专门，需按实际运动范围评估 |
| 球坐标/极坐标 | 两个转动关节与一个移动关节构成极坐标特征 | 能覆盖特定球壳状区域 | 专用搬运/加工场景和历史构型 | 使用场景较专门，不能只根据“球形工作空间”简化选型 |

**注意：**
- “六轴”描述关节数量/运动自由度的一种常见配置，不等于所有关节型工业机器人都是六轴。
- Delta 的支链、轴数、末端姿态能力和负载范围取决于具体机构；不能把“10g+”或固定 picks/min 写成通用性能。
- SCARA 常见构型具有垂直移动和末端旋转轴，但具体轴数、行程与运动能力按型号确定。
- **协作机器人是应用/安全设计类别，不是与关节型、SCARA、Delta 并列的运动学构型。** 协作机器人多数采用关节型本体，但不能据此将“协作”与“六轴”画等号。

## 3. 工业机器人系统组成

完整机器人应用通常包括以下部分：

1. **机器人本体**：底座、连杆、关节、轴承、减速器/传动、伺服电机、制动器、位置反馈、末端法兰和内部线缆/气路。
2. **控制器与驱动系统**：运动控制器、伺服驱动器、电源、控制柜、制动/安全相关接口、现场总线和软件配置。不同厂商的控制柜集成程度和安全选项不同。
3. **示教与编程工具**：示教器、手动引导、离线编程、仿真、程序备份/版本管理、工艺包和维护工具。
4. **末端执行器与工艺设备**：夹爪、真空吸具、焊枪、喷枪、螺丝刀、打磨工具、测量探头或专用工装；工具和工件质量、重心、惯量和危险特性必须纳入设计。
5. **感知与过程反馈**：2D/3D 视觉、力/力矩传感器、焊缝跟踪、激光测量、接近传感器、过程质量检测和工件识别。
6. **机器人单元与外围设备**：夹具、输送线、定位台、变位机、机床、门/电梯、供气/供液、排烟、除尘和上下游自动化设备。
7. **安全防护与系统集成**：围栏/门联锁、光幕、安全扫描仪、使能装置、急停、安全控制器、速度/空间限制、安全 PLC 或其他安全功能，以及风险评估、验证和用户培训。

**机器人本体、机器人系统和生产线不是同一个安全对象。** 本体的安全设计不能代替集成商对末端工具、夹具、工件、外围设备和人员工作流程进行风险评估。

## 4. 选型要素：从任务和工件反推型号

不要先看“负载几公斤”就选择机器人。建议按以下次序梳理：

| 选型维度 | 必须明确的输入 | 为什么重要/常见误区 |
|---|---|---|
| 任务与工艺 | 搬运、焊接、喷涂、点胶、插装、打磨、检测等；节拍、质量要求、工艺窗口 | 不同工艺对速度、刚度、轨迹、过程反馈和环境保护的要求不同 |
| 负载与惯量 | 工具质量、工件最大质量、工具/工件重心、三个方向转动惯量、腕部力矩/惯量、软管/电缆外力 | 额定 payload 不是只看末端总质量；偏心和惯量可能先于质量限制触发限制 |
| 工作空间与可达性 | 机器人底座位置、工件/夹具姿态、全部任务点、工具方向、关节范围、避障路径 | 标称 reach 不是可任意姿态到达的球形区域；需检查可达性、姿态、奇异点和碰撞 |
| 轴数与姿态自由度 | 所需工具方向、绕障能力、冗余自由度、关节限位和程序可解性 | 增加轴数可能提高灵活性，但也增加规划、标定、成本和维护复杂度 |
| 精度与重复性 | 任务位置公差、方向公差、轨迹/速度要求、工艺传感器反馈 | 重复定位精度不等于绝对定位精度；标准化测试条件和实际工作姿态必须明确 |
| 动态性能与节拍 | 真实运动路径、加速度/jerk、负载、运动区、同时动作、等待和外围设备时间 | 最高轴速度、最大 TCP 速度或厂商演示循环时间不等于整线节拍 |
| 环境与安装 | IP、防尘防水、温度、清洁/洁净、腐蚀、冲击振动、地面/倒挂/壁挂/龙门安装 | IP 等级可能因本体、腕部或选项而不同；洁净等级也需依据颗粒释放、材料、润滑和清洁验证 |
| 接口与生命周期 | 控制器型号、I/O、现场总线、PLC/MES/WMS、编程生态、备件、维护能力和软件支持周期 | 设备本体之外的集成、维护、工艺包、备件和培训成本会影响全生命周期总成本 |

### 4.1 负载评估的最低检查项

应使用具体型号的官方载荷图/载荷条件，而不是仅以标称 payload 做判断：

- 工具、工件、转接板、线缆/软管和夹持附件的总质量；
- 载荷重心相对法兰的偏移距离；
- J4/J5/J6 等腕部允许的力矩和转动惯量；
- 各关节额定/允许载荷、动态动作和 duty cycle 限制；
- 焊枪、喷枪、软管、气管和电缆的外力/拖曳影响；
- 工件在夹爪内偏移、抓取失败或工装变化时的最坏情况。

超出负载图、力矩或惯量限制可能影响精度、寿命、热负荷和安全；不能靠降低程序速度来默认抵消不符合要求的机械载荷。

### 4.2 精度、重复性和 ISO 9283

- **Pose accuracy（位姿准确度）**：机器人到达指令位姿与实际位姿之间的偏差。
- **Pose repeatability（位姿重复性）**：重复执行相同指令时，实际到达位姿的离散程度。
- **Path accuracy / Path repeatability（路径准确度/重复性）**：沿规定轨迹运动时的偏差与重复性。
- **稳定时间、距离准确度、漂移等**：取决于具体试验项目和标准定义。

ISO 9283:1998 规定工业操作机器人性能特性及相关测试方法；ISO 官方页面显示该版在 2021 年复审确认继续有效。招标或验收引用 ISO 9283 时，仍要明确测试姿态、负载、速度、路径、环境、安装、测量系统和统计口径。不要把不同厂家数据表中的“重复精度”直接横向比较，也不要将该测试标准当作安全认证标准。

## 5. 工业机器人性能和型号示例：以具体 SKU 为单位

厂商产品系列通常包含不同负载、臂长、安装方式、腕部惯量和防护配置。对外比较应保留**完整型号后缀和规格书版本**。

例如 FANUC M-20iD/25 官方产品页列示：
- 最大腕部负载：25 kg；
- 最大 reach：1831 mm；
- 轴数：6；
- 重复性：±0.02 mm；
- 机械本体质量：250 kg；
- 机身保护等级/可选项与腕部/J3 手臂保护等级不同（官方页列机身 IP54/IP65 选项、腕部/J3 IP67）。

这些参数仅适用于该具体型号和官方页面配置，不能推广到整个 M-20iD 系列或其他厂商同级机器人。型号版本、订购选项和目标地区配置应以购买时的正式数据表为准。

## 6. 典型工艺与应用

| 工艺/应用 | 常见机器人构型 | 系统重点 |
|---|---|---|
| 点焊/弧焊 | 关节型、专用焊接机器人 | 焊枪/焊机、送丝/气路、焊缝跟踪、变位机、焊接烟尘和安全单元 |
| 喷涂/涂胶 | 关节型、专用喷涂机器人 | 涂料/胶路、雾化器、流量/压力、轨迹质量、通风与防爆适用性 |
| 机床上下料 | 关节型、直角坐标、SCARA | 夹爪、机床门/卡盘互锁、工件定位、切屑/冷却液环境和节拍 |
| 装配/锁螺丝 | SCARA、关节型、直角坐标 | 末端力/扭矩控制、视觉定位、供料、螺丝追溯和质量检测 |
| 高速拾放/包装 | Delta、SCARA、轻载关节型 | 视觉跟踪、输送带同步、抓取成功率、动态轨迹和卫生清洁 |
| 码垛/拆垛 | 大负载关节型、直角坐标/龙门 | 负载图、堆垛稳定性、托盘/夹具、地面和工位空间、安全区域 |
| 打磨/去毛刺/抛光 | 关节型、协作型（具体任务评估） | 刚度、力控、工具磨损、粉尘、振动、工件装夹和过程监测 |
| 检测/测量 | 关节型、直角坐标、专用测量平台 | 测量仪器校准、机器人重复性/准确度、热稳定和测量误差预算 |

## 7. 控制、编程与仿真软件

- **厂商控制器与语言**：各厂商提供专有控制器、示教/编程环境、工艺包、通信接口和安全配置。程序迁移通常需要重新验证坐标、速度、工具、负载、I/O 和安全逻辑。
- **离线编程（OLP）**：用于工位布局、可达性/碰撞检查、节拍估算、轨迹生成和程序预验证。典型厂商工具包括 ABB RobotStudio、FANUC ROBOGUIDE 等。
- **工艺软件包**：焊接、喷涂、码垛、机床上下料和测量等工艺包会绑定本体、控制器、传感器、工具和工艺参数，不应按“通用选件”描述。
- **ROS / MoveIt 2**：可用于研究、定制应用或部分工业机器人系统的规划和集成。MoveIt 2 是运动规划框架，不等于厂商安全控制器、实时伺服系统或工艺验证；驱动、控制接口、时间同步、碰撞模型和安全链需单独集成。
- **仿真不是实机验收替代品**：虚拟调试能发现可达性、碰撞、I/O 时序和节拍问题，但不能自动验证真实刚度、工具偏差、制动、工艺质量、温升或安全功能。

## 8. 产业链与全生命周期

工业机器人供应链通常包括机械加工/铸造、减速器/传动、伺服电机与驱动、编码器、控制器、线束、末端执行器、工装夹具、传感器、软件和系统集成。不同构型、负载段、生产规模和供应链策略差异很大，不能统一宣称“三大件占成本 60–70%”。

全生命周期成本应考虑：
- 本体、控制柜、示教器、线缆与安装基础；
- 末端工具、工装、传感器、外围设备和安全防护；
- 编程、工艺开发、系统集成、仿真和试生产；
- 产线停机、备件、定期维护、校准和故障响应；
- 人员培训、软件/控制器升级、工具耗材和退役。

**供应链或成本比例必须绑定数据口径、型号范围、地区、币种、批量和时间点。** 没有 BOM 或报价证据时，不给出伪精确成本拆分。

## 9. 安全、标准和应用风险

- ISO 10218-1:2025 面向工业机器人本体；ISO 10218-2:2025 面向工业机器人应用和工作单元的集成/运行等安全要求。两者需按系统边界配合使用。
- ISO 12100 提供机械危险识别、风险评估和风险降低的通用方法；具体安全功能要求需由适用产品/应用标准和风险评估确定。
- ISO 9283 是性能特性和测试方法，不是安全标准。
- ISO/TS 15066:2016 是协作工业机器人应用技术规范，协作安全须按具体应用评估；不能把普通工业机器人配置成低速或装力矩传感器就自动称为协作安全系统。
- 美国工作场所应核对 OSHA 法规及相应 ANSI/RIA 标准；OSHA 技术手册和标准组织文件不能直接互换。
- 危险可能来自本体运动、工具、工件、夹具、焊接/喷涂过程、能源、外围设备和维护/示教模式；完整单元应由具备资质的专业人员进行风险评估与验证。
