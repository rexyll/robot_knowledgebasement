# 清洁机器人

> 清洁机器人是按清洁任务划分的产品/应用类别，既包括家用地面清洁产品，也包括商用清扫、洗地、尘推和吸尘设备。是否属于机器人、服务机器人或其他设备，应结合自主能力、预期用途和适用标准判断；不能仅凭“自动”或“无人驾驶”营销名称归类。

## 1. 分类与应用边界

### 1.1 家用与商用

| 维度 | 家用清洁产品 | 商用/专业清洁设备 |
|---|---|---|
| 典型场所 | 住宅、公寓和家庭庭院 | 商场、机场、医院、学校、仓库、工厂和办公场所 |
| 主要任务 | 吸尘、扫地、拖地、擦窗、草坪维护 | 洗地、尘推、扫吸、地毯清洁、区域清扫 |
| 运行方式 | 用户设置后自动运行，部分任务由用户监督 | 专业操作人员配置/监管，部分产品支持自主路线和远程管理 |
| 关键约束 | 家具/地毯/门槛、宠物、家庭隐私、噪声和维护 | 人员混行、湿滑地面、障碍物、清洁剂/污水、班次和设施运营 |
| 系统形态 | 小型移动平台、清洁机构、充电/清洁基站 | 手推式、驾驶式或自主移动设备；可能带补水、排污和车队管理设施 |

家用与商用是应用市场划分，不是单一技术分类。商用清洁设备中既有具备自主导航的机器人，也有需要人员驾驶或操作的设备；不应把所有商用洗地机都称为自主机器人。

### 1.2 按清洁机理分类

- **吸尘/干式清洁**：风机、尘盒/过滤器、滚刷或边刷；关注颗粒拾取、过滤、缠绕和尘盒维护。
- **扫地/尘推**：边刷、主刷或尘推组件；关注垃圾收集、扬尘控制、边角覆盖和耗材寿命。
- **洗地/湿式清洁**：清水供给、刷盘/滚刷、吸水扒、污水回收；关注水量、刷压、地面材质、污水回收和湿滑风险。
- **地毯/织物清洁**：喷液、刷洗、抽吸或干式处理；需明确适用织物、干燥时间和清洁剂兼容性。
- **擦窗/立面清洁**：吸附/保持机构、运动机构和防坠措施；其安全风险与地面移动设备显著不同。
- **草坪/户外清洁**：户外定位、边界识别、天气/地形和刀具/抛射物风险；不能直接复用室内清洁的安全假设。

## 2. 市场统计口径

IFR World Robotics 2026 的公开摘要称，2025 年消费服务机器人出货量接近 **3,420 万台**，同比增长 **37%**。IFR 同时说明，消费服务机器人主要面向大众市场，家用任务机器人（例如地面清洁、草坪维护）是其中重要组成部分。

该数字是**消费服务机器人总量**，不是扫地机器人单品销量，也不是清洁机器人全部市场规模。不能据此推导扫地机出货量、商用清洁机器人规模或某个品牌份额。IFR 服务机器人报告采用供应商调查和公开资料，年度样本构成可能变化；跨年度比较必须保留报告版本、统计类别和样本限制。

## 3. 系统组成与工程架构

清洁机器人需要把移动平台、清洁机构和清洁任务结合起来。常见子系统如下：

1. **移动平台**：驱动轮、转向/制动、悬架、底盘结构和防护；车型可能是差速、舵轮或其他构型，不能预设所有产品均为差速底盘。
2. **清洁机构**：主刷/边刷、刷盘/滚刷、吸水扒、风机、过滤器、清水箱/污水箱、泵阀和管路。不同清洁机理的机构不可简单互换。
3. **感知与安全**：激光雷达、相机、深度传感器、超声波、触边/防撞、跌落/悬崖检测、急停和状态指示。传感器配置应由环境和风险分析决定。
4. **定位与导航**：地图构建、定位、路径规划、覆盖规划、动态障碍处理和恢复策略。定位系统负责导航，不自动构成安全保护功能。
5. **任务管理**：区域/路线、清洁模式、清洁剂和水量策略、耗材/水箱状态、异常处理、任务暂停与人工接管。
6. **能源与补给**：电池、充电器、自动回充；部分商用系统另有自动补水、排污、刷具冲洗或耗材更换设施。
7. **运维与车队**：设备注册、地图/配置版本、任务调度、清洁报告、告警、远程诊断、OTA、权限和审计。

系统设计要同时考虑“机器人是否能走到目标区域”和“目标区域是否真正完成了规定的清洁作业”。导航覆盖面积不等于有效清洁面积。

## 4. 清洁覆盖与路径规划

清洁任务通常属于覆盖路径规划（Coverage Path Planning, CPP），与点到点导航不同。常见方法包括：

- **往复式条带覆盖**：适用于边界较规则、障碍较少的区域；需处理转弯空间、重叠和边界漏扫。
- **单元分解**：将复杂区域分成可覆盖子区域，再为子区域生成覆盖路径；适用于非凸空间和障碍分割。
- **区域/任务分配**：多机器人或多班次场景下，将区域按面积、清洁类型、通行限制、补给点和任务优先级分配。
- **路径连接与重规划**：覆盖路径需连接到充电/补水点、任务起点和异常恢复点；遇到动态障碍或临时封闭区域时应能安全暂停或重规划。

行距不能机械地设为清洁宽度的固定比例。有效作业宽度会受刷具磨损、速度、重叠策略、地面边缘、转弯和清洁效果影响。规划参数应通过具体设备的作业宽度、现场试验和验收标准确定。

### 4.1 地图与场景建模

建图时除几何障碍外，还应标注：
- 禁入区、临时封闭区、地面材质和清洁方式分区；
- 斜坡、门槛、伸缩缝、地漏、地毯、排水沟和易积水区域；
- 玻璃/镜面、低矮障碍、悬空桌面、线缆和反光/透明隔断；
- 人流时段、清洁窗口、门禁、电梯、补给站和人工通道；
- 地图版本、现场变更审批和回滚策略。

玻璃/镜面或黑色吸光材料对特定传感器可能形成感知困难，但不能笼统断言“LiDAR 会穿透玻璃”。应按传感器波长、入射角、玻璃结构、环境光和安装方式验证，并采用适当的多传感器冗余与现场标记。

## 5. 清洁效果与性能验收

不采用跨品牌通用的清洁效率、有效覆盖率、定位精度、越障高度、爬坡能力、噪声或续航“典型值”。厂商的理论覆盖面积、单箱覆盖面积、最大速度和实验室效率不是同一指标。

| 指标 | 推荐定义/测量方法 | 必须控制的条件 |
|---|---|---|
| 清洁效果 | 预设污染物/污渍的去除率或等级变化 | 污染物类型、用量、附着时间、地面材质、清洁剂 |
| 有效清洁覆盖 | 满足清洁质量要求的实际面积 / 目标面积 | 重复覆盖、漏扫、边角、障碍、作业速度和清洁模式 |
| 单位时间产能 | 合格清洁面积 / 实际作业时间 | 转弯、补水、排污、充电、等待、人工介入是否计入 |
| 水/清洁剂消耗 | 单位合格面积的用水/药剂量 | 稀释比例、污水回收、地面材质、污染程度 |
| 导航与覆盖完整性 | 路线完成、漏区、重复区、异常恢复 | 地图版本、人流、动态障碍和传感器配置 |
| 地面干燥/残留 | 清洁后残水、条纹、残留污物或滑倒风险 | 地面材质、温湿度、刮水条状态和检测方法 |
| 可用性与维护 | 任务可用率、故障间隔、清洁/维护时间 | 运行小时、班次、维护计划、耗材和故障分类 |
| 人员安全 | 危险场景测试、停止性能、保护功能响应 | 风险分析、测试布置、载荷、速度和测量设备 |

验收应区分导航成功、任务完成、清洁质量合格和安全功能通过。建议在代表性现场按班次和污染等级抽样，记录原始照片/视频、测量数据、地图版本、设备配置、操作员介入和失败任务，不用单一“覆盖率 KPI”代替清洁质量。

## 7. 安全与标准适用性

清洁设备的危险不仅来自移动底盘，还来自刷具、吸水扒、风机、液体、清洁剂、电池、充电和湿滑地面。至少识别：
- 车辆碰撞、夹挤、碾压、倒车和盲区；
- 刷具卷入、旋转部件接触、飞溅和维护时意外启动；
- 清水/污水泄漏、地面湿滑、清洁剂暴露和化学品不相容；
- 坡道、门槛、地漏、楼梯边缘、货梯/电梯和装卸运输；
- 电池/充电故障、进水、过温、短路和电气维护；
- 人员/动物检测失效、定位丢失、网络中断和人工接管失败。

标准适用性必须按设备用途和结构判断：
- **IEC 60335-2-10**：家用地面处理器具的相关安全要求；需核对具体产品范围和配套 IEC 60335-1 版本。
- **IEC 60335-2-72:2021**：商用乘驾式/步行操纵式地面处理机器，覆盖其范围内的扫地、洗地、湿/干式拾取、抛光等作业；标准明确排除若干其他设备类别。
- **IEC 60335-2-67:2021**：商用地面处理机器中清洁运动以横向或周期性为主、且不带牵引驱动的设备；与 -2-72 的范围需区分。
- **IEC 60335-2-68 / -2-69**：分别涉及特定商用喷抽清洁机和商用湿/干式吸尘器，不能因为设备名称包含“清洁”就忽略产品类别差异。
- **ISO/FDIS 13482（第 2 版）**：截至 2026-11-04，ISO 页面标示为 Final Draft International Standard、仍在批准流程、尚属制定中；其范围涉及个人及专业/商业服务机器人，不应将 FDIS 写成已发布的正式版本。

上述标准不是完整法规清单，也不自动覆盖机器人自主导航、现场集成、无线/EMC、网络安全、隐私、化学品或工作场所风险。具体市场和产品还需逐项确认国家/地区采用版本、适用法规、风险评估和认证路径。

## 8. 选型与部署流程

1. **定义任务**：清洁对象、污渍类型、面积、地面材质、清洁质量、班次、服务窗口和人工流程。
2. **现场勘察**：测量通道/门宽、坡度、门槛、地漏、玻璃隔断、充电/补水/排污位置、网络和人流。
3. **选择清洁机理**：吸尘、扫地、尘推、洗地或组合式；验证刷具、清洁剂、过滤、污水回收和地面兼容性。
4. **选择平台与导航**：按通行能力、转弯空间、传感器、地图维护、障碍处理和安全功能选择，不先验认定某一种 SLAM 或底盘适合所有场景。
5. **建立需求追踪与 DVP&R**：每项任务/安全需求对应验证方法、工况、设备、通过准则和责任人。
6. **试点部署**：在受控区域验证清洁质量、导航、人员共处、补给、维护和异常恢复，再按风险评估扩大运行范围。
7. **运营评估**：按合格清洁面积、任务完成率、人工干预、耗材、水/药剂、维护、停机和部署成本评估全生命周期经济性。
8. **持续运维**：管理地图/软件/配置、刷具/刮水条/过滤器耗材、清洁剂、污水处理、培训、故障工单和退役。
