# 清洁机器人

> [[移动机器人]]在清洁卫生场景的垂直大类。分**家用**（扫地机器人，全球年出货 1500 万+台）与**商用**（商场/写字楼/机场洗地尘推，单价 5-30 万，高仙为代表）两条线。

## 家用 vs 商用对比

| 维度 | 家用扫地机 | 商用清洁机器人 |
|---|---|---|
| 导航 | [[视觉SLAM]](VSLAM) 或 dToF [[激光雷达]] | 2D/3D [[激光SLAM]] + [[深度相机]]多传感器 |
| 底盘 | 差速双轮+万向轮 | 差速/阿克曼/舵轮 → [[底盘与运动机构]] |
| 清洁模块 | 滚刷+边刷+拖布自清洁 | 洗地(滚刷+吸水扒)/尘推/扫吸、水箱 15-70L |
| 续航 | 3000-6400mAh，120-180min | LFP 48V/30Ah 级，4-6h → [[电池与电源]] |
| 关键难点 | 缠毛、越障(2-4cm)、地毯识别 | 人流混行、玻璃门/扶梯识别、长直走廊效率 |
| 生态 | App+基站（自集尘/自清洗/上下水） | [[调度系统RMS]] 多机+楼层管理 |

## 商用清洁机的核心子系统

1. **清洁系统**：清水箱/污水箱分离、滚刷压力可调（20-40kg 下压力）、吸水扒真空度
2. **导航定位**：[[激光SLAM]] + [[视觉感知算法]]（地面污渍/行人/玻璃检测）→ [[导航流程]]
3. **回充与上下水**：自动回充[[充电桩与自动充电]]、自动补水排污站
4. **业务状态机**：清扫→回充→休息→故障 的 FSM → [[项目-清洁机器人]] 的 fsm_core 实例
5. **云平台**：工单调度、清洁覆盖率报告、视频远程接管 → [[云平台与IoT通信]]

## 核心参数（商用典型值）

| 参数 | 典型值 | 说明 |
|---|---|---|
| 清洁效率 | 1500-3000 m²/h | 理论值，实际有效覆盖率 85-95% |
| 工作宽度 | 550-1050mm | 滚刷/扒宽 |
| 行走速度 | 0.7-1.5 m/s | 人多场景自动降速 |
| 越障 | 15-25mm 减速带 | 商场常见卡点 |
| 爬坡 | ≤8% | 连接通道 |
| 定位精度 | ±5-10cm（清洁场景要求低） | 低于工业搬运 |
| 噪音 | <65 dB | 营业时间工作要求 |
| 覆盖率 | ≥95% | 验收核心指标 |

## 关键技术难点

- 地面材质识别与水量联动 → [[视觉感知算法]]
- 玻璃/镜面误识别（LiDAR 穿透）→ 多传感器融合 → [[多传感器融合定位]]
- 人群密集环境的路径覆盖算法（弓字形+区域分割）→ [[路径规划算法]] 的全覆盖规划（Boustrophedon、细胞分解）
- 污渍识别补清 → [[学习型机器人算法]]（小样本检测）

## 细节加深（V2）
- **代表机型参数快照**（台账调研批 2026-11）：高仙 Scrubber 50（清宽 ~460mm，500-1200 m²/h，1.0m/s，自动加排水/乘梯）、Scrubber 75 车库款（75cm/75L，20+ 传感器）；科沃斯 K1 VAC（42cm/20kPa/10L/4h）——注意厂商标"清洁效率"是理论值，**验收写有效覆盖率 ≥95%**（合同口径，→ [[性能指标体系]]）。
- **全覆盖三件套**：Boustrophedon 细胞分解 + 区段 TSP 排序 + 行距=清洁宽度×0.9——[[项目-清洁机器人]] 的 BoustrophedonDiffPlanner/AckermannCoveragePlanner 即此结构（可读其 Algorithm/robot_algorithms 源码）。
