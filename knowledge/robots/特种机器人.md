# 特种机器人

> “特种机器人”在工程实践中通常是面向特殊任务、危险环境或人类难以进入区域的应用集合，不是由某一种运动机构、控制算法或单一国际标准定义的独立机器人构型。它可以是地面履带/轮式平台、足式平台、水下航行器、无人机、机械臂或固定操作单元。分类应同时记录任务、环境、平台形态、操控方式和监管约束。

## 1. 定义与分类边界

### 1.1 应用集合，而非单一构型

特种机器人通常用于减少人员暴露于危险、受限、远距离或不可达环境中的需求，典型目标包括远程观察、采样、搬运、处置、检测、维护和应急响应。其价值不能仅用“代替人”概括：有些系统用于扩展人员感知，有些用于远程操纵工具，有些承担有限自主任务；是否能完全无人化取决于任务风险、通信条件、环境可观测性和监管要求。

ISO 8373:2021 是当前已发布的机器人术语标准。ISO/DIS 8373 第四版在 2026 年处于国际标准草案征询阶段，计划替代 2021 版，但草案不是已发布的正式标准。编写和采购文件应记录采用的标准版本，不要把草案内容写成已生效要求。

### 1.2 按任务与环境分类

| 应用类别 | 典型任务 | 常见平台/工具 | 关键工程约束 |
|---|---|---|---|
| 应急响应与城市搜救 | 火场侦察、结构坍塌搜索、危险品现场观察、灾害评估 | 遥操作地面机器人、小型空中/水面/水下平台、操作臂 | 烟尘、热、碎石、积水、无线链路衰减、部署时间、操作者负荷 |
| 排爆与危险物处置 | 远程观察、搬运或操纵危险物、隔离区域检查 | 履带/轮式遥操作平台、机械臂、专用末端工具 | 安全距离、视野、操作精细度、链路可靠性、失效后安全状态 |
| 能源与工业巡检 | 变电站、油气设施、化工装置、管廊、风电/光伏巡检 | 轮式/足式平台、无人机、固定巡检单元 | 危险区域分区、气体/粉尘、温湿度、腐蚀、设备兼容性和现场许可 |
| 核设施与辐射环境 | 远程观察、测量、取样、维护辅助和退役作业 | 抗辐照传感器/电子单元、遥操作平台、机械臂 | 累积剂量、屏蔽、材料老化、电子器件退化、远程维护和废物管理 |
| 矿山与地下空间 | 巷道巡检、测绘、设备检查、危险区域侦察 | 防爆移动平台、遥操作设备、无人机/测绘载体 | 瓦斯/粉尘、通风、定位拒止、通信覆盖、地形和救援条件 |
| 水下与海洋工程 | 海底观测、结构检查、测绘、取样和工具操作 | ROV、AUV、滑翔机和水下机械臂 | 水压、腐蚀、生物附着、浑浊度、声学通信、导航和回收 |
| 空间与行星探测 | 舱内/舱外操作、表面巡视、采样和设备维护 | 机械臂、自由飞行机器人、巡视器 | 真空、辐射、热循环、通信时延、低重力/地形、有限能源和高维修成本 |
| 建筑及其他极端环境作业 | 高处检查、危险结构测量、特殊材料处理 | 无人机、爬壁/吸附平台、移动机械臂 | 坠落风险、附着可靠性、粉尘、结构变化和人员隔离 |

此表是应用导航，不是穷尽分类。相同任务可能有不同平台；相同平台也可能服务不同任务。应避免以厂商名称或单一运动形式代替任务定义。

### 1.3 与相邻类型的边界

- **移动机器人/AMR：** 移动是平台能力；特种任务可能使用移动平台，但更关注极端环境、任务工具、通信、可维护性和任务风险。参见 [[移动机器人]]。
- **足式机器人与无人机：** 它们是运动/平台形态；进入巡检、搜救或危险环境时可成为特种应用的载体。参见 [[足式与无人机]]。
- **工业机器人：** 工业机器人按工业自动化任务和定义划分；“特种”描述应用环境或任务，并不自动让设备脱离工业机器人/机械安全要求。
- **服务/医疗机器人：** 按预期用途和对象另行分类。医院、消防或公共空间内使用，并不能仅凭场所决定其产品类别。
- **遥操作设备：** 遥操作是一种控制方式，不等同于自主机器人。必须如实说明人类操作者参与程度、远程链路依赖和失联行为。

## 2. 操控方式与自主能力

不建议使用“全遥操作—半自主—全自主”作为未经定义的统一成熟度等级。项目应将可执行功能和人类责任拆开描述：

| 模式 | 人员职责 | 机器人能力 | 需要明确的边界 |
|---|---|---|---|
| 直接遥操作 | 操作者持续发出运动/工具指令并观察反馈 | 执行低层运动和工具动作 | 延迟、视频盲区、操纵器映射、急停/安全停止和链路中断 |
| 辅助遥操作 | 操作者负责任务，系统提供稳定、限位或局部避障等辅助 | 在授权范围内抑制部分危险动作 | 辅助功能的权限、失效检测、可覆盖范围和提示 |
| 监督自主 | 操作者分配目标、批准关键步骤并处理异常 | 在限定区域和任务条件内自主执行子任务 | ODD、任务授权、接管触发、恢复策略和审计记录 |
| 自主任务执行 | 操作者负责任务批准、监控和异常处置 | 在经验证的边界内闭环执行任务 | 自主能力证据、异常退出条件、通信丢失策略和责任分配 |

模式切换应是可观察、可记录、可验证的系统状态，不使用含糊的“半自主”作为验收术语。任何自动避障、稳定控制或工具限位功能都不能在未经风险分析和验证时被宣称为安全功能。

## 3. 典型系统架构与环境适应

特种机器人没有统一硬件栈。常见设计维度包括：

1. **平台与运动机构**：轮式、履带、足式、飞行、水下推进、爬壁、固定操作臂或混合构型。平台选择由地面/介质、障碍、转弯空间、载荷、回收方式和维护条件决定。
2. **任务载荷与末端工具**：可见光/热成像相机、声学/雷达/激光传感器、气体或辐射测量仪器、采样器、夹爪、切割/操作工具等。每种载荷都要核对质量、惯量、供电、数据接口、环境额定值和任务适用性。
3. **感知与定位**：GNSS、惯性、视觉、激光、声呐、里程计、环境标志和多传感器融合。地下、水下、室内、强烟尘和空间环境可能失去部分常规定位条件，必须设计可观测性退化和定位失效检测。
4. **通信与操作者界面**：无线电、专用网络、光纤/脐带缆、水声链路或中继通信。通信系统应验证时延、抖动、丢包、遮挡、干扰、链路安全和失联策略；控制数据与视频/传感数据应分别评估带宽和优先级。
5. **能源与热管理**：电池、系留供电、外部电源、液压/气动或混合能源。需要明确环境温度、持续功率、峰值功率、热路径、充电/换电和任务回收策略。
6. **环境防护与材料**：防水防尘、腐蚀、冲击、振动、热、低温、辐射、压力和化学介质兼容性。IP 等级描述特定外壳防护试验条件，不能代替防爆、耐辐射、耐腐蚀或整机任务适用性证明。
7. **故障管理与恢复**：本地安全状态、远程急停/安全停止、看门狗、故障日志、任务中断、定位/通信/能源异常处理、拖救/回收接口和维护程序。

### 3.1 防爆与危险区域适用性

“防爆”不是一个可跨产品通用的标签。危险区域设备需要先识别气体/粉尘类型、区域/设备类别、温度组别、设备保护级别、环境温度、安装条件和适用法规，再核对具体设备的标志、证书、附表和使用条件。

- 欧盟 ATEX 设备指令 2014/34/EU 适用于拟用于潜在爆炸性环境的设备和保护系统，也涉及用于设备安全功能的相关安全/控制装置及组件；工作场所风险和设备使用还涉及其他法规，不能只看产品证书。
- IECEx 是基于 IEC 标准的国际合格评定/认证体系，不等同于某一国家或地区的法规。IECEx 证书应核对证书持有人、型号、保护型式、标志、标准版本、特殊使用条件和证书状态。
- 一个部件有防爆证书，不代表装入机器人整机后整机自动获得相同认证。整机集成、线缆/连接器、载荷、热表面、软件控制的保护机制和制造变更都可能影响认证适用性；必须以整机证书和认证文件中的范围/条件为准。
- IP 防护等级、防水防尘能力和防爆认证解决不同问题，不能相互替代。

### 3.2 证书状态、组件证书与整机配置的逐项核验

证书核验不应只搜索到一个 PDF 就结束。至少核对：证书编号与签发机构/ExCB、证书持有人、制造场所、准确型号/系列、设备组别与类别、保护型式、EPL/气体组别/温度组别、环境温度范围、标准及版次、证书状态、特殊使用条件（“X”）和证书附表/附件。对 IECEx，需查询当前证书数据库，并同时检查有效、暂停、撤销等状态及变更记录；不能用厂商旧版宣传页替代当前证书记录。

**组件证书不是整机证书。** IECEx 的 Ex Component 是不打算单独使用、并且集成到防爆设备或系统后仍需进一步认证的部件/模块。即使电机、连接器、传感器或电池组件持有组件证书，也不能据此宣称机器人整机已获防爆认证。应取得整机适用证书/评估文件，核对认证配置、安装条件、线缆/接口、载荷、热表面、软件保护相关条件和任何特殊使用限制。发生设计、材料、固件或供应链变更时，应按证书规则向认证机构确认是否需要证书更新或重新评估。

ATEX 2014/34/EU 的适用对象包括潜在爆炸性环境用设备与保护系统、与爆炸风险安全功能相关的安全/控制/调节装置，以及拟纳入上述设备/系统的组件。使用时需同时核对目标成员国转置法规、设备分类、符合性评估路径和使用场所要求；ATEX 产品符合性不等于现场风险评估、工作场所防爆分区或作业许可已经完成。检索法规应使用 EUR-Lex 当前合并文本及修订记录，而不是只引用 2014 年原始刊载文本。

## 4. 任务导向测试与能力评估

特种机器人不能只用“最大速度、负载或续航”做排名。应从任务拆解为可重复测试的基础能力，再组合成任务剖面。

NIST 的应急响应机器人测试工作将能力拆分为机动性、移动能力、灵巧操作、感知、续航、无线通信、耐久性、可靠性、自主能力、后勤和安全等维度；相关方法由 ASTM 应急响应机器人工作组发展。ASTM E2521-26 是当前有效的应急响应机器人能力评估术语标准，覆盖地面、水上/水下和空中系统；具体能力测试方法各有独立编号和版次，必须逐项核对。此类测试方法定义测量能力的过程和指标，并不替特定消防、排爆或搜救机构规定所有任务的统一合格阈值；用户组织需根据任务风险和现场需求设定通过准则。

| 测试维度 | 示例测试问题 | 应记录的条件 |
|---|---|---|
| 机动与通过性 | 能否跨越指定障碍、通过狭窄空间、在坡面稳定运动 | 障碍几何、表面材质、湿/干状态、载荷、速度和重复次数 |
| 操作与灵巧性 | 能否观察、抓取、旋拧、开门或操纵指定工具 | 工具、目标尺寸/形状、可见性、操作者经验和完成判据 |
| 感知能力 | 能否在烟尘、弱光、浑浊或遮挡条件下检测目标 | 目标、距离、环境变量、误报/漏报定义和样本量 |
| 通信能力 | 链路衰减、非视距、遮挡和干扰下能否维持所需控制/反馈 | 频段、天线、拓扑、衰减、时延、丢包和安全策略 |
| 耐久与环境适应 | 任务周期中是否发生热、进水、腐蚀、振动或机械故障 | 温度、湿度、压力、冲击谱、运行时间和检验方法 |
| 续航与后勤 | 能否完成任务并安全返回、回收或更换能源 | 任务载荷、环境、能源状态、待机时间和回收方式 |
| 操作者能力 | 人员能否在规定训练下完成任务并识别异常 | 培训时长、界面配置、任务复杂度、操作错误和工作负荷 |
| 安全与恢复 | 失联、传感器异常、卡困或能源不足时系统如何进入安全状态 | 故障注入方式、独立保护、恢复程序和记录 |

每个测试项目应包含设备 SKU/配置、软件/固件版本、测试装置、步骤、仪器校准、环境、原始数据、统计方法、通过准则和偏差。不能把某次演示或竞赛结果泛化成全部工况能力。

### 4.1 标准化测试方法不是统一的任务合格阈值

NIST 的应急响应机器人项目把任务分解为可重复的基础测试，例如机动、通过性、灵巧操作、感知、续航、无线通信、耐久、可靠性、自主能力、后勤、安全和操作者熟练度。测试装置、步骤和指标用于形成可比较的数据；NIST 明确说明，测试方法本身不规定某个消防、排爆或搜救组织必须达到的统一通过阈值。采购方/任务组织必须把 ODD、任务风险和任务剖面映射为所选测试组合及自身的验收门槛，并保存重复试验、统计置信度、操作者训练和配置基线。

标准版本也要逐项区分：截至 2026-11-05，ASTM E2521-26 是“应急响应机器人能力评估术语”当前有效版，适用于地面、水上/水下和空中系统；NIST 网页列出的若干具体测试方法版本可能仍是较早版本（例如其列表中的 E2521M-23），不能因此把 E2521-26 误读为替代所有具体测试方法。每项测试方法都应独立核对 ASTM 当前有效版本、适用平台、测试装置和测量指标。

产品选型资料至少应记录：

- 任务载荷及安装配置、机械/电气/通信接口；
- 适用环境边界与整机证书/检测报告；

- 证据等级：官方规格、证书/报告、独立测试、客户现场运行或尚待确认。

营销页面上的“工业级”“军工级”“防爆”“全自主”等描述不能替代具体证据。

## 6. 安全、法规与责任边界

特种机器人往往进入人员无法安全进入的区域，但机器人本身也可能成为新的危险源。风险分析必须覆盖机器人、任务工具、远程操作者、现场人员、设施和应急处置流程。

至少审查：
- 机械碰撞、夹挤、倾覆、卡困、工具误动作和载荷脱落；
- 火焰、高温、爆炸性气氛、毒害/腐蚀介质、辐射、压力和电气危险；
- 无线/系留链路中断、控制延迟、视频失真、定位漂移和网络攻击；
- 电池热失控、供电中断、回收失败和维护时意外启动；
- 操作者工作负荷、视角盲区、训练不足、模式混淆和人工接管失败；
- 任务执行后污染物、样品、废物或设备的回收、隔离和去污。

标准适用性必须逐产品和市场判断：
- ISO 8373 用于机器人术语；截至 2026-11-04，ISO/DIS 8373 第四版截至 2026-11-05 仍处于 enquiry 阶段（40.60，投票关闭后的处理阶段），不能替代已发布的 ISO 8373:2021 或法规。
- ISO 10218-2:2025 针对工业机器人应用与机器人单元集成；其范围明确排除水下、执法/军事、空中/空间、医疗/健康服务、服务机器人以及若干特殊环境和危险材料应用。不能把它当作全部特种机器人统一安全标准。
- ASTM E2521-26 与相关 E54.09 测试方法用于应急响应机器人能力术语/测试，不是产品安全认证或所有任务的通用合格阈值；采购方应逐项确认具体测试方法的现行版和任务阈值。
- ATEX/IECEx 仅在潜在爆炸性环境适用，且需按目标市场和准确产品证书审查。
- 水下、矿山、核设施、航空/无人机和空间任务分别可能涉及专门法规、标准、运行许可或任务方要求，须按地区、设施和任务逐项建立合规矩阵。

本页不是法律/认证意见，也不构成危险环境作业许可。部署前必须由具备相应资质和现场授权的人员完成风险评估、作业程序、培训和验收。

## 7. 选型与部署流程

1. **定义任务与退出条件**：描述要观察/操作/搬运/测量的目标、成功标准、禁止事项、失败处置和任务结束后的回收方式。
2. **确定环境与运行边界**：绘制危险区域、介质、温度/压力/辐射、地形、通信覆盖、人员位置和可回收路径。
3. **选择平台和操控模式**：比较地面、足式、空中、水下、固定操作臂和混合平台；确定远程操作、辅助遥操作或监督自主的权限与责任。
4. **选择载荷和接口**：核对质量、惯量、供电、数据链路、安装、标定、环境等级和对平台稳定性的影响。
5. **建立任务剖面和 DVP&R**：将移动、操作、感知、通信、能源、环境适应、人员能力和安全恢复映射到可重复测试。
6. **开展受控试验和现场演练**：先验证失联/故障/回收，再逐步接近真实任务条件；不得在无授权或无保护措施的危险现场试验。
7. **评估运维与全生命周期**：核算设备准备、运输、部署、操作员培训、去污、维护、备件、回收和退役成本。
8. **闭环复盘**：将故障、近失事件、任务限制和测试差异写入配置基线、操作程序和下一版本验证计划。
