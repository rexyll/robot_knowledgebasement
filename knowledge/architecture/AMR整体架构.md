# AMR 整体架构

> 一台/一支 AMR 车队的系统模板：四层车端 + 一层云 + 一层现场设施。本库两个内部项目（[[项目-amr]] · [[项目-清洁机器人]]）都是该模板的具体实例。

## 全景架构图

```
┌─────────────────── 云端层 ───────────────────┐
│ [[调度系统RMS]] · 业务系统(工单/报表) · [[云平台与IoT通信]](MQTT/HTTP) · OTA 服务 │
└──────△──────────────────────△───────────────┘
       │ 4G/5G/WiFi             │ 任务/指令 ↓ 遥测/事件 ↑
┌──────┴────────── 车端应用层 ───┴───────────────┐
│ HMI(App/Web/触摸屏) · 业务状态机(FSM: 任务/回充/暂停) · 能力插件框架([[项目-amr]]) │
├──────────────── 车端决策层 ────────────────────┤
│ 导航栈: 定位([[多传感器融合定位]]) → 规划([[路径规划算法]]/[[局部规划与避障]]) │
│ 感知: [[视觉感知算法]] · 障碍融合 · 安全监控(软层) │
├──────────────── 车端实时层(MCU) ───────────────┤
│ 底盘控制([[底盘与运动机构]] 运动学+PID) · [[电机与驱动器]] FOC · 安全链([[安全防护器件]]) │
├──────────────── 感知硬件层 ────────────────────┤
│ [[激光雷达]] · [[深度相机]] · [[IMU]] · [[编码器与里程计]] · [[毫米波雷达与超声波]] · [[电池与电源]]/BMS │
└───────────────────────────────────────────────┘
┌─────── 现场设施 ───────┐
│ [[充电桩与自动充电]] · 电梯/门禁 IoT · 反光板/二维码(可选) │
└────────────────────────┘
```

## 五条关键数据流（贯穿全栈）

| 流 | 路径 | 频率 | 协议/载体 |
|---|---|---|---|
| 感知流 | LiDAR/相机 → 感知节点 → costmap/障碍列表 | 10-30Hz | ROS2 Topic（→ [[ROS与ROS2]]） |
| 控制流 | 规划控制 → Twist → MCU → FOC | 20Hz→1kHz→20kHz | Topic→串口/CAN（→ [[实时系统与嵌入式]]） |
| 状态流 | 各节点状态 → FSM → HMI 显示 | 1-10Hz | Topic/内部总线 |
| 云流 | 遥测↑ 指令↓ OTA↓ | 0.1-5Hz | MQTT/HTTP（→ [[云平台与IoT通信]]） |
| 安全流 | 触边/急停 → 硬件断路（旁路软件） | 事件 | 硬线（→ [[功能安全体系]]） |

## 软件架构风格演进（本库项目佐证）

| 风格 | 描述 | 代表 |
|---|---|---|
| 单体 ROS 节点堆 | 所有功能平铺成节点 | 早期 ROS1 项目 |
| **能力插件化（Capability）** | 功能=注册的插件（IDL 契约+发现+调度+容错） | [[项目-amr]] 重构方向 |
| 分层 FSM | 业务状态机独立成核心库 | [[项目-清洁机器人]] fsm_core |
| 框架+插件（视觉域） | 设备/算法插件注册 | [[项目-Bozlin视觉框架]] |

> 共同趋势：**接口契约先行 + 插件注册发现 + 独立可测**——机器人软件正在向汽车 SOA（面向服务架构）靠拢。

## 部署拓扑（车队级）

```
云端(公网) ── 站点网关(NAT/防火墙) ── 车队局域网(5G CPE/AP)
  ├─ 车×N (ROS2 + MCU)
  ├─ [[充电桩与自动充电]]×M (CAN→网关→云)
  ├─ 电梯控制器对接盒 (IoT)
  └─ 调度边缘节点(可选, 弱网兜底) → [[调度系统RMS]]
```

- 弱网设计：车端具备"断网自治"（本地 FSM 继续、任务缓存、恢复上报）
- 时钟：全网 NTP，云车时差 <100ms（轨迹与事件对齐）

## 故障域划分（架构设计的灵魂）

| 故障域 | 隔离手段 |
|---|---|
| 单节点崩溃 | 进程隔离 + supervisor 重启 + 状态恢复 |
| 感知失效 | 多源冗余 + 失效检测（协方差监控）→ [[多传感器融合定位]] |
| 通信失效 | 心跳+超时+本地自治 |
| 动力失效 | BMS 保护+安全停 → [[电池与电源]] |
| 云失效 | 断网自治模式（最大能力：完成当前任务→安全停靠） |
