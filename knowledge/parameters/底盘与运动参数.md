## 经验公式

```
1. 制动距离: d = v²/(2a)  → 1.5m/s, a=1.5m/s² → 0.75m (安全保护区下限依据)
2. 安全距离(ISO 3691-4): S = v·t + v²/(2a) + 余量 (t≈0.3-0.6s 全链路)
3. 续航: T = E_batt·η / P_avg  (η≈0.7 实际工况折损)
   例: 48V·30Ah=1440Wh, P_avg=125W, η=0.75 → 8.6h
4. 充电配比: 桩数 ≈ 车队/8 (机会充电) 或 /12(夜间集中充)
5. 阿克曼转弯: R_min = L/tan(δ_max)  L=1m, δ_max=45° → R≈1m
6. 差速原地旋转速度: ω_max = (v_r−v_l)/W
```

## 精度分级参考（什么任务要什么精度）

| 任务 | 需求精度 | 手段 |
|---|---|---|
| 走廊行驶 | ±20cm | [[多传感器融合定位]] 即可 |
| 点位停靠 | ±5-10cm | 导航到位判定 |
| 充电对接 | ±5-20mm（方式相关） | 慢速+地标微调 → [[充电桩与自动充电]] |
| 货架顶升 | ±5-10mm | 对接位精定位+货架导向 |
| 叉取托盘 | ±2-5mm | 视觉引导托盘识别 → [[视觉感知算法]] |
| 清洁覆盖率 | 无精度要求（覆盖 ≥95%） | [[路径规划算法]] 全覆盖 |
