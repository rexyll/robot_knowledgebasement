# 激光雷达（LiDAR）

> LiDAR 通过光学测距获取周围环境的距离/空间观测。它是否适合导航、避障、测量或安全防护，取决于具体产品、安装配置、环境和验证结果；普通导航 LiDAR 不能默认当作安全扫描仪。

## 先修知识与学习目标

先理解距离、角度、视场、坐标系、采样频率和基本光学安全概念。完成本页后应能读懂 LiDAR 数据表，区分 2D/3D 传感器和普通/安全扫描仪，并建立与机器人任务相关的选型和验证矩阵。

## 1. 常见测距方法

| 方法 | 基本原理 | 设计/使用时关注 |
| --- | --- | --- |
| 脉冲飞行时间（pulsed ToF） | 测量发射脉冲与回波之间的时间差 | 回波检测、环境光、目标反射特性、多回波和量程 |
| 相位测距 | 根据调制光的相位差估算距离 | 调制方式、量程歧义、目标材质与精度定义 |
| FMCW | 测量调频连续光的拍频，部分方案可同时估计径向速度 | 频率扫描、相干接收、速度/距离分辨率和成本 |
| 三角测量 | 根据发射/接收光路几何和成像位置求距离 | 基线、视场、近距离几何、环境光和目标反射率 |

产品的波长、发射功率和光学安全等级必须查看完整型号的认证/标签和制造商资料，不能根据 905nm、1550nm 等波长直接推断产品的安全等级。

## 2. 2D 与 3D 扫描形态

| 形态 | 数据特点 | 选型考虑 |
| --- | --- | --- |
| 2D 平面扫描 | 单一或多个扫描平面，输出角度—距离序列 | 机器人安装高度、腿部/低矮障碍、货物悬伸和扫描平面遮挡 |
| 多层/旋转 3D | 多个垂直通道或扫描层形成空间点云 | 垂直视场、垂直/水平角分辨率、点云密度、运动畸变和算力 |
| MEMS/转镜/棱镜扫描 | 通过内部光学器件形成扫描轨迹 | 视场形状、点云分布是否均匀、扫描重复模式、机械耐久 |
| Flash/面阵等固态方案 | 一次或分区获取视场中的深度信息 | 分辨率、量程、热设计、环境光、成本和产品成熟度 |

“固态”“半固态”“机械式”等营销分类不足以单独判断性能；需要根据实际扫描器件、点云分布和数据表进行比较。

## 3. 数据表必核参数

| 参数 | 要检查的定义 |
| --- | --- |
| 测距范围 | 目标反射率、环境光、测量概率、误差判据和温度条件；不能只引用最大测距数字 |
| 距离准确度/重复性 | 误差和重复性的定义、统计口径、测距区间、目标材质和测量方法 |
| 水平/垂直视场 | 覆盖区域、安装遮挡、近场盲区及机器人实际可达区域 |
| 角分辨率 | 水平/垂直角间隔、是否随距离/模式变化、点分布是否均匀 |
| 点频/扫描频率 | 点云采样量与扫描周期；不能单凭点频推断远处小物体一定可检测 |
| 最小量程与多回波 | 近距离盲区、透明/薄物体、雨雾粉尘和多回波策略 |
| 目标反射率/材质 | 黑色低反射、镜面、玻璃、吸光表面和多路径影响 |
| 环境适应性 | 阳光、雨雪、雾、粉尘、温度、振动、冲击和防护等级 |
| 时间/同步 | 时间戳含义、扫描起止时刻、逐点时间、硬件同步和驱动排队延迟 |
| 光学安全 | 激光等级、适用标准、使用距离和制造商限制 |
| 接口与软件 | Ethernet/USB/串口、数据协议、SDK、驱动支持和许可证 |

## 4. 机器人任务与选型

不要先指定某个“主流机型”，先写清检测任务：
- 需要检测的是人、腿、托盘、货叉、地面坑洞、细杆还是远处障碍？
- 目标尺寸、最远/最近距离、目标反射率和运动速度是什么？
- 机器人移动速度、制动时间、载荷、安装高度和转向会产生什么遮挡？
- 室内/室外、玻璃/镜面、阳光、雨雾、粉尘和多传感器互扰的边界是什么？
- 数据要用于建图、定位、普通避障、测量还是安全功能？

按任务建立验证矩阵：目标类别/尺寸 × 距离 × 入射角 × 反射材质 × 环境光/天气 × 机器人速度 × 安装位置。记录检测概率、误检、漏检、延迟和失效状态。

安全扫描仪是按相应安全标准设计并验证的专用产品类别。普通 LiDAR 输出的点云或扫描距离不得替代安全器件的安全输出；安全相关用途需回到 [[安全防护器件]] 和 [[功能安全体系]]。

## 5. ROS 数据接口与同步

2D 扫描常使用 sensor_msgs/LaserScan，典型字段包括：
- header.stamp 与 frame_id：时间戳和传感器坐标系；
- angle_min、angle_max、angle_increment：角度范围与间隔；
- time_increment、scan_time：扫描时序；
- range_min、range_max 和 ranges：距离有效范围与距离序列；
- intensities：可选强度信息，是否提供及其定义取决于驱动/设备。

3D 点云常使用 sensor_msgs/PointCloud2。点云字段、组织方式、单位、点内时间和回波信息需要以设备协议及驱动定义为准。

移动机器人使用旋转/扫描式 LiDAR 时，时间同步和运动去畸变很重要：需要确认时间戳对应扫描开始、结束还是采样时刻，以及 IMU/里程计与 LiDAR 时钟之间的偏差。驱动输出应经过时间戳、坐标系、无效点、丢包和数据完整性测试。

## 6. 产品/供应商对比的记录格式

对每个候选型号建立一条受控记录：
- 制造商、完整型号、订货号、硬件/固件版本；
- 数据表、用户手册、协议和驱动版本；
- 测距条件、精度/重复性口径、视场、分辨率、点频；
- 环境和安装限制、激光安全等级及证据；
- 采购价对应的日期、数量、区域、税运和报价有效期；
- 许可证、支持周期、备件、校准和供应商变更状态。

当前可从 [[链接台账]] #116–#122/#149 进入思岚、乐动、SICK、Livox 和禾赛资料；现有旧版参数表和价格快照未按统一测试方法逐型号核验，不作为采购排名或产品保证。

## 7. 量产验证与维护

- 对近场/远场和不同反射率目标进行基准测试；
- 对齐与标定：LiDAR 到机器人基准坐标系的外参及安装公差；
- 扫描频率、时间戳、丢包、数据延迟和驱动恢复；
- 振动、温度、灰尘、水和清洁维护后的性能；
- 多传感器/多雷达同时工作时的互扰；
- 固件、配置、校准文件和替换器件的版本追溯。
