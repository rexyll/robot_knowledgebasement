# 激光雷达（LiDAR）

> LiDAR 通过光学测距获取周围环境的距离/空间观测。它是否适合导航、避障、测量或安全防护，取决于具体产品、安装配置、环境和验证结果；普通导航 LiDAR 不能默认当作安全扫描仪。

## 先修知识与学习目标

先理解距离、角度、视场、坐标系、采样频率和基本光学安全概念。完成本页后应能读懂 LiDAR 数据表，区分 2D/3D 传感器和普通/安全扫描仪，并建立与机器人任务相关的选型和验证矩阵。

## 1. 常见测距方法

| 方法 | 基本原理 | 设计/使用时关注 |
| --- | --- | --- |
| 脉冲飞行时间（pulsed ToF） | 测量发射脉冲与回波之间的时间差 | 回波检测、环境光、目标反射特性、多回波和量程 |
| 相位测距 | 根据调制光的相位差估算距离 | 调制方式、量程歧义、目标材质与精度定义 |
| FMCW | 测量调频连续光的拍频，部分方案可同时估计径向速度 | 频率扫描、相干接收、速度/距离分辨率和成本 |
| 三角测量 | 根据发射/接收光路几何和成像位置求距离 | 基线、视场、近距离几何、环境光和目标反射率 |

产品的波长、发射功率和光学安全等级必须查看完整型号的认证/标签和制造商资料，不能根据 905nm、1550nm 等波长直接推断产品的安全等级。

## 2. 2D 与 3D 扫描形态

| 形态 | 数据特点 | 选型考虑 |
| --- | --- | --- |
| 2D 平面扫描 | 单一或多个扫描平面，输出角度—距离序列 | 机器人安装高度、腿部/低矮障碍、货物悬伸和扫描平面遮挡 |
| 多层/旋转 3D | 多个垂直通道或扫描层形成空间点云 | 垂直视场、垂直/水平角分辨率、点云密度、运动畸变和算力 |
| MEMS/转镜/棱镜扫描 | 通过内部光学器件形成扫描轨迹 | 视场形状、点云分布是否均匀、扫描重复模式、机械耐久 |
| Flash/面阵等固态方案 | 一次或分区获取视场中的深度信息 | 分辨率、量程、热设计、环境光、成本和产品成熟度 |

“固态”“半固态”“机械式”等营销分类不足以单独判断性能；需要根据实际扫描器件、点云分布和数据表进行比较。

## 3. 数据表必核参数

| 参数 | 要检查的定义 |
| --- | --- |
| 测距范围 | 目标反射率、环境光、测量概率、误差判据和温度条件；不能只引用最大测距数字 |
| 距离准确度/重复性 | 误差和重复性的定义、统计口径、测距区间、目标材质和测量方法 |
| 水平/垂直视场 | 覆盖区域、安装遮挡、近场盲区及机器人实际可达区域 |
| 角分辨率 | 水平/垂直角间隔、是否随距离/模式变化、点分布是否均匀 |
| 点频/扫描频率 | 点云采样量与扫描周期；不能单凭点频推断远处小物体一定可检测 |
| 最小量程与多回波 | 近距离盲区、透明/薄物体、雨雾粉尘和多回波策略 |
| 目标反射率/材质 | 黑色低反射、镜面、玻璃、吸光表面和多路径影响 |
| 环境适应性 | 阳光、雨雪、雾、粉尘、温度、振动、冲击和防护等级 |
| 时间/同步 | 时间戳含义、扫描起止时刻、逐点时间、硬件同步和驱动排队延迟 |
| 光学安全 | 激光等级、适用标准、使用距离和制造商限制 |
| 接口与软件 | Ethernet/USB/串口、数据协议、SDK、驱动支持和许可证 |

## 4. 机器人任务与选型

不要先指定某个“主流机型”，先写清检测任务：
- 需要检测的是人、腿、托盘、货叉、地面坑洞、细杆还是远处障碍？
- 目标尺寸、最远/最近距离、目标反射率和运动速度是什么？
- 机器人移动速度、制动时间、载荷、安装高度和转向会产生什么遮挡？
- 室内/室外、玻璃/镜面、阳光、雨雾、粉尘和多传感器互扰的边界是什么？
- 数据要用于建图、定位、普通避障、测量还是安全功能？

按任务建立验证矩阵：目标类别/尺寸 × 距离 × 入射角 × 反射材质 × 环境光/天气 × 机器人速度 × 安装位置。记录检测概率、误检、漏检、延迟和失效状态。

安全扫描仪是按相应安全标准设计并验证的专用产品类别。普通 LiDAR 输出的点云或扫描距离不得替代安全器件的安全输出；安全相关用途需回到 [[安全防护器件]] 和 [[功能安全体系]]。

## 5. ROS 数据接口与同步

2D 扫描常使用 sensor_msgs/LaserScan，典型字段包括：
- header.stamp 与 frame_id：时间戳和传感器坐标系；
- angle_min、angle_max、angle_increment：角度范围与间隔；
- time_increment、scan_time：扫描时序；
- range_min、range_max 和 ranges：距离有效范围与距离序列；
- intensities：可选强度信息，是否提供及其定义取决于驱动/设备。

3D 点云常使用 sensor_msgs/PointCloud2。点云字段、组织方式、单位、点内时间和回波信息需要以设备协议及驱动定义为准。

移动机器人使用旋转/扫描式 LiDAR 时，时间同步和运动去畸变很重要：需要确认时间戳对应扫描开始、结束还是采样时刻，以及 IMU/里程计与 LiDAR 时钟之间的偏差。驱动输出应经过时间戳、坐标系、无效点、丢包和数据完整性测试。

## 8. 2026-11-15｜ROS 2 接口、代表型号数据与安全扫描仪边界复核

### 8.1 ROS 2 Jazzy 的 LaserScan 时间和坐标语义

ROS 2 Jazzy `sensor_msgs/msg/LaserScan` 对字段有明确约定：

| 字段 | 正确解释 | 集成注意事项 |
| --- | --- | --- |
| `header.stamp` | 扫描第一束 ray 的采集时刻 | 不能一概当作整帧结束时刻或中点时刻；驱动应说明时间戳来自设备时钟还是主机接收时钟 |
| `header.frame_id` | 扫描数据所在坐标系 | 与 URDF/TF 中的雷达安装坐标严格对应 |
| `angle_min/max/increment` | 第一束/最后一束角度及相邻测量角间隔，单位 rad | 绕 +Z 轴测角；Z 朝上时逆时针为正，0 rad 沿 +X |
| `time_increment` | 相邻测量之间的时间间隔 | 运动去畸变会用它插值每束光的位姿；必须确认设备/驱动确实提供有效值 |
| `scan_time` | 相邻两次扫描之间的时间 | 不等同于一帧内第一束到最后一束的耗时，也不能自动替代 `time_increment` |
| `range_min/max`、`ranges` | 有效量程边界和每束距离 | 小于最小值或大于最大值的数据应按消息约定丢弃 |
| `intensities` | 设备特定单位的强度值 | 无强度数据时数组应为空；不同厂商的强度不能未经标定横向比较 |

逐束时间戳只有在驱动正确填充 `time_increment` 且时钟/扫描时序语义明确时，才能按第一束时刻加索引时间计算。不能把 `scan_time/N` 作为通用替代值。

### 8.2 ROS 2 Jazzy 的 PointCloud2 数据布局与点内时间

`sensor_msgs/msg/PointCloud2` 将点集存为二进制 blob，由 `fields` 描述字段位置和类型：

- `height`、`width` 描述二维有组织点云或一维无组织点云；无组织点云通常 `height=1`。
- `fields` 定义 x/y/z、intensity、ring、normal 等通道在点记录中的布局；`is_bigendian` 指示字节序。
- `point_step` 是单点字节数；`row_step` 是一行字节数；`data` 字节数为 `row_step × height`；`is_dense` 标记是否没有无效点。
- 基础 PointCloud2 定义没有强制规定通用 per-point timestamp 字段名、单位或时钟基准。设备/驱动可能增加 `time`、`t`、`timestamp` 等字段，但必须查看准确驱动和数据协议，不能仅凭字段名猜单位或相对/绝对时间语义。

**去畸变验收最低要求：** 同时保存设备时间戳、主机接收时间、驱动版本、点内时间字段、IMU/里程计时钟关系、TF 外参和丢包统计；通过静止与受控运动数据回放对比未去畸变/去畸变点云。没有点内时间或等价逐点时序时，不应声称完成逐点运动补偿。

### 8.3 Livox Mid-360：产品页数值必须连同测试脚注一起引用

Livox 官方 Mid-360 参数页列出的代表性信息：

| 参数 | 官方页数据 | 条件/边界 |
| --- | --- | --- |
| 波长/激光等级 | 905 nm；Class 1（IEC 60825-1:2014） | 这是激光产品等级，不是机器安全扫描仪的 Type/PL/SIL 等级 |
| 测距范围 | 40 m @ 10% 反射率；70 m @ 80% 反射率 | 标注环境照度 100 klx；不要脱离目标反射率和环境光引用“最大量程” |
| 近距离盲区 | 0.1 m | 0.1–0.2 m 可输出点云，但厂商说明不能保证探测精度 |
| 视场 | 水平 360°；垂直 -7° 至 +52° | 安装遮挡、车体结构和俯仰姿态会缩小实际有效覆盖 |
| 测距随机误差（1σ） | ≤2 cm @10 m；≤3 cm @0.2 m | 脚注条件为 25°C、80% 反射率；0.1–1 m 的低反射率/细小目标不保证探测效果 |
| 点云/同步 | 200,000 点/s（first return）；10 Hz 典型帧率；100BASE-TX；PTPv2/GPS | 需核对实际回波模式、设备固件、驱动点时间及网络同步配置 |
| 环境/供电 | IP67；-20 至 55°C；9–27 V DC；6.5 W 平均 | -20 至 0°C 自加热时峰值功耗可达 14 W；强振动、大雾和高低温会影响表现 |

上述数据仅为产品页给定条件下的型号快照。它不证明黑色吸光物、玻璃、细线、水面、雾天或运动目标在机器人现场一定可检出；采购前还需核对数据手册/用户手册、配置、固件、安装和目标场景测试。

### 8.4 普通 2D LiDAR 与安全激光扫描仪：同样有“检测区”，但安全属性不同

| 设备示例 | 厂商资料明确内容 | 应如何解释 |
| --- | --- | --- |
| SICK TiM1xx | 2D LiDAR；TiM10x/TiM15x 室内应用量程分别至 3 m/10 m；可配置检测场并通过数字输出报告区域被侵入；手册明确写明它不是机器安全标准下的安全组件 | 数字输出/区域检测不等于 OSSD、安全认证或安全功能 |
| SICK nanoScan3 I/O（Core I/O / Pro I/O 对应手册） | 2026-05-26 版手册列 Type 3（IEC 61496）、SIL 2（IEC 61508/IEC 62061）、Category 3、PL d、PFH 8×10⁻⁸ h⁻¹、任务时间 20 年，并给出 OSSD 安全输出 | 仅适用于手册列出的准确型号/配置和规定条件；系统级 PL/SIL 仍取决于完整安全链、控制器、接线、复位和验证 |
| nanoScan3 的 Ethernet 测量数据 | 手册将该数据输出定位为一般监控/AGV 导航支持，并明确说明该数据输出不用于安全相关应用 | 即使同一设备具有安全扫描功能，也不能把导航点云/测量数据通道当作安全输出；安全功能应使用指定 OSSD/安全通信接口并按手册集成 |

nanoScan3 手册还把室外、水下、爆炸危险环境以及透明物体检测列为不允许/不支持的使用边界。安全参数、响应时间、保护区域补偿、最大扫描周期和配置校验必须按确切订货号与安全手册确定，不能把系列名称或产品宣传页的最高值推广到所有变体。

### 8.5 标准边界：激光产品等级 ≠ 机器安全功能等级

- IEC 60825-1:2014 第 3 版是当前官方目录显示的有效版次，主题是激光产品的分类与要求；它解决激光辐射/产品等级问题，不授予机器人人员检测或机器安全功能等级。IEC 页面显示第 4 版仍在 ACD 阶段，预测发布日期 2027-02-01；预测日期不是已经发布的标准。
- IEC 61496-3:2025 第 4 版为有效版次，针对使用漫反射响应主动光电保护器件（AOPDDR）的电敏保护设备，规定其设计、制造和测试的附加要求。其范围不替代具体机器风险评估/保护区域布置，也未覆盖室外应用测试；其适用波长和检测对象条件亦有明确限制。
- 因此“Class 1”只能说明激光产品的光辐射分类，不等于 IEC 61496 Type 3、PL d、SIL 2，更不等于特定 AGV/AMR 整机已经实现安全停机或通过验证。
