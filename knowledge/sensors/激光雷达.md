# 激光雷达（LiDAR）

> 发射激光测量 TOF（飞行时间）获得周围空间点云，是 AMR 的主感知传感器。选型看 **测距原理 × 扫描方式 × 参数** 三层。

## 测距原理

| 原理 | 波长/方式 | 精度 | 成本 | 适用 |
|---|---|---|---|---|
| 三角测距 | 780-940nm，视差法 | ±5-20mm（近距离好，远距差） | 低（¥300-1500） | 家用扫地机、小型 AMR（Sick TiM 代表工业级） |
| 脉冲 TOF（dToF） | 905nm 脉冲 | ±10-30mm | 中 | 主流 2D/机械式 3D |
| 相位式 | 调幅连续波 | ±5-10mm | 中高 | 室内中距 |
| FMCW | 1550nm 相干探测 | ±5mm + 直接测速（多普勒） | 高 | 车规/高端（Aeva、Aurora） |

## 扫描方式（3D）

| 方式 | 原理 | 代表 | 特点 |
|---|---|---|---|
| 机械旋转 | 电机整体旋转线束 | Velodyne HDL-64（鼻祖）、禾赛 AT128（半固态） | 传统车载 |
| 半固态（MEMS/转镜） | 振镜偏转 | 禾赛 AT128/FT120、速腾 M 系列 | 当前车载主流 |
| 固态（Flash/OPA） | 面阵发光/光学相控阵 | OPA 尚在成熟中 | 终极形态未到 |
| 棱镜式 | 旋转棱镜折射 | Livox Mid-360（¥3499，机器人普及款）、HAP | 花瓣状 FOV |
| 电子扫描 | VCSEL 阵列 | 速腾 E1、禾赛 JT | 车规固态新潮 |

## 关键参数解读（选型口诀）

1. **点频/分辨率**：决定远距小障碍（行人腿、细杆）能否成点。25m 外识别 2cm 杆 ≈ 需要 >0.1° 角分辨率。
2. **精度 vs 准度**：精度(repeatability) 同点重复性；准确度(trueness) 与真实距离偏差——SLAM 更在意前者。
3. **近场盲区**：0.05-0.5m，底盘四周需补超声波/触边。
4. **10% 反射率量程**：黑色/暗面物体实际探测距离标尺，比"最大量程"更诚实。
5. **波长**：905nm（硅基、便宜、人眼安全限制功率）vs 1550nm（铟镓砷、可大功率、远距、贵）。
6. **多机互扰**：同频 LiDAR 互相打到 → 厂商提供干扰规避模式（脉冲相位随机化）。

## LaserScan 消息结构（V3 · 附件整合）

> 来源：用户附件 PDF（Google Search 会话，2026-11-01 导出）。驱动发布 `sensor_msgs/LaserScan` 到 `/scan`——本质是**极坐标（角度+距离）**描述雷达周围障碍分布。

| 字段 | 含义 | 备注 |
|---|---|---|
| header.stamp / frame_id | 本帧扫描起始时间戳 / TF 坐标系名（如 `laser`） | frame_id 必须与 TF 树一致 → [[导航流程]] |
| angle_min / angle_max | 起始/结束角度（弧度，如 ∓3.14159=∓180°） | 配置参数 |
| angle_increment | 相邻两束的角间隔（角分辨率，弧度） | 一圈点数由此决定 |
| time_increment | 束与束之间的时间间隔（秒） | **运动畸变校正用**（高速时逐点去畸变） |
| scan_time | 两次扫描间隔（秒）= 1/频率 | 10Hz → 0.1 |
| range_min / range_max | 可信测距下/上限 | 小于/大于即无效值 |
| float32[] ranges | **核心距离数组** | `len = (angle_max-angle_min)/angle_increment + 1` |
| float32[] intensities | 反射强度数组（与 ranges 等长） | 与材质/反射率相关；低成本单回波硬件可能为空 |

- **特殊值处理**：无障碍（超程）或强干扰 → 驱动置 `NaN` / `Inf` / 越界值——下游 costmap 与 SLAM 都要先过滤这些值，直接喂进去是"鬼点"的常见来源。
- echo 示例（`ros2 topic echo /scan`）：`angle_increment≈0.0175（约 1°/360 点）、scan_time 0.1（10Hz）、range_min 0.15、range_max 12.0`。
