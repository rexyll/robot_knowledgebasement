# 传感器总览

> 机器人的"五官"。按感知维度组织：空间几何、运动状态、环境物理量、人机交互。

## 分类树

```
传感器
├── 空间几何（外面世界长什么样）
│   ├── [[激光雷达]]（2D/3D 点云）
│   ├── [[深度相机]]（RGB-D、结构光/ToF/双目）
│   └── [[毫米波雷达与超声波]]（距离+速度）
├── 运动状态（我自己在哪、怎么动）
│   ├── [[IMU]]（角速度+加速度）
│   ├── [[编码器与里程计]]（轮速/关节角）
│   └── GPS/RTK（室外厘米级，见[[多传感器融合定位]]）
├── 安全与接近
│   ├── [[安全防护器件]]（触边/急停/防撞条/安全扫描仪）
│   └── 红外对管/悬崖传感器（家用清洁机防跌落）
└── 专用物理量
    ├── 力/力矩传感器（六维力、关节力矩）
    ├── 触觉阵列（灵巧手电子皮肤）
    ├── 温度/气体/湿度（特种巡检）
    └── 电流传感（碰撞检测的廉价替代）
```

## 典型配置方案

| 机器人类型 | 感知配置 |
|---|---|
| 商用 AMR（搬运） | 2D LiDAR×2（前后）+ IMU + 轮编码器 + 深度相机×2 + 触边 |
| 无人叉车 | 3D LiDAR + 安全扫描仪×2 + 相机（托盘识别）+ IMU |
| 家用扫地机 | dToF LiDAR + 悬崖红外 ×6 + 沿墙传感 + IMU + 光流 |
| 商用清洁机 | LiDAR + 深度相机 + 超声波×4 + 触边 + 防跌落 → 参照 [[项目-清洁机器人]] |
| 巡检四足 | 全景相机 + LiDAR + 关节力矩 + 气体/红外载荷 |

## 融合关系

2. **避障线**：[[局部规划与避障]]（深度相机+超声波+安全器件 的代价地图融合）
