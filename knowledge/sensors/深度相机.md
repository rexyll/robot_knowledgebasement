# 深度相机（RGB-D / 3D 相机）

> 深度相机估计场景中各像素对应的距离，可与 RGB 图像一起用于识别、测量、避障和抓取。不同测深原理的失效条件不同；“室内/室外可用”不能只凭技术名称决定。

## 先修知识与学习目标

先理解图像分辨率、视场角、焦距、像素、深度图、坐标系和相机标定。完成本页后，应能读懂深度相机数据表、区分测深原理、建立传感器安装与验证计划，并理解深度误差如何影响机器人任务。

## 1. 常见测深原理

| 原理 | 基本原理 | 典型约束/误差源 |
| --- | --- | --- |
| 被动双目 | 两台相机从不同视角观察同一纹理，通过视差估计深度 | 弱纹理、重复纹理、遮挡、运动模糊、曝光差和基线/标定 |
| 主动双目 | 在双目基础上增加红外图案/纹理辅助匹配 | 阳光红外、投射图案对比度、其他主动传感器干扰和目标材质 |
| 结构光 | 投射已知图案，根据图案变形/成像求深度 | 环境光、投影图案可见性、工作距离和表面反射特性 |
| 间接飞行时间（iToF） | 测量调制光往返造成的相位差 | 多径干扰、相位歧义、环境光、反射材质和距离范围 |
| 直接飞行时间（dToF） | 根据光脉冲往返时间估计距离 | 回波强度、目标反射率、环境光、测量概率和器件实现 |

主动双目不等同于传统结构光；具体产品可能融合多种技术。需根据实际产品架构、数据表和测试条件判断。

## 2. 关键参数及其定义

| 参数 | 应核对的定义 | 选型注意 |
| --- | --- | --- |
| 深度范围 | 最小/最大可用距离及对应模式 | 最大演示距离不等于任务可用距离 |
| 深度误差 | 准确度、偏差、RMSE 或重复性 | 必须确认距离、目标材质、环境光和统计口径 |
| 深度分辨率 | 深度图像素宽高 | 分辨率提高不自动带来更准确的深度 |
| RGB 分辨率/帧率 | 彩色相机分辨率与帧率 | RGB 与深度是否同步、是否同视场 |
| 视场角（FOV） | 水平/垂直视角和有效深度视场 | 需结合安装角度、遮挡和目标区域 |
| 基线/焦距 | 双目基线与镜头参数 | 影响几何测距能力、近远场分布和结构尺寸 |
| 曝光/工作模式 | 深度曝光、发射器强度、滤波、帧同步 | 模式变化可能改变量程、噪声和延迟 |
| 环境适应性 | 环境光、阳光、温度、振动、粉尘、水 | 看准确型号数据表，勿只按原理分类 |
| 多径/反射 | 镜面、透明、黑色、斜入射和多表面反射行为 | 玻璃和高反光表面可能产生缺失或错误深度 |
| 延迟/同步 | 深度与 RGB 帧时间戳、曝光时刻和输出延迟 | 运动机器人须将时间误差纳入融合和去畸变 |
| 接口与SDK | USB、Ethernet、MIPI 等及 SDK/驱动支持 | 核对平台、操作系统、内核和许可证兼容性 |

## 3. 按机器人任务选型

- **近距离避障：** 关注最低可靠测距、地面/桌腿/线缆检测、遮挡、深度空洞和运动模糊。
- **抓取与操作：** 关注深度精度、RGB-D 对齐、手眼外参、重复性、视场和物体材质。
- **VSLAM/VIO：** 关注相机内参、曝光/帧率、时间同步、滚动快门、纹理和动态模糊。
- **室外移动机器人：** 必须以具体型号验证阳光、温度、雨雾和强反射环境；不能用“被动双目适合户外”作为免测试结论。
- **人员感知：** 关注目标遮挡、视场覆盖、隐私合规和环境变化；普通深度相机不等同于安全防护器件。

先定义目标物体最小尺寸、距离区间、表面材料、运动速度和现场光照，再构建验证矩阵，而不是先选品牌。

## 4. 标定、安装与数据链路

1. **内参标定：** 相机模型、焦距、主点、畸变参数和图像分辨率/裁剪模式。
2. **深度到 RGB 对齐：** 核对深度与彩色图的坐标映射、遮挡和对齐模式。
3. **外参标定：** 确定相机与机器人 base、工具中心点或其他传感器之间的空间关系。
4. **时间同步：** 记录曝光时刻、设备硬件时间戳、主机接收时间、驱动延迟和丢帧。
5. **安装结构：** 控制振动、遮挡、窗口反射、保护玻璃影响、散热和维修可达性。
6. **数据单位：** 区分米/毫米、无效深度编码、置信度、深度量程和滤波后的输出。

ROS 中常见图像接口包括 Image、CameraInfo 和 PointCloud2。深度单位、编码、坐标系、内参、外参及时间戳需要与驱动文档一致；不能仅凭话题名称假设深度数据已正确标定。

## 5. 典型故障与排查

| 现象 | 可能原因 | 检查方向 |
| --- | --- | --- |
| 深度图有大片空洞 | 低纹理、过曝、反射/透明表面、量程外或发射器问题 | 原始 RGB/IR、置信度、工作模式和目标材质 |
| 深度随太阳光显著变化 | 主动红外受环境光影响或传感器内部饱和 | 户外实测、遮光罩、曝光/发射设置和替代方案 |
| 近距离误差很大 | 超出最小量程、双目遮挡、镜头/基线误差 | 最近工作距离、视差范围和近场标定 |
| RGB 与深度错位 | 外参/对齐模式/分辨率配置不一致 | CameraInfo、坐标映射和软件版本 |
| 点云拖影/跳动 | 时间戳不同步、运动模糊、曝光时间长或队列积压 | 硬件时间戳、曝光、延迟和队列 |
| 更换相机后结果变化 | 型号/镜头/固件/安装位置变化 | 完整型号、配置基线、重标定和回归测试 |

## 6. 型号资料与采购规则

当前调研的资料入口见 [[链接台账]] #123–#127（RealSense、Orbbec、Stereolabs 等）。现有旧版价格及量程数据没有在统一工作条件下逐项复核，本页不提供型号排名。任何参数进入采购规格前，都应匹配完整订货号、镜头/基线、深度模式、固件/SDK 版本和制造商数据表。

定点资料至少包括：规格书、用户手册、SDK/驱动、标定文件格式、同步机制、环境限制、供应生命周期、许可证、备件/维修政策和变更通知。

### 具体型号资料示例：D455 与 D457

以下仅用于演示如何读取制造商资料，不构成型号推荐或跨产品性能比较：

| 项目 | D455 | D457 |
| --- | --- | --- |
| 测深方案 | 主动红外双目立体视觉 | 主动红外双目立体视觉 |
| 接口/集成重点 | USB-C 3.1 Gen 1 | GMSL 2 / FAKRA；主机端需匹配解串器 |
| 公开环境/结构信息 | 制造商产品页列出理想工作范围 0.6–6 m | 2025-12 数据表列 IP65；需遵守连接器及同步接口盖帽条件 |
| 额外注意 | 页面所列“4 m 处小于 2%”必须连同测量口径阅读 | 数据表的 0.4 m 至 10 m 以上描述注明随光照条件变化；另需安装专用 GMSL 内核驱动 |

D455 的制造商深度质量说明将 ≤2% Z-accuracy 等指标限定于特定距离、HD 分辨率、80% ROI，以及完成 OEM 集成校准的模组；不能把单一产品页的简述当作任意目标、任意距离和任意集成状态下的保证。D457 虽具有 IP65 声明，也不意味着整机安装后自动达到 IP65；连接器、线束、同步接口盖帽、窗口/外壳和安装开孔都必须按数据表要求复核。

## 7. 验收与量产成果物

- 深度范围/误差测试计划与不同材质目标测试记录；
- 目标尺寸、距离、入射角、光照和温度覆盖矩阵；
- 相机内参、RGB-D 对齐和机器人外参标定文件；
- 延迟、丢帧、同步、点云完整性和驱动恢复测试；
- 固件/SDK/参数版本与供应商变更控制；
- 现场安装、清洁、遮挡检查和重新标定维护规程。
