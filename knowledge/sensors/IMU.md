# IMU（惯性测量单元）

> 输出三轴角速度（陀螺）+ 三轴加速度（加计），部分含三轴磁力计（9 轴）。是所有运动融合定位的**粘合剂**：高频（200-1000Hz）、不受光照/纹理影响、短时准、长时漂移。

## 精度分级（决定价格的天花板）

| 等级 | 陀螺零偏稳定性 | 典型器件 | 价格 | 用途 |
|---|---|---|---|---|
| 消费级 | >50°/h | MPU6050、BMI088 | ¥5-50 | 玩具、扫地机（配轮计/VSLAM 纠偏） |
| 工业级 | 1-10°/h | ADIS16470、STIM300、Honeywell HG4930 | ¥2000-20万 | AMR/无人机主流 |
| 战术级 | 0.1-1°/h | 光纤陀螺 FOG | 10万+ | 特种、军用 |
| 导航级 | <0.01°/h | 激光陀螺 | 百万级 | 舰船、飞机 |

> AMR 实践：室内 SLAM 场景工业级够用；外参标定（LiDAR-IMU 外参）比换贵 IMU 收益更大。

## 关键参数

| 参数 | 含义 | 典型值（工业级） |
|---|---|---|
| 零偏稳定性（Bias Instability） | 静止时输出的随机漂移，Allan 方差最低点 | 1-10°/h |
| 角度随机游走（ARW） | 积分后角度噪声 | 0.1-0.5°/√h |
| 量程 | 最大角速度/加速度 | ±2000°/s、±16g |
| 带宽/输出频率 | 数据率 | 200-4000Hz |
| 非线性 | 满量程误差 | 0.1% |
| 温漂 | 零偏随温度变化 | 需温补模型 |

## 在融合定位中的角色（→ [[多传感器融合定位]] · [[卡尔曼滤波]]）

```
IMU(200-1000Hz) ──预测──→ 状态传播
LiDAR/视觉(10-30Hz) ──观测──→ 修正漂移
轮里程计(100Hz) ──观测──→ 速度约束
GNSS-RTK(1-10Hz, 室外) ──观测──→ 绝对位置
```

- 紧耦合 LIO（FAST-LIO2/Point-LIO）：IMU 迭代误差状态卡尔曼滤波（EKF/IESKF）
- 零偏在线估计是核心：6 维偏差状态（陀螺/加计各 3）
- 预积分（GTSAM/`imu_preintegration`）：把 IMU 流压缩为关键帧间约束

## 使用要点（工程经验）

1. **安装位置**：靠近机器人旋转中心，刚性安装（减震垫防高频振动但别软到共振）
2. **外参标定**：LiDAR-IMU 时延与旋转外参 → 手眼标定变体 → [[视觉软件栈]] 的标定思想
3. **温机**：零偏随温度漂，开机预热 5-15min 后做静态初始化（VINS 的 VI 初始化）
4. **振动干扰**：轮电机高频振动让加计饱和 → 机械滤波+低通

## /imu/data 消息结构与用途补充（V3 · 附件整合）

> 来源：用户附件 PDF（Google Search 会话，2026-11-01 导出）。IMU 是"**向内看**"的传感器（本体运动状态），与 LiDAR"向外看"互补。

**格式化消息 `sensor_msgs/Imu`（话题 /imu/data）**：

| 字段 | 含义 | 要点 |
|---|---|---|
| orientation (x,y,z,w) | 四元数姿态 | 硬件无内置融合时可能全 0（由滤波算法填） |
| orientation_covariance | 姿态协方差（9 元素行主序） | 0 表示未知，-1 表示无参考 |
| angular_velocity (x,y,z) | 陀螺角速度（rad/s） | 融合的**高频主角** |
| angular_velocity_covariance | 角速度协方差（9 元素） | EKF 的 R 来源 → [[卡尔曼滤波]] |
| linear_acceleration (x,y,z) | 加计线加速度（m/s²） | **静止时 Z≈9.81**（重力） |
| linear_acceleration_covariance | 加计协方差（9 元素） | 同上 |

**驱动层之下的原始数据**：经 I2C/SPI/串口从 IMU 芯片（MPU6050/ICM20689 类）读出的是**原始 16 位 ADC 计数**（如 ax_raw=16384），驱动按当前**量程（Gain/Sensitivity）换算**——±2g 量程下 16384 对应 1g（9.81 m/s²）。换算错误=整机加速度数据整体错的头号原因。

**术语补充**：带磁力计的 IMU 称 **IMMU**（9 轴，辅助校准航向防漂移）；不带磁力计为 6 轴 IMU（机器人主流，理由见 [[09-04-传感器选型与标定]] 磁干扰警告）。

**用途四补充**（V2 已述融合，此处补三条易漏）：
1. **高频运动补偿（Deskewing）**：LiDAR 10-20Hz 刷新 vs IMU 100-1000Hz——用 IMU 对两次扫描间的运动做**点云去畸变**（LIO 标配）。
2. **碰撞与跌倒检测**：加计的**反向冲击波**可瞬间识别撞墙（即使触边未触发）；俯仰/翻滚角瞬时超限触发"跌倒保护/呼救"逻辑（足式/清洁机爬坡卡住场景）。
3. **短时死航（Dead Reckoning）**：角速度一次积分=角度、加速度两次积分=位移——进无激光特征的狭长走廊/无 GPS 隧道时"盲推"位置；⚠️ 消费级 MEMS 零偏与噪声使误差**二次方爆炸**，只可作短时应急，不可长时间单独导航（→ [[多传感器融合定位]]）。
