# 充电桩与自动充电

> 自动充电是机器人、充电设备、BMS、现场基础设施和调度系统组成的系统功能。充电电压、电流、倍率、接口和对接公差必须针对具体电池包与充电设备确认，不存在适用于所有 AMR 的通用规格。

## 先修知识与学习目标

先阅读 [[电池与电源]]、[[09-03-电子电气设计]] 和 [[多机调度流程]]。理解电压、电流、功率、容量 Ah、能量 Wh、充电倍率 C，以及充电许可与故障状态。

完成本页后应能画出充电系统接口图、定义充电状态机、识别主要失效模式，并形成供应商接口和验证清单。

## 1. 充电系统边界

至少包括：电池包/电芯、BMS、充电器或充电桩、连接器/触点、车辆侧配电与控制器、机械对接结构、通信接口、地面基础设施、调度系统和现场人员操作。

系统设计前先确认：
- 电池包准确型号、串并联、电压范围、允许充电电流/功率和温度窗口；
- 充电器输出范围、限流/恒压行为、纹波、隔离、保护、散热和故障输出；
- 连接器额定值、触点材料/镀层、温升、插拔寿命、对接公差和防误触；
- 通信协议、握手责任、超时、掉线后的输出状态和恢复逻辑；
- 停车定位、机械容差、地面平整度、排水/粉尘、人员可达和防火要求。

## 2. 充电方式

| 方式 | 主要特点 | 需要重点验证 |
| --- | --- | --- |
| 接触式自动充电 | 弹片、插头或自动对接触点 | 触点接触电阻、温升、电弧、磨损、污染、极性、防触电和插拔寿命 |
| 人工插接充电 | 结构较简单，依赖操作人员 | 防误插、连接器额定值、操作程序、断开次序和人员安全 |
| 无线充电 | 无裸露电气触点，可改善部分环境适应性 | 线圈对准容差、异物检测、效率、发热、电磁兼容、通信和故障保护 |
| 换电/可更换电池 | 可缩短补能停机时间 | 电池重量、吊装/插拔安全、互锁、防错、批次追溯、备用电池管理 |

不应将乘用车无线充电标准或某个厂商的频率/功率方案直接套用到机器人；必须确认标准适用范围和实际设备的认证资料。

## 3. 自动回充状态机

```
IDLE
  → REQUESTED（电量/任务预测/运维指令触发）
  → RESERVED（调度系统分配充电位）
  → APPROACH（进入对接路线和限制速度）
  → DOCKED（机械/电气连接状态确认）
  → PRECHECK（BMS、温度、电压、极性、绝缘和互锁检查）
  → CHARGING（按电池包允许的电流/电压闭环充电）
  → COMPLETE（达到终止条件并确认电流降至安全断开范围）
  → UNDOCK（断开并确认输出状态）
  → AVAILABLE
任一阶段发现异常 → FAULT（停止充电、进入定义的安全状态、记录原因）
```

关键原则：
1. SOC 阈值只是调度触发条件，不是电气充电许可。
2. 充电器启动前要确认电池包状态、连接状态、温度窗口、允许充电电流和互锁。
3. 充电期间持续监控电压、电流、温度、通信状态和设备故障。
4. 通信中断、触点过温、异常电压、绝缘故障或人员防护触发时，必须按安全设计停止能量传输。
5. 停止充电、断开连接器和机器人驶离之间必须定义互锁与时序；不能在触点仍承载电流时随意拔插。
6. 故障复位要明确故障消除条件和人工授权，不得无限自动重试。

## 4. 充电倍率和时间估算

充电倍率 C 的近似定义：

`I_charge(A) = C_rate × Q_capacity(Ah)`

但实际允许电流由电芯型号、串并联、电池包温度、SOC、BMS 限流、充电器能力、线束和热设计共同决定。不能把 0.5C、1C 或 2C 写成所有电池的通用充电倍率。

理想化能量估算：

`t_ideal(h) ≈ E_to_add(Wh) / P_average_charge(W)`

真实充电时间还受恒压阶段电流下降、温度限流、均衡、通信握手和运营策略影响；应使用电池包/充电器正式曲线和实测任务周期。

## 5. 采购接口控制表

| 接口 | 双方必须确认 |
| --- | --- |
| 电气 | 输出电压范围、电流/功率、隔离、纹波、极性、防反接、短路/过温保护、接地/保护联结 |
| 电池/BMS | 允许充电窗口、温度限值、限流/截止条件、SOC/SOH/故障字、协议版本 |
| 机械 | 定位基准、接触压力、对接公差、浮动补偿、磨损件更换和防夹 |
| 通信 | 物理层、协议/版本、超时、重连、认证、异常和日志 |
| 环境 | 防护等级、温度、湿度、粉尘、水、腐蚀、振动和清洁方式 |
| 服务 | 故障码、远程诊断、备件、维护周期、固件升级和变更通知 |

接口协议可能是 CAN、RS-485、以太网或厂商定义方案；不得默认所有充电系统都使用 CAN。

## 6. 安全与验证

至少规划以下验证：空载/满载对接误差、触点温升和接触电阻、长周期插拔磨损、异常断开、电压/极性错误、过流/短路保护、过温、通信中断、BMS 故障、绝缘/接地（按适用要求）、雨水/粉尘/清洁环境，以及充电期间人员进入和紧急停止。

电池运输试验、工业电池安全要求和整机机器安全是不同层次：
- IEC 62619:2022 涉及工业应用二次锂电芯/电池安全要求与试验；
- UN《试验和标准手册》38.3 涉及锂电池运输相关试验和测试摘要；
- 整机充电系统仍需按目标市场、产品用途和实际安装环境评估适用标准与法规。

## 7. 车队充电调度

常见策略：
- **阈值回充：** SOC 低于设定阈值后申请充电；需防止车辆集中排队。
- **机会充电：** 在任务空闲和运营窗口补能；需核对电池允许的充电策略。
- **前瞻规划：** 结合剩余能量、路线能耗、载荷和充电位可用性决定是否接受任务。
- **轮换/换电：** 按电池批次、健康状态和人员操作风险管理。

SOC 不是绝对准确值；调度系统还应考虑电池温度、SOH、功率限制、任务可完成性、保底返航能量和充电位故障。

## 8. 自动充电系统的安全边界、标准生命周期与厂商实例（2026-11-15）

### 8.1 EN 1175:2025 不等于无人驾驶车辆自动运行功能的完整电气安全依据

截至 2026-11-15，CEN 已发布 EN 1175:2025《工业车辆安全——电气/电子要求》，并取代 EN 1175:2020；多个国家采用版已在 2026 年生效。例如 UNI EN 1175:2026 标记为 CURRENT，生效日期为 2026-01-29。

将该标准用于 AGV/AMR 时必须注意其范围：它针对 ISO 5053-1:2020 范围内自推进工业车辆的电气安装、电气/电子系统及安全相关控制系统要求，但明确排除无人驾驶工业车辆自动运行使用的功能，并指向 EN ISO 3691-4:2023 §4.1.3。不能只因设备是电动工业车辆，就把 EN 1175:2025 当作 AMR 自动运行、自动对接或自动充电功能的完整安全依据。机器中非自动运行的电气部分是否适用，仍需按设备定义、系统边界和目标市场逐项判断。

### 8.2 ISO 3691-4 的已发布版与第三版 DIS 草案

- **当前已发布版本：** ISO 3691-4:2023。ISO 官方范围说明该标准覆盖无人驾驶工业车辆及其系统，但动力源要求不在其范围内。因此，不能只凭引用 ISO 3691-4 就认为电芯、电池包、BMS、充电器或充电设施的全部产品安全要求已经得到覆盖。
- **第三版草案：** ISO/DIS 3691-4 第三版截至本次复核仍标为 Under development / Draft International Standard，尚未取代 2023 版。ISO 官方公开预览的目录列出 §4.5 “Automatic battery charging”；系统定义还把 charging stations 和 online charging systems 列为无人驾驶车辆系统的辅助组成示例。
- **草案使用限制：** 上述目录/定义可以提示设计团队将自动充电站、车载触点和充电控制纳入系统边界审查；但草案条款不能提前作为当前已发布标准的符合性依据，也不能从目录标题推断 §4.5 的具体通过条件。正式标准发布后应重新审读完整条文和验证要求。

### 8.3 具体厂商案例：ABB Flexley Stack AMR F702 在线充电

ABB《Flexley Stack AMR F702 Product Manual》，文档 ID 3HAS00050-001、Revision A（2025），展示了一种接触式在线充电实现。该案例仅适用于该手册所述产品配置，不代表所有 AMR 的通用设计：

1. 车辆请求充电后由 Fleet Manager 下发充电任务；AMR 精确停到充电站触点位置。
2. 车辆与充电站建立 CAN 通信；手册描述只有在通信建立且相应状态切换后，接触器才向刷板供电，刷板在接触器动作前不带电。
3. 手册说明如果充电过程中 AMR 移动，连接刷板的接触器会断开；充电结束则先结束电流传输，再退出充电流程。
4. 手册单独列出在线充电的残余风险：导电异物跨接刷板可能短路；接触带电刷板可能造成触电。制造商说明该产品刷板标称电压低于 50 V DC，但仍将触电列为残余风险，并要求执行充电站和车载充电模块的预防性维护。

**不能从该案例推导的结论：** 手册中的 CAN 握手、软件许可和接触器时序，不足以证明 CAN 本身是安全通信，也不足以证明接触器回路满足任何特定 PL/SIL、诊断覆盖或单故障性能；本页也没有该项目充电站的实际 SKU、原理图、接触器反馈、保护等级或认证证据。低于 50 V DC 也不得泛化为所有直流触点在所有环境下“无触电风险”。

### 8.4 自动充电状态机应补齐的安全条件

在既有 DOCKED → PRECHECK → CHARGING → COMPLETE → UNDOCK 状态机基础上，项目设计至少应明确：

- **上电许可：** 只有车辆和充电站均确认正确停靠、机械位置/触点状态满足要求、BMS 允许充电且协议握手有效后，才允许充电输出接触器动作。SOC 低或调度系统派单不能单独构成电气充电许可。
- **持续监控：** 充电时监测车辆位置/运动状态、通信存活、BMS 充电许可、电压/电流/温度及充电器故障状态。明确谁拥有最终断能权，以及失联、越位或许可撤销时的输出行为。
- **先断能、后分离：** 退出充电前先停止电流传输，确认输出接触器已断开且触点电压/电流达到项目定义的可安全分离条件，再允许机械脱离和机器人驶离。阈值必须来自准确器件规格、风险评估和测试，不能从其他型号照搬。
- **异常失效与恢复：** 验证通信中断、错位/触点弹跳、接触器粘连、输出残压、BMS 拒绝/温度越限、外部急停、突然掉电和恢复供电等场景。故障恢复不得仅凭通信重新连上就自动再次给刷板上电；应重新执行停靠和许可检查，并按风险定义是否需要人工复位。
- **人身与异物防护：** 分析刷板/针脚可触及性、金属异物跨接、雨水/导电污染、清洁维护、工具接触、磨损和接触压力；按需要设计遮蔽、隔离、互锁、维护断能与警示。

### 8.5 建议的项目验证矩阵（测试阈值待具体规格确定）

| ID | 验证主题 | 主要证据 | 限制 |
| --- | --- | --- | --- |
| CHG-01 | 未停靠/错位/未握手时输出保持断能 | 位置输入、通信日志、接触器命令/反馈、触点电压记录 | 需明确对接容差和输出电压阈值 |
| CHG-02 | 通信中断、状态非法或 BMS 撤销许可 | 故障注入记录、输出断能时序、恢复状态 | 不能假设普通 CAN 即为安全通信 |
| CHG-03 | 充电时车辆运动或离开停靠位置 | 运动/位置事件、接触器断开、实际电流衰减记录 | 需在机械受控和批准限能条件下测试 |
| CHG-04 | 电流降至允许断开条件后再分离 | 电流、触点电压、机械脱离时序 | 限值绑定具体连接器/充电器和风险评估 |
| CHG-05 | 接触器粘连、反馈不一致或输出残压 | 单故障分析、反馈诊断、独立断能路径和实测 | 未经审批不得在裸露带电触点上做破坏性试验 |
| CHG-06 | 异物跨接、触点可触及性、错位和污染 | 结构审查、探具/防护评估、受控短路防护测试 | 禁止用人员或徒手导电物代替测试夹具 |
| CHG-07 | 触点温升、接触电阻、磨损及环境适应 | 多循环温升/压降/寿命数据、环境记录 | 按准确材料、连接器和实际充电曲线制定限值 |
| CHG-08 | 断电、恢复供电和故障复位 | 掉电/重启日志、接触器默认状态、重新上电授权记录 | 必须证明不会未经许可自动重新上电 |
