# 充电桩与自动充电

> 自动充电是机器人、充电设备、BMS、现场基础设施和调度系统组成的系统功能。充电电压、电流、倍率、接口和对接公差必须针对具体电池包与充电设备确认，不存在适用于所有 AMR 的通用规格。

## 先修知识与学习目标

先阅读 [[电池与电源]]、[[09-03-电子电气设计]] 和 [[多机调度流程]]。理解电压、电流、功率、容量 Ah、能量 Wh、充电倍率 C，以及充电许可与故障状态。

完成本页后应能画出充电系统接口图、定义充电状态机、识别主要失效模式，并形成供应商接口和验证清单。

## 1. 充电系统边界

至少包括：电池包/电芯、BMS、充电器或充电桩、连接器/触点、车辆侧配电与控制器、机械对接结构、通信接口、地面基础设施、调度系统和现场人员操作。

系统设计前先确认：
- 电池包准确型号、串并联、电压范围、允许充电电流/功率和温度窗口；
- 充电器输出范围、限流/恒压行为、纹波、隔离、保护、散热和故障输出；
- 连接器额定值、触点材料/镀层、温升、插拔寿命、对接公差和防误触；
- 通信协议、握手责任、超时、掉线后的输出状态和恢复逻辑；
- 停车定位、机械容差、地面平整度、排水/粉尘、人员可达和防火要求。

## 2. 充电方式

| 方式 | 主要特点 | 需要重点验证 |
| --- | --- | --- |
| 接触式自动充电 | 弹片、插头或自动对接触点 | 触点接触电阻、温升、电弧、磨损、污染、极性、防触电和插拔寿命 |
| 人工插接充电 | 结构较简单，依赖操作人员 | 防误插、连接器额定值、操作程序、断开次序和人员安全 |
| 无线充电 | 无裸露电气触点，可改善部分环境适应性 | 线圈对准容差、异物检测、效率、发热、电磁兼容、通信和故障保护 |
| 换电/可更换电池 | 可缩短补能停机时间 | 电池重量、吊装/插拔安全、互锁、防错、批次追溯、备用电池管理 |

不应将乘用车无线充电标准或某个厂商的频率/功率方案直接套用到机器人；必须确认标准适用范围和实际设备的认证资料。

## 3. 自动回充状态机

```
IDLE
  → REQUESTED（电量/任务预测/运维指令触发）
  → RESERVED（调度系统分配充电位）
  → APPROACH（进入对接路线和限制速度）
  → DOCKED（机械/电气连接状态确认）
  → PRECHECK（BMS、温度、电压、极性、绝缘和互锁检查）
  → CHARGING（按电池包允许的电流/电压闭环充电）
  → COMPLETE（达到终止条件并确认电流降至安全断开范围）
  → UNDOCK（断开并确认输出状态）
  → AVAILABLE
任一阶段发现异常 → FAULT（停止充电、进入定义的安全状态、记录原因）
```

关键原则：
1. SOC 阈值只是调度触发条件，不是电气充电许可。
2. 充电器启动前要确认电池包状态、连接状态、温度窗口、允许充电电流和互锁。
3. 充电期间持续监控电压、电流、温度、通信状态和设备故障。
4. 通信中断、触点过温、异常电压、绝缘故障或人员防护触发时，必须按安全设计停止能量传输。
5. 停止充电、断开连接器和机器人驶离之间必须定义互锁与时序；不能在触点仍承载电流时随意拔插。
6. 故障复位要明确故障消除条件和人工授权，不得无限自动重试。

## 4. 充电倍率和时间估算

充电倍率 C 的近似定义：

`I_charge(A) = C_rate × Q_capacity(Ah)`

但实际允许电流由电芯型号、串并联、电池包温度、SOC、BMS 限流、充电器能力、线束和热设计共同决定。不能把 0.5C、1C 或 2C 写成所有电池的通用充电倍率。

理想化能量估算：

`t_ideal(h) ≈ E_to_add(Wh) / P_average_charge(W)`

真实充电时间还受恒压阶段电流下降、温度限流、均衡、通信握手和运营策略影响；应使用电池包/充电器正式曲线和实测任务周期。

## 5. 采购接口控制表

| 接口 | 双方必须确认 |
| --- | --- |
| 电气 | 输出电压范围、电流/功率、隔离、纹波、极性、防反接、短路/过温保护、接地/保护联结 |
| 电池/BMS | 允许充电窗口、温度限值、限流/截止条件、SOC/SOH/故障字、协议版本 |
| 机械 | 定位基准、接触压力、对接公差、浮动补偿、磨损件更换和防夹 |
| 通信 | 物理层、协议/版本、超时、重连、认证、异常和日志 |
| 环境 | 防护等级、温度、湿度、粉尘、水、腐蚀、振动和清洁方式 |
| 服务 | 故障码、远程诊断、备件、维护周期、固件升级和变更通知 |

接口协议可能是 CAN、RS-485、以太网或厂商定义方案；不得默认所有充电系统都使用 CAN。

## 6. 安全与验证

至少规划以下验证：空载/满载对接误差、触点温升和接触电阻、长周期插拔磨损、异常断开、电压/极性错误、过流/短路保护、过温、通信中断、BMS 故障、绝缘/接地（按适用要求）、雨水/粉尘/清洁环境，以及充电期间人员进入和紧急停止。

电池运输试验、工业电池安全要求和整机机器安全是不同层次：
- IEC 62619:2022 涉及工业应用二次锂电芯/电池安全要求与试验；
- UN《试验和标准手册》38.3 涉及锂电池运输相关试验和测试摘要；
- 整机充电系统仍需按目标市场、产品用途和实际安装环境评估适用标准与法规。

## 7. 车队充电调度

常见策略：
- **阈值回充：** SOC 低于设定阈值后申请充电；需防止车辆集中排队。
- **机会充电：** 在任务空闲和运营窗口补能；需核对电池允许的充电策略。
- **前瞻规划：** 结合剩余能量、路线能耗、载荷和充电位可用性决定是否接受任务。
- **轮换/换电：** 按电池批次、健康状态和人员操作风险管理。

SOC 不是绝对准确值；调度系统还应考虑电池温度、SOH、功率限制、任务可完成性、保底返航能量和充电位故障。
