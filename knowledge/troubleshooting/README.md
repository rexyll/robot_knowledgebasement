# 故障诊断与现场运维（Troubleshooting）

本目录记录可复现的故障现象、证据、诊断路径、根因分析、恢复措施和有效性验证。按根目录 TaskPlan 的统一 Guide、Limit 执行，不在本目录另设全局规则。

## 零基础入口

- [机器人系统故障诊断与闭环处理](系统故障诊断与闭环处理.md)：从安全围堵、配置基线和故障复现，到分层诊断、假设验证、根因、CAPA/FRACAS 和量产/售后横向展开。

## 后续专题（待建设）

- 电源、电池、BMS 与充电故障。
- 电机、驱动器、编码器、传动和热故障。
- LiDAR、相机、IMU、时间同步、标定和数据质量故障。
- ROS 2 节点、DDS/QoS、网络、时钟和资源故障。
- 定位、建图、导航、规划、抓取与控制故障。
- 云端、OTA、车队调度、客户现场与远程运维故障。
- 生产不良、供应商批次、返工返修和现场质量问题。

## 每张故障知识卡的最低信息

故障 ID、适用型号/版本、序列号或批次范围、发生条件、可复现步骤、原始证据、风险级别、候选假设、已排除原因、经验证根因、纠正/预防措施、回归证据、复发观察和知识来源。

## 使用边界

报警码不自动等于根因；重启恢复不等于故障关闭；单台维修成功不等于批次风险已排除。安全相关故障必须按专业风险评估和组织程序处理，禁止绕过安全装置来复现问题。
