# 电机与驱动器

> 电机和驱动器必须作为一个机电系统选型。不能仅按“额定功率”或一个峰值扭矩数字选型；负载曲线、传动比、工作循环、热条件、反馈、供电和安全功能都会改变结果。

## 先修知识与学习目标

先理解力、力矩、角速度、功率、电流、电压、减速比和占空比。完成本页后应能区分常见电机类别，读懂扭矩—转速曲线，按任务计算初步电机需求，列出驱动器接口与验证项目。

## 1. 电机类型与适用性

| 类型 | 工作特点 | 常见用途 | 主要限制/检查点 |
| --- | --- | --- | --- |
| 有刷直流电机 | 电刷/换向器完成换向，驱动相对简单 | 小型教具、低成本执行机构 | 电刷磨损、电磁干扰、维护寿命和火花 |
| 步进电机 | 按步进指令移动，开环配置可能不测量真实位置 | 轻载定位轴、仪器、实验平台 | 负载变化/加速度过高可能失步；低速共振、发热和保持电流 |
| 无刷永磁电机（BLDC/PMSM） | 永磁转子与电子换向；具体反电势、绕组和控制实现依电机而异 | 轮驱、关节、云台、无人机等 | 需要匹配驱动器、电压/电流、反馈和冷却；BLDC/PMSM 名称应结合电机结构与驱动方式判断 |
| 交流伺服系统 | 通常是电机、反馈器件和伺服驱动器组合 | 工业轴、机器人关节和高动态控制 | 需要核对完整系统的扭矩速度曲线、反馈、总线、调试和安全功能 |
| 空心杯/无铁芯电机 | 转子结构降低某些转动惯量和齿槽效应 | 小型精密执行器、灵巧手部件 | 热容量、峰值/连续能力、机械强度和驱动匹配 |
| 直线电机 | 直接输出直线推力，省去传统旋转到直线传动环节 | 高速直线轴、精密设备 | 行程、磁轨、散热、导向、供电和防护成本 |
| 舵机/一体化执行器 | 将电机、减速机构、控制和反馈集成在一个产品中 | 教育机器人、关节模组、轻型机构 | 必须核对实际负载能力、接口、热降额、齿隙、持续工作能力和寿命 |

“伺服”通常表示闭环控制系统/产品形态，不是某一种独立电机物理类型。比较方案时要对比完整的电机、驱动器、反馈和传动组合。

## 2. 从任务曲线推导扭矩、转速和功率

先定义负载端的任务曲线：位置、速度、加速度、外载、循环周期、停歇时间、启动次数、环境温度和预期寿命。

旋转机械功率关系：

`P = T × ω`

其中功率 `P` 的单位为 W，扭矩 `T` 为 N·m，角速度 `ω` 为 rad/s。

经减速机构驱动时，初步关系为：

`T_load_side ≈ T_motor × i × η`

其中 `i` 为减速比，`η` 为对应方向、速度、负载和温度条件下的传动效率。该式是理想化选型关系，不包含齿隙、弹性、惯量、效率变化和瞬态峰值的完整模型。

选型步骤：
1. 明确工作端负载力/力矩、运动行程、速度、加速度和外部扰动。
2. 把负载惯量、传动比和传动惯量折算到电机轴；核对加速、减速和反向工况。
3. 计算每个运动段的扭矩—转速工作点，检查是否落在制造商的连续/间歇工作区。
4. 根据实际工作循环计算 RMS 扭矩或采用制造商认可的热模型，不能把瞬时峰值当连续额定。
5. 检查母线电压、持续/峰值电流、驱动器过载时间、制动/再生能量和电源吸收能力。
6. 评估温升、冷却、噪声、振动、安装姿态、环境防护、寿命和维护周期。

## 3. 必须从数据表读取的关键参数

| 参数 | 应核对内容 | 常见误区 |
| --- | --- | --- |
| 连续额定扭矩/电流 | 规定冷却、环境温度、转速和工作制下的额定值 | 不同冷却/安装条件的额定值不可直接比较 |
| 峰值扭矩/电流 | 峰值持续时间、重复间隔、温度初始条件和保护限制 | 峰值不代表可长期输出，也不是通用“额定的 3 倍” |
| 扭矩常数/反电势常数 | 单位、定义、温度和换算约定 | Kt 与 Ke 的单位体系和定义可能不同 |
| 转速范围 | 额定转速、最高机械转速、弱磁区和负载曲线 | 最高转速时可用扭矩通常不同于低速 |
| 转子惯量 | 匹配负载惯量、加速和伺服稳定性 | 不能只按静态扭矩选电机 |
| 反馈 | 编码器类型、分辨率、绝对/增量、单圈/多圈、接口 | 位数/PPR 不等于整机定位精度 |
| 热与环境 | 绕组/壳体温度限制、传感器、冷却、IP、振动 | 防护等级不等于耐腐蚀或适合所有清洁剂 |
| 驱动器 | 输入电压、连续/峰值电流、控制模式、反馈兼容、再生能力 | “额定功率相同”不表示兼容 |
| 安全功能 | 如 STO、SS1、SLS 等具体功能及认证/验证条件 | 普通限流、堵转保护不是安全功能 |

## 4. 驱动器与控制环

典型伺服/无刷驱动的功能层包括功率级、位置/速度/电流控制、反馈解码、故障诊断和通信接口。FOC（磁场定向控制）是永磁交流电机常见控制方法之一，但不是所有电机/所有驱动都使用同一实现。

典型闭环：
- 电流/转矩控制：按电流测量和电机模型调节电磁转矩；
- 速度控制：根据编码器/估算器反馈调节转速；
- 位置控制：根据位置反馈控制轨迹；
- 上层轨迹规划：提供有限幅值和动态约束的目标。

环路带宽、采样率、PWM 频率和滤波器参数必须从实际驱动器手册和整机稳定性测试中确定，不使用本页设定固定通用 kHz 数值。

## 5. 通信与系统集成

常见接口包括脉冲/方向、模拟量、UART/RS-485、CAN/CANopen、EtherCAT 及厂商专用协议。选择时考虑：
- 轴数、更新周期、同步精度、拓扑、布线距离和电磁环境；
- 对象字典/过程数据、控制状态机、故障码和安全状态；
- 时间同步、丢包/掉线行为、启动顺序和恢复流程；
- 驱动器配置工具、固件版本、参数备份和售后生命周期。

总线节点数、实际带宽、延迟和同步误差受具体协议栈、设备实现、网络拓扑和配置影响，不可仅依据理论链路速率推断可用性能。

## 6. 选型示例：先做需求，不先挑型号

教学示例：假设负载端在某运动区间需要 8 N·m，减速比为 10，假设该工况效率为 0.8，则电机轴侧稳态扭矩的初步估算为：

`T_motor ≈ 8 / (10 × 0.8) = 1 N·m`

这只是某个工作点的近似。真实选型仍需补上加速惯量、启动/制动、重复工作循环、热条件、连续/峰值曲线、转速和驱动器电流，并校核安全与寿命要求。

## 7. 量产与验证成果物

- 负载任务曲线和扭矩/转速工作点；
- 电机、驱动器、反馈器件和减速机构的准确型号及数据表版本；
- 热模型、惯量匹配、供电与再生能量预算；
- 总线/端口定义、线束与 EMC 设计；
- 参数配置备份、固件版本、校准和生产测试规范；
- 温升、扭矩/速度、重复定位、耐久、振动、噪声和故障恢复报告；
- 关键器件供应商变更、停产和替代评估记录。
