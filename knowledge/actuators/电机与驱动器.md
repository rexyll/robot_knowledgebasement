# 电机与驱动器

> 电机和驱动器必须作为一个机电系统选型。不能仅按“额定功率”或一个峰值扭矩数字选型；负载曲线、传动比、工作循环、热条件、反馈、供电和安全功能都会改变结果。

## 先修知识与学习目标

先理解力、力矩、角速度、功率、电流、电压、减速比和占空比。完成本页后应能区分常见电机类别，读懂扭矩—转速曲线，按任务计算初步电机需求，列出驱动器接口与验证项目。

## 1. 电机类型与适用性

| 类型 | 工作特点 | 常见用途 | 主要限制/检查点 |
| --- | --- | --- | --- |
| 有刷直流电机 | 电刷/换向器完成换向，驱动相对简单 | 小型教具、低成本执行机构 | 电刷磨损、电磁干扰、维护寿命和火花 |
| 步进电机 | 按步进指令移动，开环配置可能不测量真实位置 | 轻载定位轴、仪器、实验平台 | 负载变化/加速度过高可能失步；低速共振、发热和保持电流 |
| 无刷永磁电机（BLDC/PMSM） | 永磁转子与电子换向；具体反电势、绕组和控制实现依电机而异 | 轮驱、关节、云台、无人机等 | 需要匹配驱动器、电压/电流、反馈和冷却；BLDC/PMSM 名称应结合电机结构与驱动方式判断 |
| 交流伺服系统 | 通常是电机、反馈器件和伺服驱动器组合 | 工业轴、机器人关节和高动态控制 | 需要核对完整系统的扭矩速度曲线、反馈、总线、调试和安全功能 |
| 空心杯/无铁芯电机 | 转子结构降低某些转动惯量和齿槽效应 | 小型精密执行器、灵巧手部件 | 热容量、峰值/连续能力、机械强度和驱动匹配 |
| 直线电机 | 直接输出直线推力，省去传统旋转到直线传动环节 | 高速直线轴、精密设备 | 行程、磁轨、散热、导向、供电和防护成本 |
| 舵机/一体化执行器 | 将电机、减速机构、控制和反馈集成在一个产品中 | 教育机器人、关节模组、轻型机构 | 必须核对实际负载能力、接口、热降额、齿隙、持续工作能力和寿命 |

“伺服”通常表示闭环控制系统/产品形态，不是某一种独立电机物理类型。比较方案时要对比完整的电机、驱动器、反馈和传动组合。

## 2. 从任务曲线推导扭矩、转速和功率

先定义负载端的任务曲线：位置、速度、加速度、外载、循环周期、停歇时间、启动次数、环境温度和预期寿命。

旋转机械功率关系：

`P = T × ω`

其中功率 `P` 的单位为 W，扭矩 `T` 为 N·m，角速度 `ω` 为 rad/s。

经减速机构驱动时，初步关系为：

`T_load_side ≈ T_motor × i × η`

其中 `i` 为减速比，`η` 为对应方向、速度、负载和温度条件下的传动效率。该式是理想化选型关系，不包含齿隙、弹性、惯量、效率变化和瞬态峰值的完整模型。

选型步骤：
1. 明确工作端负载力/力矩、运动行程、速度、加速度和外部扰动。
2. 把负载惯量、传动比和传动惯量折算到电机轴；核对加速、减速和反向工况。
3. 计算每个运动段的扭矩—转速工作点，检查是否落在制造商的连续/间歇工作区。
4. 根据实际工作循环计算 RMS 扭矩或采用制造商认可的热模型，不能把瞬时峰值当连续额定。
5. 检查母线电压、持续/峰值电流、驱动器过载时间、制动/再生能量和电源吸收能力。
6. 评估温升、冷却、噪声、振动、安装姿态、环境防护、寿命和维护周期。

## 3. 必须从数据表读取的关键参数

| 参数 | 应核对内容 | 常见误区 |
| --- | --- | --- |
| 连续额定扭矩/电流 | 规定冷却、环境温度、转速和工作制下的额定值 | 不同冷却/安装条件的额定值不可直接比较 |
| 峰值扭矩/电流 | 峰值持续时间、重复间隔、温度初始条件和保护限制 | 峰值不代表可长期输出，也不是通用“额定的 3 倍” |
| 扭矩常数/反电势常数 | 单位、定义、温度和换算约定 | Kt 与 Ke 的单位体系和定义可能不同 |
| 转速范围 | 额定转速、最高机械转速、弱磁区和负载曲线 | 最高转速时可用扭矩通常不同于低速 |
| 转子惯量 | 匹配负载惯量、加速和伺服稳定性 | 不能只按静态扭矩选电机 |
| 反馈 | 编码器类型、分辨率、绝对/增量、单圈/多圈、接口 | 位数/PPR 不等于整机定位精度 |
| 热与环境 | 绕组/壳体温度限制、传感器、冷却、IP、振动 | 防护等级不等于耐腐蚀或适合所有清洁剂 |
| 驱动器 | 输入电压、连续/峰值电流、控制模式、反馈兼容、再生能力 | “额定功率相同”不表示兼容 |
| 安全功能 | 如 STO、SS1、SLS 等具体功能及认证/验证条件 | 普通限流、堵转保护不是安全功能 |

## 4. 驱动器与控制环

典型伺服/无刷驱动的功能层包括功率级、位置/速度/电流控制、反馈解码、故障诊断和通信接口。FOC（磁场定向控制）是永磁交流电机常见控制方法之一，但不是所有电机/所有驱动都使用同一实现。

典型闭环：
- 电流/转矩控制：按电流测量和电机模型调节电磁转矩；
- 速度控制：根据编码器/估算器反馈调节转速；
- 位置控制：根据位置反馈控制轨迹；
- 上层轨迹规划：提供有限幅值和动态约束的目标。

环路带宽、采样率、PWM 频率和滤波器参数必须从实际驱动器手册和整机稳定性测试中确定，不使用本页设定固定通用 kHz 数值。

## 5. 通信与系统集成

常见接口包括脉冲/方向、模拟量、UART/RS-485、CAN/CANopen、EtherCAT 及厂商专用协议。选择时考虑：
- 轴数、更新周期、同步精度、拓扑、布线距离和电磁环境；
- 对象字典/过程数据、控制状态机、故障码和安全状态；
- 时间同步、丢包/掉线行为、启动顺序和恢复流程；
- 驱动器配置工具、固件版本、参数备份和售后生命周期。

总线节点数、实际带宽、延迟和同步误差受具体协议栈、设备实现、网络拓扑和配置影响，不可仅依据理论链路速率推断可用性能。

## 6. 选型示例：先做需求，不先挑型号

教学示例：假设负载端在某运动区间需要 8 N·m，减速比为 10，假设该工况效率为 0.8，则电机轴侧稳态扭矩的初步估算为：

`T_motor ≈ 8 / (10 × 0.8) = 1 N·m`

这只是某个工作点的近似。真实选型仍需补上加速惯量、启动/制动、重复工作循环、热条件、连续/峰值曲线、转速和驱动器电流，并校核安全与寿命要求。

## 7. 量产与验证成果物

- 负载任务曲线和扭矩/转速工作点；
- 电机、驱动器、反馈器件和减速机构的准确型号及数据表版本；
- 热模型、惯量匹配、供电与再生能量预算；
- 总线/端口定义、线束与 EMC 设计；
- 参数配置备份、固件版本、校准和生产测试规范；
- 温升、扭矩/速度、重复定位、耐久、振动、噪声和故障恢复报告；
- 关键器件供应商变更、停产和替代评估记录。

## 8. IEC 61800-5-2:2026 修订版的适用范围与系统边界（2026-11-05）

IEC 官方目录当前列出 **IEC 61800-5-2:2016+AMD1:2026 CSV**，合并版为 Edition 2.1，发布日期 2026-10-30，状态 Valid。CSV（Consolidated Version）将修订内容并入基础出版物；不能只看基础版年份而遗漏后续修订。官方页面列出的技术变化包括术语统一为 safety sub-function、增加 PDS(SR) 热/机械抗扰要求、更新参数化和测试要求，以及补充电磁、热和机械抗扰测试内容。来源：[[链接台账]] #896。

### 8.1 标准对象不是“任意电机驱动器”

该标准是产品标准，针对 IEC 61800 系列范围内的可调速电力驱动系统，规定安全相关电力驱动系统（PDS(SR)）的功能安全设计、开发、集成和验证要求。应先判断具体设备是否属于其产品范围，再核对制造商声明、准确硬件/固件版本、适用安全子功能和安全性能数据；不能因设备是伺服驱动器、变频器或带有安全端子，就直接宣称适用或符合。

### 8.2 标准不能替代应用层风险分析

IEC 61800-5-2 的范围说明将 PDS(SR) 本身的产品级集成与其进入机器/装置安全相关应用后的系统集成区分开来。该标准不替具体机器或应用完成：
- 特定机器/机器人应用的危险与风险分析；
- 识别该应用需要哪些安全子功能，或对这些安全子功能进行初始 SIL 分配；
- 被驱动设备本体的要求（驱动接口安排除外）；
- 生产/制造过程中的次生危险，以及 PDS(SR) 自身的制造过程要求；
- PDS(SR) 输入信号和命令有效性的保证；
- 网络安全或 PDS(SR) 访问安全等 security aspects。

电气、热和能量安全考虑由 IEC 61800-5-1 覆盖，不应把它们误认为 IEC 61800-5-2 的功能安全子功能要求。应用层仍须依据整体机器/装置风险评估确定安全需求，并验证完整的传感器—逻辑—驱动—制动/保持—机械负载链路。

因此，驱动器资料中列出 STO、SS1、SLS 等名称，不代表这些功能在当前接线、参数、编码器、制动器、控制器、网络和机械负载组合下已经达到目标风险降低要求。系统集成方仍需根据机器风险评估确定安全需求，并验证传感器、逻辑、驱动安全子功能、制动/保持装置、机械结构和最终停止行为的完整链路。

### 8.3 需求模式与安全术语边界

IEC 61800-5-2 主要面向高需求或连续运行模式下的 PDS(SR)。应避免把“低需求模式不属于本标准的主要要求范围”误写成“低需求模式下不得使用相关安全子功能”：公开范围文本说明，高需求/连续模式下实现的安全子功能也可能用于低需求模式，但低需求模式的要求应依据 IEC 61508 系列；Annex F 仅提供在给定 PFH 条件下估算 PFDavg 的指导，不能据此推断本标准完整覆盖低需求模式。2026 修订版也将相关功能术语统一为 **safety sub-function（安全子功能）**。阅读旧版资料、驱动器手册和证书时，要核对术语、版次与声明范围，避免把产品子功能等同于整机安全功能。

### 8.4 驱动器安全证据检查表

采购、设计评审和集成验证至少要求供应商给出：
1. 标准编号、版次/修订、证书或评估报告编号、发证/评估机构及适用地区；
2. 准确产品型号、硬件/固件版本、选件和参数化限制；
3. 每项安全子功能的边界、触发条件、响应行为、PFH/PFD/SIL/PL 等声明及其适用前提（仅记录供应商实际声明，不自行推定）；
4. 对编码器、制动器、接触器、外部逻辑、通信和供电的依赖及排除项；
5. 故障反应、复位/重启行为、诊断覆盖、测试间隔和维护要求；
6. 温度、振动、EMC、安装和污染条件限制，以及版本变更/停产通知；
7. 系统级安全需求追踪、验证记录和异常工况测试证据。

## 9. 驱动安全子功能与机器级停止功能的边界（2026-11-15）

驱动器中的安全子功能属于安全相关电力驱动系统（PDS(SR)）的组成部分；它们不能单独代表整台机器的急停、风险降低或安全状态。功能名称相同，也不代表不同厂商、不同硬件/固件、选件和参数组合具有相同实现。

### 9.1 常见驱动安全子功能

| 功能 | 核心作用 | 设计/验证时必须注意 |
| --- | --- | --- |
| STO（Safe Torque Off，安全转矩关闭） | 阻止驱动输出级继续产生驱动电机的转矩。 | 运动中的电机可能自由滑行；STO 不提供受控减速，也不等同于机械制动或电源隔离。检查负载是否会因重力、惯性或外力继续运动。 |
| SS1（Safe Stop 1，安全停止 1） | 先执行受控停止过程，再进入 STO。 | 需核对设备实现的是时间监控、减速斜坡监控还是其他允许形式；停止斜坡、监控阈值、计时器和最终 STO 时刻都必须按准确型号/配置验证。 |
| SS2（Safe Stop 2，安全停止 2） | 使驱动受控停止，并转入安全运行停止相关状态。 | 与仅切断转矩的 STO 不同，通常还涉及位置/速度监控能力；应核对所需反馈、监控限值和失效反应。 |
| SOS（Safe Operating Stop，安全运行停止） | 对停止状态进行安全监控，允许驱动保持维持位置所需的控制能力。 | 不是断电隔离，也不自动等于机械抱闸；垂直轴、外力负载和失电场景需要独立处理。 |
| SBC（Safe Brake Control，安全制动控制） | 通过安全输出控制外部机械保持制动器。 | 必须核对制动器本体、制动力矩、响应/磨损、输出回路、反馈和失电行为；有 SBC 名称不等于任意机械制动器均满足安全需求。 |
| SLS（Safely-Limited Speed，安全限速） | 对驱动速度进行安全限制/监控。 | 依赖具体的速度测量或估算路径、编码器/反馈配置、阈值、容差和故障反应；不同选件的可用性不同。 |
| SDI（Safe Direction，安全方向） | 监控运动方向是否符合设定方向。 | 核对方向判定、零速附近行为、反馈器件和配置限制；不得将普通软件方向限制当作 SDI。 |
| SMS/SSM 等监控功能 | 对安全最大速度或安全速度状态进行相应监控。 | 名称、功能范围、输出语义和适用条件需按具体产品手册核对；不能推定每台驱动器都具备。 |

以上是概念层解释，不是各厂商功能定义的替代品。功能的标准术语、产品实现名称、类别/停止类别、诊断和安全数据必须以适用版次标准及该驱动器受控手册为准。

### 9.2 STO、机械制动、电气隔离和急停不是同一概念

1. **STO 不等于停止到零速。** ABB ACS880 系列资料明确指出，运行中的电机在 STO 触发后可能自由滑行停止；如果滑行本身不可接受，必须先采用适当的停止方式，再触发 STO。
2. **STO 不等于断开电源或安全隔离。** ABB 对具体驱动器的警告指出，STO 不会切断主回路和辅助回路电压；电气维修仍须按设备说明隔离主电源及其他电压源，不能用 STO 代替上锁挂牌（LOTO）或隔离装置。
3. **STO 不等于机械保持。** 垂直轴、悬挂负载、弹性储能或受外力负载可能在失去电机转矩后继续运动；需要时应评估独立制动器、平衡机构、机械止挡和安全制动控制。
4. **驱动安全子功能不自动等于机器急停功能。** ISO 13850 规定机器急停功能的功能要求和设计原则，电气实现还需结合 IEC 60204-1。驱动器 STO、SS1 或其他子功能可以作为安全控制系统的最终执行环节之一，但按钮、逻辑、停止类别、驱动器、制动、能量切断、复位和防止意外重启必须作为完整机器功能进行风险评估和验证。
5. **停止类别不能直接从驱动器功能名称推断。** 应依据机器适用标准和风险评估选择停止策略，并确认断电、掉线、单通道故障、驱动器故障、制动器失效、反馈失效及恢复供电等工况。

因此，项目资料、采购规格或测试报告不得仅凭“支持 STO/SS1/SLS”就声称设备具备急停、人员保护或整机达到某一 PL/SIL。

### 9.3 制造商资料示例：功能取决于产品配置

- **Siemens SINAMICS S120：** Siemens 2026 年 1 月的 Motion Control Drives D21-3 资料将 STO、SS1 和 SBC 列为不同功能；资料对 SS1 描述了经参数化延时后转入 STO 的行为，并把 SBC 标注为配置激活时的底层功能。功能控制输入、选件模块、反馈要求和许可范围也按功能分别列示。该资料只能说明 S120 产品系列中的特定实现与选件边界，不能外推到全部 SINAMICS 型号。
- **ABB ACS880：** ABB ACS880-01 硬件手册区分驱动器标准 STO 与通过 FSO-12/FSO-21 等安全功能模块实现的 SS1、SBC、SLS 等功能，并明确外部安全回路接线和模块配置由机器制造商负责。另一个 ACS880-M04 官方手册明确指出 STO 触发后电机可能滑行、主/辅助回路仍可能带电；针对永磁或 SynRM 电机的特定多 IGBT 故障场景，手册还提示可能出现对齐转矩。该故障提示只适用于手册明确列出的产品/电机条件，不能推广为所有驱动器的统一行为。
