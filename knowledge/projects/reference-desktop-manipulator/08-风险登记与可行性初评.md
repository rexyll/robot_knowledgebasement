# 08｜风险登记与可行性初评

## 0. 评估性质

本文件是概念阶段的初始危险源/风险登记入口，不是正式风险评估、功能安全分析、认证文件或安全使用说明。当前没有冻结的机械结构、关节驱动、电源、安全部件和使用场景，因此**严重度、发生概率、暴露、可避免性、风险等级、PLr/SIL、保护距离、停止时间/距离均保持 TBD**。不得依据本清单自行操作真实危险设备。

项目范围暂定为固定工作台、预定位托盘、已知工件、受监督室内环境。仍须通过用户/场景研究确认人员如何接近、谁可操作、谁可维护、何时允许运动以及异常时如何撤离。

配套风险记录见 [09 初始风险登记矩阵](09-初始风险登记.csv)。矩阵中的 TBD 不代表低风险或风险已接受。

## 1. 风险登记方法

每条风险必须沿下列链条描述：

1. **危险源**：能够造成伤害或损害的运动、温度、电气、结构、控制或储能状态。
2. **危险情况**：人员/物体何时、如何暴露于危险源；覆盖正常、异常、维护、调试、清洁、运输和可预见误用。
3. **可能后果**：对人员、设备、工件、数据和业务的潜在伤害或损害。
4. **风险估计**：依据产品边界、目标地区、预期用途和适用方法，由胜任人员确定严重度、暴露、可避免性等输入及风险等级。
5. **风险降低措施**：优先考虑本质安全设计，再考虑防护/保护措施，最后是信息告知；措施必须有负责人和验证证据。
6. **残余风险与复核**：记录采取措施后的残余风险、用户信息、维护条件、变更触发和批准责任。

最终方法、风险矩阵和接受准则应按适用标准、产品类型、地区和组织程序确定。没有正式输入时不能套用通用数字矩阵，也不能提前填定 PLr/SIL 或保护距离。

## 2. 初始危险源覆盖面

| 风险 ID | 初始危险源/失效场景 | 需要分析的问题 | 后续证据方向 |
|---|---|---|---|
| HAZ-001 | 关节/连杆运动导致夹挤、剪切或碰撞 | 人员可达范围、机械间隙、运动方向、速度/力、维护状态、保护装置 | 场景风险评估、几何/速度分析、保护设计和目标配置验证 |
| HAZ-002 | 夹爪/工件脱落或夹持失败 | 工件质量/质心、夹持方式、失压/失电、夹持反馈、下方人员/物品 | 负载谱、抓取保持试验、故障状态和防护验证 |
| HAZ-003 | 误启动、意外重启或异常运动 | 启动权限、复位语义、通信恢复、控制状态机、维护模式 | 状态机评审、故障注入、保护功能验证 |
| HAZ-004 | 电击、短路、过流、过温或火灾 | 电源条件、绝缘、接地、保护协调、连接器、线束、检修隔离 | 电气设计审查、准确器件资料、合适试验与专业评审 |
| HAZ-005 | 储能释放、制动失效或重力轴下坠 | 断电/失联后关节行为、制动器、重力负载、维修程序 | 载荷与制动分析、故障状态验证、维修安全评审 |
| HAZ-006 | 结构、紧固件、减速器或安装失效 | 动态载荷、疲劳、连接松脱、工作台稳定性、工具和工件惯量 | 结构计算、紧固/装配控制、耐久与检查方案 |
| HAZ-007 | 热表面、驱动器/电机过热或材料老化 | 连续任务、冷却、机壳表面温度、堵转、故障保护 | 热预算、热稳态测试、温度监测和异常反应 |
| HAZ-008 | 传感器/编码器/控制软件故障导致危险动作 | 反馈丢失、错位、时间戳错误、参数损坏、限位失效 | FMEA/FTA、诊断覆盖、独立保护和故障注入 |
| HAZ-009 | 调试、标定、清洁和维修过程暴露 | 维护权限、能源隔离、工具空间、旁路控制、残余运动 | 维护模式分析、授权/培训、隔离和维修规程 |
| HAZ-010 | 未授权访问/配置变更触发动作 | 物理/软件权限、镜像/参数完整性、调试端口、远程接口边界 | 威胁分析、权限设计、日志/变更审计与测试 |
| HAZ-011 | 工件/治具错误装载或不兼容工具 | 工件类别、质量、装夹基准、工具 ID、配方和防错 | 输入校验、工装防错、任务前检查和异常处理 |
| HAZ-012 | 运输、包装、储存或退役中的伤害/损害 | 重量/重心、锐边、残余能源和数据未清理 | 包装运输评审、能源处置、回收/数据清理方案 |

该列表用于发现问题，不代表风险已完整识别。随任务/用户、具体器件、机械布局和维护方案变化，必须新增、合并或重评相关条目并保留变更轨迹。

## 3. 风险控制与验证追踪

每项风险至少映射到：
- 需求矩阵中的 PRD/SYS 需求 ID；
- 机械、电气、控制、软件、末端工具和防护设计文件；
- 风险降低措施的责任人、配置和版本；
- 分析/仿真/台架/实机验证方法和验收判据；
- 失败处置、回归范围、残余风险批准和用户告知。

不能把 ROS/应用层普通软件状态、日志或急停按钮 UI 当作独立安全功能。安全相关设计必须结合目标产品边界、适用标准、器件资料与专业评审，在目标配置上验证。

## 4. 初始可行性结论

| 维度 | 当前判断 | 主要缺口/解除条件 |
|---|---|---|
| 任务定义 | 有教学项目假设，尚未通过真实访谈 | 明确用户/教学目的、工件集合、任务流程和节拍 |
| 运动学 | 有二维入门推导和概念架构，未定义自由度/几何 | 采集目标位姿，建立候选结构、FK/IK/碰撞/奇异点分析 |
| 执行与负载 | 没有载荷谱和准确器件资料 | 完成工件/工具/下游质量和惯量，获取准确供应商曲线 |
| 电气与热 | 没有供电树、负载和热数据 | 建立电源/电流/损耗/热模型并进行专业审核和测试 |
| 安全 | 已列初始危险源，未完成风险估计/措施验证 | 胜任人员按产品/地区/标准开展正式风险评估 |
| 供应链与成本 | 没有准确料号和报价 | 取得正式报价、生命周期/PCN/EOL 和替代料资料 |
| 制造与交付 | 有流程草案，没有工艺能力/试产/质量数据 | 工厂/供应商评审、DFM/DFA/DFT、PVT 和质量验证 |

因此当前结论为：**可以继续开展需求澄清和概念可行性研究；尚不足以批准详细设计、关键器件采购、实物加工或任何有人接近的带电/带载运动试验。** 下一阶段先补齐任务输入和真实工件数据，再开展结构/驱动选型；风险评估随设计迭代持续更新。

## 5. 责任和关闭纪律

- 产品/用户代表确认预期用途、工件和任务要求。
- 机械、电气、控制、软件和制造工程师分别承担其专业设计风险。
- 安全/法规负责人确定适用风险方法、标准和评审要求。
- 验证/质量负责人定义证据、测试配置、回归及残余风险流程。
- 风险不得仅因没有发生事故、演示成功或文字记录存在而关闭；必须有批准的控制措施和证据。
