# 04｜NPI 量产与客户交付路线

## 0. 重要边界

本文件说明参考项目未来如何从工程样机进入制造、量产准备、客户交付和售后。当前没有真实 BOM、供应商报价、工艺能力、试产批次、产线、良率、产能、认证结果或客户数据。所有量产指标阈值必须由实际项目、工厂、供应链、风险和合同要求建立。

## 1. 从设计输出到制造定义

| 设计/工程输入 | 制造侧输出 | 责任角色 |
|---|---|---|
| CAD、工程图、公差、材料 | 受控图纸、检验基准、制造工艺 | 机械/制造工程 |
| 原理图、PCB、线束、连接器 | PCBA/线束工艺、测试点、ICT/FCT 策略 | 电气/制造工程 |
| 电机、减速器、关节/驱动器 | 采购规格、来料检验、序列号/批次追溯、校准工序 | 机械/电气/采购/质量 |
| URDF/SRDF、关节参数、控制配置 | 烧录/配置工序、软件镜像、关节校准和版本记录 | 嵌入式/软件/制造 |
| 末端工具、TCP、标定数据 | 工具安装、标定、抓取功能测试工序 | 机械/控制/测试 |
| 安全分析、保护设计、合规资料 | 安全相关检查、验证记录、出厂文件 | 安全/法规/质量 |
| DVP&R 和测试报告 | 生产测试规范、检验限值和异常反应计划 | 测试/质量 |

## 2. EBOM、MBOM 与配置管理

### EBOM（工程物料清单）
按产品设计结构记录所有零件、组件、软硬件和图纸版本；每项须有唯一料号、描述、数量、单位、修订、批准替代料和设计来源。

### MBOM（制造物料清单）
按制造/装配顺序展开，说明工序用料、耗材、工装关联、损耗、包装物和工位。MBOM 不应只是复制 EBOM；必须体现实际制造、装配、测试和维修需要。

### 初版物料族（未选型号）
- 机械结构：底座、连杆、关节支撑、轴承/连接件、紧固件、护罩；
- 关节/执行：电机、减速器或集成关节、编码器/反馈、驱动器、制动（如设计需要）；
- 末端执行器：夹爪/吸盘、指尖/垫片、气动/电动附件；
- 控制与计算：运动控制器、MCU/实时控制硬件、上位计算、存储、调试接口；
- 传感器：关节反馈、夹爪状态、必要限位/温度/状态传感；
- 电气：电源、配电、保护器件、连接器、线束、接地/屏蔽；
- 安全：物理防护、访问控制、急停/互锁相关器件及其配套；
- 生产与交付：工装、校准件、测试线束、包装、手册和备件。

在架构和采购评审前，上述为物料族，不是可采购 BOM。

## 3. DFM / DFA / DFT 评审

**DFM（可制造性）：** 加工方式、材料可得性、公差能力、加工成本、表面处理、供应风险。

**DFA（可装配性）：** 零件数、装配顺序、可达性、紧固工具空间、线束布置、防错、维护拆装。

**DFT（可测试性）：** 测试点、诊断接口、校准可达性、工位自动化、原始数据导出、软件版本读取。

机械臂特别关注：
- 关节与连杆同轴度、轴承/减速器安装基准；
- 关节线缆弯折、拖链、应力释放和反复运动寿命；
- 工具法兰重复安装、TCP 标定和工具快速更换；
- 关节零位、编码器偏置、传动间隙与温态变化；
- 夹爪指尖、接触垫和工件换型；
- 装配后整机重心、振动、共振与结构变形。

上述项目的允差/检验方式必须由详细设计、供应商数据和测试确定。

## 4. 供应链与供应商质量

对长交期、单一来源、停产风险或安全关键器件优先建立供应商资料包：

- 准确制造商、料号、数据手册和技术规格；
- 生命周期、PCN/EOL 通知渠道、交期和产能承诺；
- 质量体系与关键工艺能力（按采购风险确定审核深度）；
- 来料检验、批次/序列号、合格证明与变更通知；
- 替代料兼容性、重新验证范围和批准权限；
- 退货、失效分析、供应商纠正措施和质量协议。

替代料不允许仅凭外形/接口相似即视为等效；必须核查电气、机械、热、软件/固件、寿命、认证和可维修性影响。

## 5. 工艺流程与工位规划（概念）

| 工序 ID | 工序 | 主要输入 | 关键控制/记录 | 输出 |
|---|---|---|---|---|
| OP-010 | 来料检验 | 零件、批次、供应商文件 | 关键尺寸/电气/外观、检验设备校准 | IQC 记录/放行状态 |
| OP-020 | 机械子组件装配 | 基座、连杆、关节部件 | 紧固、装配基准、防松和操作记录 | 机械子组件 |
| OP-030 | 电气/线束装配 | 驱动器、线束、保护器件 | 针脚、极性、接地、线束固定和目检 | 电气子组件 |
| OP-040 | 整机集成 | 机械、电气、工具 | 接口核对、配置版本、检验点 | 整机待 bring-up |
| OP-050 | 上电与基础检查 | 电源、控制系统 | 受控供电、保护状态、固件和诊断 | 上电检查记录 |
| OP-060 | 校准 | 关节、TCP、工件治具 | 标定工具、零位、坐标版本、校准结果 | 校准报告 |
| OP-070 | 生产测试 | 整机、软件镜像、测试工装 | 功能、运动、抓取、停止/保护验证 | FCT 记录 |
| OP-080 | 最终检验 | 完整产品和资料 | 外观、标签、序列号、文件包和配置 | OQC 放行 |
| OP-090 | 包装/入库 | 放行产品、包装材料 | 防护、运输固定、随箱文件 | 出货记录 |

这是待详细设计与工厂评审的概念工艺，不是已批准作业指导书。紧固扭矩、电气测试限值、标定参数、速度限制和安全测试阈值均不能从本表推断。

## 6. 生产质量体系

必须按实际产品风险和工厂流程建立：

- PFMEA：识别制造过程失效模式、影响、原因、预防/检测控制和行动；
- Control Plan：明确工序、特性、规格来源、测量方法、频率、抽样和异常反应；
- IQC/IPQC/OQC：来料、过程和出货质量控制；
- MSA/GR&R：对关键测量系统进行适用性分析；
- SPC/过程能力：当数据类型、样本和过程稳定性满足统计方法前提时使用；
- NCR/CAPA：不合格品隔离、处置、根因、纠正预防和效果验证；
- ECO/ECN：设计/工艺/供应商/软件/参数变更受控审批；
- 追溯：序列号、关键零件批次、固件/软件、标定、测试和返工记录。

## 7. 序列号和配置追溯

每台产品建议形成一份受控 Unit History Record（UHR）：

| 字段族 | 应追踪的信息 |
|---|---|
| 产品身份 | 产品料号、序列号、生产日期、工厂/工位 |
| 关键机械 | 关节、减速器、轴承、结构件批次/序列号（按风险确定） |
| 关键电气 | 驱动器、控制器、PCB、线束、电源和保护器件版本 |
| 工具/标定 | 末端工具 ID、TCP、关节零位、校准工装和校准记录 |
| 软件配置 | Bootloader、固件、OS、ROS/应用、依赖、参数和镜像哈希 |
| 测试 | 工位/设备 ID、程序版本、原始数据、通过判据、测试员 |
| 质量事件 | 不合格、返工、维修、偏差、CAPA 和批准 |
| 出货服务 | 客户/现场（按隐私规则）、出货配置、安装验收、维修升级 |

## 8. 量产放行条件（须形成真实证据）

- 设计和配置冻结；所有关键变更受控；
- 适用法规/标准与产品技术文件经责任人员评审；
- 供应商和关键物料来源、替代料和生命周期风险可控；
- 工艺路线、工装、作业指导、人员培训已验证；
- PFMEA、Control Plan、检验规范、产测和异常反应已批准；
- 测量/测试设备校准和适用的 MSA 已完成；
- 试生产数据、问题闭环、良率/节拍和产能评估达到事先批准标准；
- 产品序列号、物料批次、软件版本、测试和返工可追溯；
- 出厂检验、包装运输、用户/维护手册和售后准备完成；
- 安全关键问题和法规阻塞项已关闭，或依据正式程序处理；不得用 Conditional Go 绕过。

## 9. 客户交付与售后

交付前：
- 明确客户预期用途、工位空间、基础设施、人员角色和现场风险；
- 检查产品配置、运输状态、配件、工具、包装、安装工装；
- 建立安装、调试、标定、任务配方、客户培训和验收计划；
- 交付操作、维护、故障排查、备件、保修和服务联系信息。

交付中：
- 记录安装配置、现场标定、软件参数、测试结果和异常；
- 按合同/已批准验收要求执行，不以演示代替验收；
- 遗留问题须有影响、责任人、期限、临时控制和客户确认。

交付后：
- 记录服务请求、故障配置、序列号、原始证据、维修/换件和回归；
- 将现场失效链接至设计、供应商和制造批次；
- 运行 FRACAS/CAPA，必要时评估停发、返修、现场措施或召回义务；
- 定义备件库存、软件支持、升级/回滚、产品变更和 EOL 计划。

## 10. 必须引入的外部资源

| 工作 | 所需资源/能力 | 初学者可承担的部分 |
|---|---|---|
| 结构/负载/疲劳设计 | 具备机械设计能力的工程师、必要的计算/测试设施 | 学习基本原理、整理需求与测量条件 |
| 电气/电源/保护设计 | 具备电气设计与安全能力的人员、合适仪器 | 学习接口、读取数据手册、记录测试 |
| 安全风险评估 | 具备相应能力的安全/法规专业人员 | 收集场景、危险、使用流程和变更信息 |
| CNC/钣金/注塑/线束/PCBA | 合格供应商与工厂 | 读图、询价资料准备、来料记录 |
| EMC/环境/可靠性试验 | 适用实验室及专业测试人员 | 学习测试计划与结果解释 |
| 量产 NPI/质量 | 制造工程、质量、供应链团队 | 整理 BOM、工艺流程和追溯 |
| 市场准入/认证 | 目标销售地区的合格检测/认证机构及法规顾问 | 维护适用性矩阵和文件资料 |

## 11. G8–G11 输出物索引

| 阶段 | 主要输出 |
|---|---|
| G8 PVT | 试产计划/批次、MBOM、路线、工装、作业指导、PFMEA、Control Plan、IQC/IPQC/OQC、MSA、产测和不良闭环 |
| G9 量产 | 量产放行报告、供应商质量计划、产能/节拍/良率/成本、追溯演练、ECO/ECN 和服务备件计划 |
| G10 交付 | 出厂检验、包装运输、现场勘察、安装调试、培训、FAT/SAT（适用时）、客户验收和配置清单 |
| G11 售后/EOL | FRACAS/CAPA、维修记录、备件、升级/回滚、保修/SLA、停产通知、数据清除和退役记录 |
