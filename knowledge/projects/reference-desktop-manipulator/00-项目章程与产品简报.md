## 1. 项目使命与教学目标

本项目用一个边界受控的机械臂产品练习完整工程链：产品机会 → 用户需求 → 系统需求 → 架构/接口 → 机械、电气、控制和软件设计 → PoC/工程样机 → EVT/DVT → PVT/NPI → 量产准备 → 客户部署 → 售后和退役。

最终目标不是做一个“能动的机械臂演示”，而是学会如何将需求变成可测量、可制造、可维护、可追溯的产品定义，并明确哪些工作需要专业人员、真实设备、试验室、工厂、供应链、资金和授权批准。

## 2. 产品机会假设（H-级，未验证）

### 2.1 假设用户

- 教学实验室、职业教育/高校工程课程、机器人初学者训练环境；
- 小型研发团队，用于学习关节机械臂的集成和工程验证；
- 需要在固定工位演示预定义工件分拣流程的系统集成学习者。

这些是初步假设，不代表已经完成用户访谈、市场规模、购买意愿、竞品或定价研究。

### 2.2 待解决问题

学习者往往能看到机械臂运动学、夹爪控制和规划算法的独立示例，却缺少把固定工件、托盘、机械臂、工具、控制器、软件、操作流程和测试指标连成可验证工作单元的完整案例。

**需要验证的价值：** 是否能减少从基础知识到可复现实验的学习成本；是否能以安全、可重复的方式教学机械臂从任务定义到质量验证的流程。

### 2.3 替代方案

| 替代方案 | 可能优势 | 需要比较的不足/成本 |
|---|---|---|
| 纯软件仿真 | 初期投入低、易于重置 | 无法证明真实摩擦、间隙、柔性、热、驱动和安全行为 |
| 教学套件/成品机械臂 | 快速开始、厂商资料可能较完整 | 设计自由度、接口开放程度、长期供货、售后和改装限制 |
| 自制机械臂 | 可学习完整结构和工程取舍 | 机械加工、电气设计、装配、校准、风险和测试工作量更高 |
| 外包整机/定制工作站 | 可获得集成方案 | 成本、知识沉淀、供应商依赖和后续维护能力需评估 |

## 3. 产品定义与预期用途

### 3.1 暂定产品概念

一套固定安装在工作台/专用底座上的关节式机械臂工作单元，配备可更换或可维护的末端执行器、基本关节位置反馈、控制系统和受控工作区，用于将已知类别、预先摆放在定义位置的教学工件从供料托盘转移至指定分拣区域。

初始概念优先采用固定工装和已知取放点；视觉识别、随机堆叠抓取、自主任务规划和移动底盘作为后续可选扩展，不纳入 MVP 必须功能。

### 3.2 预期用途（待需求评审）

在受控、固定、有人监督的室内教学/实验工作台环境中，执行预先定义的低复杂度抓取、搬运和放置任务，用于机械臂运动学、路径规划、控制、末端执行器、系统集成和验证教学。

### 3.3 明确不在初始范围

- 不作为协作机器人或可与人员无防护接触的设备；
- 不用于医疗、生命支持、航空航天、汽车安全关键工序或危险环境；
- 不搬运易燃、易爆、腐蚀、有毒、锋利、高温或生物危害物；
- 不在公共空间、无监督场地或未经评估的开放工作区自主运行；
- 不承诺达到任何未经定义和验证的载荷、速度、重复精度、节拍或寿命；
- 不把教育原型视为可直接销售或量产的产品。

最终适用范围必须由正式风险评估、适用法规/标准分析和设计验证确定。

## 4. CONOPS｜运行概念

### 4.1 典型任务流程

1. 操作者检查工作区、工具、夹爪、托盘和防护措施；
2. 选择已批准的教学任务配方；
3. 系统完成自检，确认关节反馈、末端执行器、控制器和保护状态；
4. 操作者启动任务；
5. 机械臂移动至预定义取料位姿；
6. 末端执行器执行抓取，读取可用状态反馈；
7. 机械臂沿已规划并检查的路径移动至目标分拣位；
8. 执行释放并确认结果；
9. 记录任务成功/失败、异常码、配置和测试环境；
10. 操作者结束任务、检查工件和设备状态。

任何自检失败、保护状态异常、反馈丢失或超出已批准运行边界的情况，都必须按设计定义的受控方式停止/禁止启动；具体安全功能和硬件实现须在风险分析与详细设计阶段确定。

### 4.2 用户角色

| 角色 | 主要职责 | 不应默认拥有的权限 |
|---|---|---|
| 学习者/操作者 | 装载已批准工件、选择任务、观察状态、记录结果 | 修改安全参数、旁路联锁、带电拆机 |
| 教学/实验负责人 | 场地管理、培训、任务批准、设备状态管理 | 未经授权更改设计或安全功能 |
| 机械/电气/控制维护人员 | 检查、维护、校准和故障处理 | 超出资质/授权范围的安全系统更改 |
| 产品/系统工程负责人 | 需求、架构、配置、风险和变更管理 | 无证据批准测试或量产放行 |
| 质量/安全/法规责任人 | 独立评审风险、证据和合规 | 以文档齐备替代真实测试 |

## 5. ODD｜初始运行设计域（均为待验证假设）

| 维度 | 初始边界 | 需要进一步定义/验证 |
|---|---|---|
| 场地 | 室内、固定工作台、受控实验区域 | 地面/台面承载、稳定性、周边空间、通道和隔离 |
| 工件 | 已知类别、尺寸/质量范围受控的刚性教学工件 | 材料、重心、表面摩擦、形状、公差及损坏风险 |
| 供料 | 固定托盘/治具，已知取料位置 | 托盘定位公差、工件摆放误差、换型流程 |
| 人员 | 受训人员监督；初始设计不假设人员可进入运动区 | 防护方式、访问控制、示教/维护状态、残余风险 |
| 环境 | 一般室内实验环境 | 温湿度、粉尘、液体、照明、振动和电磁环境限制 |
| 网络 | 初期本地运行，网络不是执行任务的必要条件 | 远程维护是否需要、访问控制、更新和回滚 |
| 任务 | 预定义抓取/放置配方 | 目标数量、异常处理、成功定义和周期要求 |

## 6. 产品需求初稿（PRD）

下列需求是待评审的需求框架，不是已经批准的性能承诺。任何目标值应在用户研究、技术可行性、风险分析和试验方案确认后填写。

| PRD ID | 初始需求 | 验收方法 | 目标/判据状态 |
|---|---|---|---|
| PRD-F-001 | 系统应能执行已批准的取料—转移—放置任务配方 | 代表性任务测试 | 任务集合与成功定义 TBD |
| PRD-F-002 | 操作者应能选择/停止已批准任务，并看到当前任务状态 | 功能演示/状态检查 | 状态定义与权限矩阵 TBD |
| PRD-F-003 | 系统应能检测并报告关键任务失败，如抓取未确认或执行超时 | 故障注入/负向测试 | 检测覆盖率与超时阈值 TBD |
| PRD-P-001 | 产品应达到用户认可的末端可达范围和定位/重复性要求 | 测量、重复试验 | 工作空间、误差和样本计划 TBD |
| PRD-P-002 | 产品应在定义工件集合和任务工况下满足任务成功率及节拍要求 | 统计试验 | 工件、样本量、成功率、节拍 TBD |
| PRD-S-001 | 产品应按风险评估实施防护和安全功能，防止未经授权进入危险运动区域 | 风险评估、检查、验证 | 防护设计与验收判据 TBD |
| PRD-R-001 | 产品应满足定义的教学运行寿命和维护周期 | 耐久测试/分析 | 周期数、维护间隔 TBD |
| PRD-M-001 | 产品应有唯一序列号并记录关键部件、软件/固件版本和测试结果 | 记录审计/追溯演练 | 追溯范围与保存期 TBD |
| PRD-SV-001 | 产品应提供可理解的安装、操作、维护、故障处理和退役资料 | 文件评审/用户演练 | 内容与维护能力要求 TBD |

## 7. KPI 字典草案

| KPI ID | 指标 | 计算/口径 | 尚待定义的工况 |
|---|---|---|---|
| KPI-001 | 任务成功率 | 成功完成并确认放置的任务数 / 有效执行任务总数 | 工件集合、异常和中止是否计入分母 |
| KPI-002 | TCP 位置误差 | 测量 TCP 与目标 TCP 的位置差 | 测量系统、姿态、负载、参考坐标 |
| KPI-003 | 重复定位离散度 | 相同命令在固定条件下多次测量的离散程度 | 试验次数、温态、负载、统计方法 |
| KPI-004 | 任务周期 | 任务开始到完成确认的时间 | 起止定义、空运行/取放任务、统计分位数 |
| KPI-005 | 抓取保持/掉落率 | 搬运阶段保持成功与掉落次数 | 物体材质、表面、加速度、夹持策略 |
| KPI-006 | 故障恢复时间 | 故障出现到按批准流程恢复的时间 | 故障类别、人工介入边界 |
| KPI-007 | 单任务能耗 | 指定任务期间测得的能耗 | 电源计量边界、待机功耗、工况 |

## 8. G1 阶段评审输入与退出条件

**输入：** 用户/学习者访谈计划、教学任务观察、竞品/替代方案比较、初始 ODD、项目风险和资源假设。

**G1 退出所需证据：**
- 目标用户和购买/使用/维护角色已区分；
- 典型任务与不做事项已评审；
- PRD 初稿中的需求可以被验证，且来源和价值理由可追溯；
- 初始风险、场地、专业人员和预算约束已识别；
- 仍未验证的市场和技术假设均有 owner 与验证计划。

G1 未评审通过前，不应锁定关节数、负载、工作半径、器件型号或成本承诺。
