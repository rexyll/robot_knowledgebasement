## 2. 机械接口

每份机械接口图必须至少注明：

- 坐标系、基准面/基准孔和尺寸单位；
- 安装孔位、螺纹规格、紧固件等级/防松要求（依据设计和应用确定）；
- 安装包络、关节扫掠空间、线缆活动空间和维护拆装空间；
- 工具质量、重心、力矩和惯量边界；
- 材料、表面处理、环境限制和检验方法；
- 图纸编号、修订、GD&T/公差来源和批准状态。

任何承载、倾覆、疲劳、螺栓连接或结构安全计算，必须使用准确工况和材料/连接数据并由具备能力人员复核。

## 4. 关节与运动命令契约

对每个关节需定义：

- 唯一关节 ID、正方向、零位、机械/软件限位；
- 位置、速度、加速度及（适用时）力矩/电流的单位和符号；
- 命令与反馈的时间戳、采样周期、延迟和允许抖动；
- 上电、使能、运行、暂停、取消、故障、维护和关机状态；
- 位置/速度/力矩模式切换条件和禁止切换条件；
- 超时、通信丢失、反馈异常、超限、过温和跟随误差的响应；
- 控制器容差、轨迹结束和任务完成的语义。

未定义的命令不接受；无效、过期或版本不兼容命令必须有明确处理方式。安全相关停止不得仅依赖普通网络消息。

## 5. 坐标、单位和时间

| 数据 | 必须声明 |
|---|---|
| 关节状态 | 关节 ID、rad 或 m、速度单位、时间戳、有效性 |
| TCP 位姿 | 父/子坐标系、米、四元数或明确姿态表示、时间戳 |
| 工件位姿 | 相机/基座/托盘坐标链、标定版本、不确定度 |
| 力/力矩（若使用） | 传感器坐标系、N/N·m、偏置/标定和滤波 |
| 任务事件 | 任务 ID、工件 ID、配方/配置版本和时间源 |

统一使用 SI 单位或在接口中显式声明转换。禁止只写“位置 0.3”而不说明单位、参考坐标系和时间基准。

## 6. 末端执行器接口

需定义工具 ID、工具类型、TCP、开口/行程、夹持力/真空参数（准确工具选定后）、抓取/释放命令、状态反馈、工具存在检测、失压/断电行为和故障处理。对于保持负载、垂直搬运或人员可能暴露的工况，应单独分析掉落危险和失效安全状态。

## 7. 安全与状态语义

- 物理防护、访问控制、急停、互锁、复位和维护模式要有明确需求；
- 不得把普通 ROS topic/service/action 或未认证通信接口当作安全链；
- 故障、断电、通信丢失和异常复位时的机械/驱动状态要有风险评估支持；
- 保护装置复位不得自动导致危险运动重新启动；
- 维护、示教和调试模式须定义授权、速度/空间约束和接管方式；
- 最终安全架构依据适用法规/标准、制造商资料与专业风险评估确定。
