# 参考项目：桌面型物料分拣机械臂

> **项目类型：** 教学型端到端参考项目（Teaching Reference Project）。这是用于学习产品定义、系统工程、机械臂设计、验证、NPI、量产质量和交付的方法案例，不是已制造、已认证、已上市或已量产的真实产品。

## 1. 为什么选这个项目

现有 AMR 项目能支撑移动机器人、定位导航、车队调度和云端运维学习；本项目补齐机械臂、操作规划、末端执行器、抓取、工艺验证与生产导入的差异路线。两者共享需求工程、计算平台、软件工程、风险管理、测试验证、BOM、NPI、质量和售后方法，但不能互相替代。

## 2. 项目边界

初始概念是：固定在工作台上的小型关节机械臂，把预先定义、已知类别和已知取放区域的教学工件从供料托盘转移到指定分拣区域。初版不把视觉 AI、移动底盘、开放人机协作、复杂装配或自主学习作为必需能力；是否纳入后续版本必须通过需求变更和风险评审。

本项目不预先指定关节数、工作半径、负载、速度、精度、电机型号、减速器、供电电压、控制器或目标价格。上述参数须由需求、可行性、风险和真实器件资料确定。

## 4. 项目阶段和证据状态

本项目借用知识库 G0–G11 阶段门，但每个阶段必须依据实际证据评审。为避免把“写了文档”当成“已验证”，本项目暂用以下内部证据标记（不是行业标准或认证等级）：

| 标记 | 证据含义 | 不能据此宣称 |
|---|---|---|
| H | 假设/待研究 | 需求成立、技术可行 |
| D | 文档化设计/需求 | 设计已实现 |
| A | 计算、分析或供应商资料评估 | 实测性能或安全符合 |
| S | 仿真/软件测试 | 真实硬件安全或量产能力 |
| B | 受控台架/样件实测 | 设计验证或批量一致性 |
| V | 代表性目标配置上按批准计划完成验证 | 其他配置或产品家族自动通过 |
| P | 受控生产过程、批次和质量数据 | 未经批准的后续变更仍然有效 |

当前所有需求均为草案，数值阈值多为 TBD；当前没有 B/V/P 等级的真实设备或量产证据。

## 5. 项目状态

- 已建立（均为草案）：教学项目边界、产品简报、系统架构/接口、验证策略、产品化路线、方案比较/参数预算和初始风险登记文档；“文档已建立”不代表阶段门或设计验收完成。
- 进行中：产品需求确认、技术路线可行性、机械/电气/控制方案比较、风险分析与可测量判据。
- 尚未进行：详细设计冻结、实体打样、硬件 bring-up、真实机械臂测试、EVT/DVT/PVT、量产认证/放行、客户交付。
- 不允许把本项目文档描述为真实机器人产品、已验证设计或量产案例。

## 6. 如何参与

1. 从 [项目章程](00-项目章程与产品简报.md) 读取项目假设和不做事项。
2. 对每条 PRD/SYS 需求提出来源、单位、测量方法和验收判据。
3. 在没有批准设计输入前不要选购关键器件或加工高风险零件。
4. 每次变更都更新需求追踪矩阵、接口、风险和验证计划。
5. 到真实硬件阶段前，补齐专业评审、实验环境、能源隔离和人员授权。

## 8. 主要决策纪律

- 任何数值必须标注单位、工况、配置和证据来源。
- 未选型的器件不写成确定 BOM；教学占位不得当成采购建议。
- 不把普通应用软件、普通 MCU 或 ROS 节点直接宣称为安全功能实现。
- 不把仿真轨迹无碰撞等同于真实机器人可安全运行。
- 不把单台工程样机成功等同于 PVT、量产能力或客户现场验收。
