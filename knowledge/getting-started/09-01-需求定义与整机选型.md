# 09-01 需求定义与整机选型（从0搭建 · 第一步）

> 一切失败的项目都败在「没把需求写死」。本页把「我想要一台机器人」翻译成可验收的数字指标，再用决策树锁定机型——后续所有章节都从这里派生。

## 1. 需求定义八问（填写模板）

| # | 问题 | 示例回答（本指南沿用） | 派生指标 |
|---|---|---|---|
| 1 | 谁用？在哪用？ | 室内仓库/写字楼，恒温，人流中等 | 环境、防护等级 IP54 |
| 2 | 搬什么/干什么？ | 料箱 30kg 或 清扫 | 负载/机构 |
| 3 | 多大场地？ | 1200 m²，通道最窄 0.9m | 通过性 ≤0.6m 宽 |
| 4 | 跑多快？多久到？ | 稳态 1.2 m/s，单程 60m ≤60s | 速度/加速度 |
| 5 | 停得多准？ | 点位 ±10cm；充电对接 ±5mm | 定位/对接精度 |
| 6 | 连续干多久？ | 8h×1 班 | 续航+充电策略 |
| 7 | 几台？会不会扩？ | 首期 3 台，规划 10 台 | 多机调度预留 |
| 8 | 预算+工期？ | ≤5 万/台（样机），4 个月 | BOM 约束 → [[09-11-BOM清单与预算]] |

> **验收先行**：把上表右列抄进合同/立项书（→ [[性能指标体系]] 的四层 KPI），后面每章都在兑现它。

## 3. 机型决策树

```
Q1 负载 > 500kg 或 举升 > 1m?
 ├─ 是 → 需要货叉/顶升 → 无人叉车([[仓储物流机器人]]) 或 潜伏式(配顶升机构)
 └─ 否 ↓
Q2 主要任务是"覆盖地面"(清洁)?
 ├─ 是 → 清洁机形态 → [[清洁机器人]]（本指南样机兼容此形态）
 └─ 否 ↓
Q3 通道 <1m 且需横移/窄调头?
 ├─ 是 → 全向底盘（舵轮/麦轮）→ [[底盘与运动机构]]
 └─ 否 → 差速底盘（最简单、最便宜、社区资料最多）★初学者首选
Q4 室外或 >1.5m/s 长直道?
 └─ 是 → 阿克曼（高速稳定）→ [[底盘与运动机构]]
```

> **初学者路线建议（本指南默认样机）**：**差速底盘 + 2D LiDAR + IMU + 轮编码器 + Jetson Orin Nano + STM32 底盘 MCU + ROS2 Jazzy**。理由：开源资料最多（Nav2 全适配）、安全风险最低、总成本可控（→ [[09-11-BOM清单与预算]] 约 2-4 万）。

```
┌ 云端: 先不做(样机期), 用 SSH+rosbag 替代 [[云平台与IoT通信]]
├ HMI: 笔记本 SSH + Foxglove 可视化 (→ [[09-10-系统联调与测试]])
├ 应用层: 简单任务脚本 (goal 下发) → [[09-08-算法集成与调参]]
├ 导航: Nav2 (SLAM/定位/规划/避障) → [[Nav2导航框架]]
├ 中间件: ROS2 Jazzy (DDS 默认) → [[ROS与ROS2]] · [[DDS专题]]
├ 算力: Jetson Orin Nano (40 TOPS) → [[计算平台]]

```

## 7. 细节加深（V2）
- 需求矩阵实践中最常见的三个坑（行业经验总结）：
  1. **把"最大速度"当"工作速度"** → 运营速度通常只有最大值 60-80%（避障/转弯降速）；
  2. **漏写"不做什么"** → 样机阶段明确：不做乘梯、不做多楼层、不做雨天室外（否则范围失控）；
  3. **精度口径未约定** → ±10cm 是"2σ 还是最大值"、含不含起步段，验收时必扯皮——写进 [[性能指标体系]] 的口径定义。
- 需求评审通过标准：任一指标能被一句话反问「怎么测？」且有测量方法（→ [[性能指标体系]] 测量方法学）。
