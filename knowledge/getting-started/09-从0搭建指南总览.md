# 09-从0搭建指南总览（主线）

> **目标**：通过 12 步完成一台可自主导航的 AMR 教学样机（差速底盘 + 2D LiDAR + ROS2 的参考路线）。这是系统集成入门实践，不是完整产品开发或量产交付。
> **零基础读者**先阅读 [[00-零基础学习路径]]；有些步骤需要先修编程、Linux、数学、机械和电学知识。
> 样机完成后，继续阅读 [[端到端产品化路线总览]]，进入 EVT、DVT、PVT、量产和交付阶段。每一步的专业细节链接到知识库对应详情页。

## 三条使用建议

1. **顺序执行 1→8**，9-11 可并行穿插；12 是面向具备基础编程能力者的 90 天节奏表。零基础读者先补 [[00-零基础学习路径]]。
2. 每步的「上游/下游」节把本步连接到的知识域（硬件/软件/算法）全部列出，深挖走链接。
3. 代码示例集中在 [[10-代码实例README]] 与各步内嵌摘录；所有外链可访问性由 [[链接台账]] 背书。样机通过测试后，不得直接宣称可以量产；下一步进入 [[端到端产品化路线总览]]。
