# 从零到量产｜机器人产品端到端路线

> **本路线是全知识库的工程主线。** 它把零基础学习、产品定义、技术设计、样机研发、工程验证、生产导入、量产交付和售后维护连成一条路径。每个阶段都必须有输入、输出、实践、评审和放行条件。

## 1. 先理解：样机不等于产品，产品不等于量产

- **教学/概念模型**：用于解释原理，不代表可以实际运行。
- **概念验证（PoC）**：验证关键技术是否可行，可能是台架、仿真或局部装置。
- **工程样机 / Alpha**：多个子系统集成，验证基本功能与系统架构。
- **EVT（Engineering Validation Test）**：验证工程设计和关键技术实现。
- **DVT（Design Validation Test）**：验证设计是否满足产品需求、性能、环境、可靠性和合规要求。
- **PVT（Production Validation Test）**：验证生产工艺、工装、人员、供应链和质量控制能稳定制造合格产品。
- **量产爬坡与 MP（Mass Production）**：验证产能、节拍、良率、成本、交付和持续质量能力。
- **交付与运营**：设备到达真实客户环境后安装、配置、培训、验收、维护和持续改进。

这些阶段并非所有行业都使用同一名称。医疗、航空、汽车、工业设备、消费机器人等领域必须按适用法规、质量体系和客户要求映射等效阶段。

## 2. 端到端阶段门

| 阶段 | 核心问题 | 必须形成的主要成果物 | 退出条件/阶段门 |
| --- | --- | --- | --- |
| G0 学习与能力准备 | 团队是否具备开展该项目的基础能力？ | 能力矩阵、先修学习记录、安全培训/资质、资源和预算清单 | 关键任务有人承担；危险任务有合格人员负责 |
| G1 机会与需求定义 | 为谁解决什么问题？ | 市场/场景调研、用户需求、CONOPS、ODD、PRD、初步 KPI | 需求边界和目标用户经评审确认 |
| G2 可行性与概念方案 | 技术、成本、供应和法规上是否可行？ | 技术路线比较、系统框图、初步 BOM、成本/风险、法规适用性预判 | 关键技术和高风险假设有验证计划 |
| G3 系统需求与架构 | 各子系统如何分工和连接？ | SRS、需求追踪矩阵、功能/物理架构、接口控制文件、验证策略 | 关键接口、性能预算和系统边界冻结 |
| G4 详细设计 | 设计是否足够具体，能够制造和实现？ | CAD/工程图、材料、公差、原理图/PCB、线束、BOM、软件/固件设计、网络和安全设计 | 设计评审通过；关键风险有控制措施 |
| G5 PoC 与工程样机 | 关键方案能否运行，子系统能否集成？ | PoC 记录、样机配置、装配记录、Bring-up、调试、问题清单 | 基本功能可重复演示，安全前提满足 |
| G6 EVT 工程验证 | 工程实现是否有效、稳定？ | EVT 计划/报告、性能数据、故障注入、设计迭代、问题闭环 | 重大工程问题关闭或有正式批准的处置 |
| G7 DVT 设计验证 | 冻结设计能否满足产品要求与适用法规？ | DVT 报告、环境/耐久/可靠性测试、风险分析、合规差距、设计冻结包 | 需求验证通过；认证路径与遗留风险明确 |
| G8 PVT 生产验证 | 工厂能否按受控流程稳定制造？ | MBOM、工艺流程、工装、作业指导书、PFMEA、Control Plan、检验规范、产测、追溯和试产报告 | 试产质量/良率/节拍达到预设标准，问题闭环 |
| G9 量产准备与爬坡 | 产能、成本、质量和供应是否可持续？ | 供应商质量计划、IQC/IPQC/OQC、MSA/SPC、产能计划、成本模型、备件、变更流程 | 量产放行评审通过，产能和质量风险可控 |
| G10 客户交付与验收 | 产品在客户现场是否满足约定需求？ | 出厂检验、包装运输、安装调试、现场测试、培训、验收签署、交付资料 | 合同/需求验收通过，遗留项有责任与期限 |
| G11 售后与生命周期 | 产品是否能被安全维护、升级和退役？ | 服务手册、SLA、备件、故障数据库、升级/回滚、质量反馈、EOL/退役计划 | 运营问题进入反馈闭环，产品生命周期责任明确 |

## 3. 每个阶段的工作包

### 3.1 产品机会与需求（G1）

先定义用户、场景、任务、环境、负载、工作时间、人机关系、运行设计域和痛点，再将其转换为可测量需求。要回答：不做机器人是否更合理？是否需要移动、操作、感知、联网或自治？系统必须达到什么性能才算成功？

相关章节：机器人类型地图、09-01 需求定义与整机选型、AMR 整体架构、02 需求定义与系统工程。

### 3.2 可行性与架构（G2–G3）

比较不同机构、执行器、传感器、算力、OS、通信和算法路线；建立质量、功耗、算力、热、成本、实时性和安全预算；定义接口和验证方法。不要先采购昂贵部件再寻找应用场景。

相关章节：03–17、20、21。

### 3.3 详细设计与工程样机（G4–G5）

把概念方案变成可制造、可装配、可调试的工程定义：CAD/工程图、材料、公差、PCB/线束、零件编号、BOM、软件接口、驱动、参数、测试台架和装配作业步骤。样机必须记录实际物料版本和软件/固件配置，不能只保留“最终能跑”的状态。

相关章节：03–14、18–20、22。

### 3.4 工程与设计验证（G6–G7）

按需求追踪逐项验证功能、性能、可靠性、环境适应、故障恢复和安全需求。必须保留失败数据、根因、整改、回归和最终结论。需要认证的项目应明确实验室、检测机构和技术文件准备计划。

相关章节：19、20、22。

### 3.5 生产工程与试产（G8）

必须从“工程师手工装得出来”转为“受控工艺能重复制造”。至少检查：

- DFM/DFA/DFT：可制造、可装配、可测试性；
- MBOM、物料编码、替代料、工艺路线、工位和工装；
- 作业指导书、人员培训、检验规范、扭矩/胶水/固件/标定等关键工艺参数；
- PFMEA、Control Plan、首件/来料/过程/出货检查；
- 产线测试程序、校准工位、序列号和批次追溯；
- 不合格品隔离、返工/返修、变更审批和试产问题闭环。

相关章节：03、05、07、09、18、19、20、22。

### 3.6 量产爬坡与持续质量（G9）

关注产能、节拍、一次通过率、良率、返工/报废、供应商质量、交期、库存、成本偏差、现场故障和保修成本。建立 IQC/IPQC/OQC、MSA、SPC、ECO/ECN、供应商纠正措施和产品质量反馈机制。指标阈值必须按产品和工厂实际建立，不能照抄其他企业数字。

相关章节：18、19、20、21、22。

### 3.7 客户交付与服务（G10–G11）

交付不是把货物运到客户处。还包括现场勘查、基础设施确认、安装、网络与系统配置、地图/工艺/任务配置、人员培训、验收、操作手册、维护手册、备件、SLA、远程监控、升级回滚、故障响应和安全退役。

相关章节：15–17、20、22、24。

## 5. 不同机器人类型的路线差异

端到端阶段门是共通的，但技术工作包不能照搬：

| 机器人类型 | 特有工程重点 | 主要差异章节 |
| --- | --- | --- |
| AMR/AGV | 底盘、定位导航、交通调度、现场地图、车队运营 | 04、06、13、14、17 |
| 工业机械臂/协作机器人 | 关节/减速器、运动学、末端工具、工艺、工作空间和协作安全 | 04、14、20 |
| 清洁/服务机器人 | 任务效果、液体/粉尘、耐久、用户交互、场景运营 | 01、05、15、19、22 |
| 人形/足式机器人 | 多自由度关节、全身控制、平衡、灵巧操作、数据和复杂安全 | 04、07、13、14、23 |
| 无人机 | 飞行器结构、推进、电池、飞控、链路、空域和运行安全 | 03–10、14、20 |
| 医疗机器人 | 临床需求、风险管理、软件/硬件验证、质量体系和市场准入 | 02、19、20、22 |

## 6. 当前主线的定位

现有 12 步 AMR 样机指南是 G4–G6 的入门实践路线之一，适合学习子系统和整机集成。它**不等同于**完整的产品化路线；后续必须继续学习 DVT、PVT、生产工程、量产爬坡、客户交付和售后。
