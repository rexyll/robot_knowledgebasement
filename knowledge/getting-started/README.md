# Getting Started | 从零搭建到产品化

本目录提供面向非机器人行业学习者的入口，以及从教学样机到产品化交付的完整主线。

## 学习入口

- [00 零基础学习路径](00-零基础学习路径.md)：适合没有编程、机械、电气或机器人背景的读者；先建立能力地图，再选择项目。
- [12 步 AMR 样机指南](09-从0搭建指南总览.md)：完成一台可自主导航的教学样机。
- [端到端产品化路线](端到端产品化路线总览.md)：从需求和概念设计，继续到 EVT、DVT、PVT、量产爬坡、客户交付和售后。

## 如何使用

1. 完全零基础：从 00 零基础学习路径开始，按能力自测决定学习顺序。
2. 已有工程基础：直接进入机器人类型和产品需求章节，再按项目路线补齐知识。
3. 做样机：执行 12 步 AMR 路线；它是学习系统集成的参考项目之一。
4. 做产品：必须继续端到端产品化路线，不能把样机跑通当作量产完成。

所有专业知识回链到 knowledge/ 对应板块；全局约束和任务依赖见 [根 TaskPlan](../../TaskPlan.md) 和 [章节计划索引](../../docs/TaskPlan/README.md)。
