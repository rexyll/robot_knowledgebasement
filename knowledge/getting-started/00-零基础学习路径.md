# 机器人行业零基础学习路径

> 本路线面向**没有机器人行业背景**的学习者。它不是要求所有人一次学完所有学科，而是帮助你判断当前能力、补齐必要基础，再沿着一个明确的机器人项目逐步学习。每一阶段都要完成练习或成果物，不能只看视频或收藏链接。

## 1. 怎么使用这套知识库

建议按三条路线交替学习：

1. **基础路线**：补足数学、物理、编程、计算机、机械和电学常识。
2. **项目路线**：选择一种机器人，从需求、设计、样机、验证逐步做出成果。
3. **查询路线**：遇到具体零部件、算法、接口、标准或故障时，再深入对应专业章节。

先读 [知识地图](../maps/README.md)，再根据能力选择本页入口。完整的产品化主线见 [端到端产品化路线](端到端产品化路线总览.md)。

## 2. 能力等级与学习入口

| 等级 | 当前状态 | 应建立的能力 | 建议入口 |
| --- | --- | --- | --- |
| A0 零基础 | 没有机器人/工程经验 | 科学计量、基本数学和物理、技术阅读、工程安全意识 | 本页第 3 节 |
| A1 工程基础 | 能使用电脑并完成基础学习练习 | 编程、Linux/Git、基础电路、机械识图和测量 | 11、12、03、05、08 章 |
| A2 单专业入门 | 能独立完成一个专业子任务 | 机械/电气/嵌入式/算法/软件等一个专业方向 | 03–14 章 |
| A3 系统集成 | 能理解多个子系统接口 | 系统工程、接口、配置、集成、测试和故障定位 | 02、10、11、19、22 章 |
| A4 产品化与量产 | 能参与产品导入与交付 | DFM/DFA/DFT、BOM、供应链、质量、认证、试产和售后 | 18–22、25 章 |

能力等级不是学历或职业认证。每个人可以从不同等级进入，但涉及安全、法规和生产放行的工作必须满足对应专业审核要求。

## 3. 零基础先修课程

### 3.1 工程常识与科学计量

学习：SI 单位、数量级、有效数字、误差、测量、实验记录、因果与相关、数据可视化。

练习：用尺、秤和秒表测量一个物体的尺寸、质量和运动时间，写出测量条件、单位和误差来源。

达标：能解释单位换算、测量误差和为什么工程参数必须附工况。

### 3.2 数学与物理基础

学习：代数、函数、三角、向量、坐标系、基础微积分、概率统计；力、力矩、功率、能量、摩擦、速度/加速度；电压、电流、电阻、功率和简单电路。

练习：计算一个移动平台在给定质量、速度和坡度下的大致驱动需求；用向量表示二维位置和方向。

达标：能读懂后续知识中的基本公式，知道每个变量的单位和假设。进一步内容见 [数学基础与通用算法](../../docs/TaskPlan/12-数学基础与通用算法/TaskPlan.md)。

### 3.3 计算机与编程基础

学习：文件系统、命令行、编辑器、Git、Linux 基础、Python 入门、C/C++ 基础、调试、日志、数据结构和简单网络概念。

练习：写一个读取 CSV、计算平均值并生成图表的小程序；用 Git 完成一次提交和回滚。

达标：能运行、修改、调试一个小项目，并记录依赖和版本。软件工程路线见 [软件架构与工程体系](../../docs/TaskPlan/11-软件架构与工程体系/TaskPlan.md)。

### 3.4 机械识图与 CAD 入门

学习：三视图、尺寸/公差、螺纹、轴承、材料、常见加工方式、装配和基本 CAD 建模。

练习：绘制一个支架或安装板，标注尺寸、孔位、材料和加工要求。

达标：能读懂基础机械图，并理解设计尺寸与加工尺寸不是同一回事。

### 3.5 电学、电子与实验室安全

学习：低压直流电源、欧姆定律、串并联、保险、极性、接地、连接器、万用表基础和静电防护。

练习：在受限的低压、限流、安全教学套件上测量电压/电阻并搭建简单 LED 电路。

达标：能识别极性、短路和基本电气风险。市电、高压、大电流、电池组和电机台架操作必须接受适当培训并由合格人员监督。

### 3.6 工程沟通与项目习惯

学习：需求表达、版本记录、问题复现、测试记录、变更说明、会议纪要、成本和风险意识。

练习：为一个桌面小装置写一页需求、一个结构草图、一张物料表和三条验收标准。

达标：别人能根据文档理解你要做什么、如何判断完成以及有哪些风险。

## 4. 选择第一个机器人项目

| 项目路线 | 适合学习的内容 | 复杂度与提醒 |
| --- | --- | --- |
| 桌面差速移动机器人 | 电机、编码器、传感器、嵌入式、ROS、定位与导航 | 推荐作为系统入门样机；从仿真和低速、低风险实验开始 |
| 桌面机械臂 | 连杆、关节、运动学、伺服、轨迹、抓取和安全 | 需重点关注夹伤、碰撞、负载和运动范围 |
| 简单服务/清洁机器人 | 机电集成、任务流程、用户交互、环境适应和维护 | 需要考虑液体、粉尘、地面和真实作业环境 |
| 无人机/足式/医疗/工业机器人 | 特定动力学、法规、安全、精密控制或行业要求 | 不建议作为完全零基础的第一个实物项目；先完成基础课程和仿真，再由专业团队参与 |

项目类型不是一张简单排行榜。先依据场景、风险、资源和目标选择，再阅读 [机器人类型与应用](../robots/README.md)。

## 5. 从入门到产品化的路线

- **学习准备**：完成本页先修课程和安全能力检查。
- **做出样机**：现有 [12 步 AMR 样机指南](09-从0搭建指南总览.md) 带你完成一台可自主导航的教学样机。
- **做成产品**：继续 [端到端产品化路线](端到端产品化路线总览.md)，学习 EVT、DVT、PVT、生产工艺、量产爬坡、客户交付和售后。
- **查专业细节**：按 [TaskPlan 章节索引](../../docs/TaskPlan/README.md) 进入机械、电气、软件、算法、供应链、质量和法规专题。

## 6. 学习成果检查

开始项目之前，至少确认自己能够：
- 用正确单位描述长度、质量、速度、电压和功率；
- 读懂简单的电路图和机械图；
- 使用 Git 保存版本，写出可复现的问题记录；
- 识别可能造成触电、火灾、夹伤、碰撞或电池热风险的操作；
- 写出一条清晰的需求和一条可验证的验收标准；
- 知道遇到超出能力范围的工作时，如何停止并寻求专业帮助。

## 7. 重要边界

知识库提供学习路径、工程方法和参考资料，不代表读者仅凭阅读就具备从事安全关键工作、制造、检测或认证的资格。实际产品开发必须结合真实测量、专业设计评审、风险评估、实验验证、供应链和法规要求。
