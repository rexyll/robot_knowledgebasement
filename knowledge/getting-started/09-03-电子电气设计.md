# 09-03 电子电气设计（从0搭建 · 第三步）

> 目标：一张电源树 + 一张线束表 + 一条独立急停链。初学者 80% 的"玄学重启"都来自电源与接地，本章优先解决它们。

## 1. 样机电源树（24V LFP 主线）

```
LFP 24V 40Ah 电池组(带 BMS, → [[电池与电源]])
 ├─ [主开关+60A 保险] ── 电机驱动器×2 (峰值 30A/个)
 ├─ [10A 保险] ── DCDC 24→5V/5A ── LiDAR、5V 外设(每路独立保险 2A)
 ├─ [8A 保险]  ── DCDC 24→19V/6A ── Jetson Orin Nano (7-25W, 峰值留 3 倍)
 ├─ [5A 保险]  ── DCDC 24→12V/3A ── 预留(4G/屏/相机)
 └─ 充电口(XLR-4) ── 充电桩/充电器 (24V 5A, 充电时主开关断电机路)
急停链(独立于软件, → [[安全防护器件]]):
  急停按钮(常闭) + 触边条(常闭) 串联回路 → 直接断"电机驱动器供电继电器"
  MCU 仅"知晓"急停事件(引脚采样), 不参与断路
```

**电源设计三纪律**：
1. **每路独立保险**（分级：电池总保险 > 支路保险），短路时只烧最小范围；
2. **大电流线与小信号分离**（电机线双绞+远离信号线 10cm 以上，EMC 基础）；
3. **共地单点**：MCU/Jetson/传感器共地必须在电源入口单点汇接，避免电机地弹跳窜入传感器（IMU 漂移玄学的头号来源 → [[IMU]]）。

## 2. 线束表（样机实测规格）

| 起点 → 终点 | 线材 | 接口 | 备注 |
|---|---|---|---|
| 电池 → 配电板 | 12AWG 硅胶线 ×2 | XT60 | 主动力 |
| 配电板 → 电机驱动器 | 14AWG ×2 | XT30/焊接 | 双绞 |
| 电机 → 驱动器 | 16AWG ×2 + 编码器 5 芯屏蔽线 | JST-XH | 屏蔽层单端接地 |
| Jetson ← DCDC | 18AWG ×2 | DC 头/焊接 | 峰值电流核算 |
| LiDAR/IMU → Jetson | USB3/网线/USB-C | 原装口 | IMU 走串口或 USB |
| Jetson ↔ MCU | USB-C（UART 桥）或 USB-TTL | USB | 心跳协议 → [[实时系统与嵌入式]] |

## 3. MCU 最小系统（底盘板）

- **选型**：STM32F405/F411（社区资料最多，micro-ROS 支持）或 Teensy 4.1（上手最快，Arduino 生态）
- **必备外设**：编码器接口 ×2（定时器编码器模式）、串口 ×2（Jetson + 调试）、PWM ×2 或 CAN、ADC（电池电压采样分压）、急停输入（外部中断）
- **布局**：功率区（驱动器）与 MCU 区分区放置，晶振远离电源线
- 不画 PCB 的样机路线：**飞线面包板不可行**（电机噪声），用洞洞板+端子台或直接买现成"双电机驱动扩展板"

## 4. EMI 与安全（一次性做对）

- 电机线**双绞** + 屏蔽线缆用于编码器/编码信号（干扰源见 [[实时系统与嵌入式]]）
- 电池仓：LFP 加绝缘托盘 + 保险丝盒；充电口带防反接二极管/理想二极管
- 急停按钮选 22mm 常闭自锁（GB/ISO 13850 样式），红色黄底
- 整机加总开关（带锁）+ 独立急停——两个东西，别混用

## 7. 细节加深（V2）
- **DCDC 选型要留 3 倍余量**：Jetson 标称 7-25W，但上电瞬态+GPU 满载可到 40W+；DCDC 峰值电流按 3A→6A 选，否则"跑 SLAM 就重启"。
- **XT60 vs XT30**：>20A 用 XT60，10-20A 用 XT30；电池主回路禁用 USB/杜邦。
- **保险丝分级实例**：电池总保险 60A（电机短路兜底）；DCDC 支路按「功率÷电压×2.5」取值。
- **接地测量法**：万用表交流档测「电机地 ↔ IMU 地」<50mV（负载运行时）为合格，超标查共地。
