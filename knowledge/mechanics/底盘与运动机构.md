# 底盘与运动机构

> AMR 的"腿"。运动学决定控制算法、里程计模型和适用场景——选底盘就是选运动学（→ [[轨迹优化与运动控制]]）。

## 轮式底盘构型对比（AMR 主战场）

| 构型 | 自由度 | 原理 | 优点 | 缺点 | 适用 | 里程计 |
|---|---|---|---|---|---|---|
| **差速驱动** | 2（v, ω） | 两独立驱动轮+万向轮配平 | 结构简单便宜、控制最简、原地转 | 万向轮打滑引入误差 | 家用扫地机、小型 AMR、潜伏式（配顶升） | 双轮编码器 |
| **四轮差速** | 2 | 四驱差速 | 爬坡/载重强 | 转向滑动摩擦大、磨损 | 重载牵引、户外 | 四轮融合 |
| **阿克曼** | 2 | 前轮转向（内轮角>外轮角） | 高速稳定、轮胎磨损小、像汽车 | 不能原地转、转弯半径受限 | 无人叉车、户外、清洁机（快速大场景） | 转向角+驱动轮 |
| **麦克纳姆轮** | 3（横移！） | 45° 辊子差速合成 | 全向、窄空间 | 辊子磨损/震动/贵、效率低 | 精密对接、装配线接驳 | 三轮速度解算 |
| **舵轮（Ominidirectional steering）** | 3 | 驱动轮+转向轮组合单元×2-4 | 全向+大负载（1-3t）+平滑 | 复杂、贵 | 重载全向 AMR、叉车 | 每轮解算 |
| 三轮全向（120° omni） | 3 | 全向轮×3 | 简单全向 | 承载低 | 轻型平台 | 三轮解算 |

> [[项目-清洁机器人]] 同时维护 **阿克曼 + 差速两套底盘驱动包**（Chassis/AckermannChassis 与 DifferentialWheelChassis），以适配不同场景机型——同一导航栈兼容两种运动学的工程范例。

## 特殊机构

| 机构 | 原理 | 用途 |

| 顶升机构 | 电机顶杆举货架 3-5cm | 潜伏式搬运（→ [[仓储物流机器人]]） |

## 底盘控制器（MCU 实时层）

```
输入(1-100Hz, ROS2 → 串口/CAN): 目标 v, ω ( Twist 消息)
运动学逆解: 差速 [vl,vr]=[v-Wω/2, v+Wω/2]; 阿克曼 δ=atan(ωL/v), 轮速=v/cosδ
速度环 PID (1kHz): 编码器反馈 → [[电机与驱动器]] FOC 电流环
安全层: 超速/失联(>200ms 无指令→急停)/过流/触边触发 → 独立硬件路径
输出: 编码器里程计回传 (→ [[编码器与里程计]])
```

- 失联保护是硬安全设计：心跳丢失 200ms 自动刹停 → [[功能安全体系]]

## 底盘选型核心参数（整机视角）

| 参数 | 说明 | 典型值 |
|---|---|---|
| 额定/峰值负载 | 结构强度+电机扭矩 | 见 [[移动机器人]] 参数表 |
| 最大速度 | 满载/空载分开标 | 1-2.5 m/s |
| 最小转弯半径 | 阿克曼 `R=L/tan(δ_max)` | 阿克曼 0.6-1.5m；差速 0 |
| 爬坡 | 持续/短时 | 室内 5%，坡道 10%，特种 30°+ |
| 越障 | 减速带/门槛 | 商用清洁 15-25mm |
| 通过性 | 宽×高、对角线 | 货梯/通道限宽 0.8m 起 |
| 定位重复精度 | 停靠 | ±5-10mm（对接级） |
