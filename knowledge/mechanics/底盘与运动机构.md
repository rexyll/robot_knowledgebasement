# 底盘与运动机构

> 底盘构型决定运动学约束、可通过性、结构负载路径、驱动器数量和维护复杂度。没有脱离任务、场地和载荷的“最佳底盘”。

## 先修知识与学习目标

先理解坐标系、速度/角速度、力矩、摩擦、重心和基本机械制图。完成本页后，应能按任务约束初筛底盘构型，知道需要哪些结构/运动参数，并建立验证计划。

## 1. 从使用场景定义需求

在选构型前先明确：
- 总质量、额定载荷、载荷分布、重心高度与偏移；
- 运行速度、加速度、制动、转弯、坡度、门槛/沟槽和地面摩擦；
- 通道宽度、货架/货梯/工作站空间、地面接缝和定位对接要求；
- 连续运行时间、温度、湿度、粉尘、水、清洁和腐蚀环境；
- 人员共存、碰撞风险、机械防护和维护空间；
- 生产方式、尺寸公差、材料可得性、装配工艺和目标成本。

## 2. 轮式底盘构型对比

| 构型 | 运动特点 | 优点 | 局限 | 常见候选场景 |
| --- | --- | --- | --- | --- |
| 差速驱动 | 两侧驱动轮速度差产生转向；通常不能横向平移 | 机构相对简单，控制与维护较直接 | 转向时轮胎/脚轮可能滑移，定位误差受地面影响 | 室内 AMR、小型搬运平台 |
| 四轮差速 | 多个驱动轮按差速运动 | 可提高牵引能力和冗余设计空间 | 轮径、安装误差和转弯滑移会影响运动学与磨损 | 中/重载平台，需具体结构分析 |
| 阿克曼转向 | 转向轮几何关系约束转弯 | 连续转向运动自然，适合较高速度的车辆式方案 | 转弯半径受轴距和转角限制，不能原地旋转 | 户外移动平台、无人叉车等 |
| 麦克纳姆轮 | 多个斜辊合成平面全向运动 | 可横移，便于狭窄空间对接 | 辊子接触和地面平整度影响效率、振动和定位 | 受限空间内的特定对接/搬运 |
| 舵轮/独立转向驱动 | 每个轮组可驱动和转向 | 运动灵活，适合大型平台定制 | 机构、标定、控制和维护复杂 | 重载/大型全向平台 |
| 三轮全向轮 | 多轮速度合成平面运动 | 机构和控制可较简化 | 对载荷、地面、轮子接触和振动敏感 | 轻载实验或特定平台 |

同一机器人可能有多种底盘配置；差速与阿克曼必须分别建立运动学模型和标定参数，不能只在软件层切换一个模式就假定机械兼容。

## 3. 特殊机构

| 机构 | 关键设计问题 | 典型用途 |
| --- | --- | --- |
| 顶升机构 | 偏载、导向、丝杆/链条强度、防坠、限位和维护 | 潜伏式搬运 |
| 货叉/升降桅杆 | 额定载荷曲线、重心、倾覆、链条/液压、门架挠度和防坠 | 无人叉车/堆垛 |
| 履带 | 接地压力、张紧、驱动阻力、转向磨损和脱轨 | 特种/越障平台 |
| 腿式机构 | 关节力矩、动态稳定、冲击载荷、热管理和跌倒保护 | 四足/人形 |
| 轮腿复合机构 | 切换稳定性、机构锁止、冲击和失效状态 | 复杂地形机器人 |

## 4. 运动学与驱动控制的边界

差速底盘的简化运动学关系（轮半径为 `r`，轮距为 `W`，左右轮角速度分别为 `ω_L` 与 `ω_R`）：

`v = r(ω_R + ω_L)/2`

`ω = r(ω_R - ω_L)/W`

这是理想无侧滑模型。实际误差来自有效轮径差、轮距误差、轮胎变形、地面滑移、载荷变化和脚轮拖曳，需要通过编码器、IMU 或外部测量标定。

底盘控制常见分层：
- 上层规划给出有边界的速度/轨迹目标；
- 实时控制器完成轮速/转向控制和状态反馈；
- 安全相关的速度限制、停止和制动由经风险评估的安全架构实现；
- 普通 ROS 控制节点不能默认承担安全功能。

阿克曼运动学需要结合轴距、前轮转角、轮速和实际转向机构几何建模；舵轮/麦克纳姆/腿式机构应使用对应的运动学与动力学模型。

## 5. 机械尺寸、强度与选型参数

不要用“AMR 常见速度”“通常爬坡百分比”或某一个商用车型作为设计输入。对每个候选构型，至少计算或验证：

- 静载/动载下的框架强度、刚度、局部应力、屈曲和疲劳；
- 额定载荷、偏载、重心、制动和坡道下的稳定性/倾覆裕度；
- 轮胎/履带接地、附着、滚动阻力、越障和地板载荷；
- 电机连续/峰值力矩、减速器额定寿命、热平衡和驱动器再生处理；
- 轮轴、轴承、紧固件、焊缝、连接件和防松设计；
- 线束/电池/计算平台/传感器安装、公差链、维护通道和防护罩；
- 制造工艺、材料批次、表面处理、焊接变形、加工公差和检验方法。

入门估算可从牵引力分解开始：

`F_required ≈ F_roll + F_slope + F_accel + F_other`

坡道分量可近似写为 `F_slope = m g sin(θ)`；加速分量为 `F_accel = m a`。实际项目还要考虑轮地附着、传动效率、负载变化和安全系数；系数与验收条件应由设计依据确定，不能在本页给定一个通用值。

## 6. 选型决策表

| 评价维度 | 对比证据 |
| --- | --- |
| 任务适配 | 路线、速度、转弯、门槛、载荷、对接和工作节拍 |
| 运动学/控制 | 可实现轨迹、最小曲率、横移需求、定位和标定难度 |
| 安全 | 制动、保持、倾覆、夹点、人员检测与安全防护集成 |
| 可靠性 | 轮胎/脚轮磨损、轴承寿命、冲击、振动、防护和维护 |
| 制造与供应链 | 关键零部件可得性、加工能力、公差、维修和替代供应商 |
| 全生命周期成本 | 采购、研发、制造、能耗、耗材、停机、维护和报废 |
| 验证 | 台架、耐久、坡道、越障、制动、振动和现场试验 |

商用产品参数可作为竞品和需求对标输入，但不能作为“自研必须全面超过某一型号”的单一决策规则。需要比较相同工况、载荷、速度、测量方法、支持服务和生命周期成本。

## 7. 制造与验证成果物

- 底盘总装与零件 CAD、工程图、公差和材料规格；
- 结构计算/仿真报告、载荷与稳定性计算；
- 运动学模型、参数标定记录和控制器接口；
- 关键件与装配 BOM、工艺路线、检验要求；
- 牵引/制动/坡道/越障/耐久/振动/环境验证计划与报告；
- 设计变更、失效记录、维修和备件策略。
