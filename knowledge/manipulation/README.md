## 使用边界

仿真中的无碰撞轨迹不等于真实设备安全可执行；逆运动学有解也不等于任务可达、不会碰撞或满足负载和工艺要求。真实设备运行必须结合准确型号/配置、制造商手册、风险评估、现场防护和具备相应能力人员的批准。
