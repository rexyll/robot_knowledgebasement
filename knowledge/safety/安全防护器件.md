# 安全防护器件

> 安全器件的选型必须从危险、所需安全功能和目标性能要求出发。商品名称里有“安全”二字、具备某个检测距离，或可以向 ROS 输出数据，都不代表它适合承担某项安全功能。

## 先修知识与学习目标

先理解 [[功能安全体系]] 的风险评估、PLr、停止行为和验证思路。读完后应能区分普通传感器与安全相关防护装置，知道选型时需要核对哪些正式资料。

## 1. 器件类别与责任边界

| 类别 | 可能用途 | 选型/系统核验重点 |
| --- | --- | --- |
| 急停装置 | 人员主动触发紧急停止功能 | 执行器形式、触点/输出结构、复位方式、适用标准、额定值、环境等级和安全相关控制系统整体验证 |
| 安全激光扫描仪/安全光幕 | 检测人员或物体进入保护区域 | 完整型号/订货号、检测能力、保护距离/角度、响应时间、安装限制、配置工具、安全输出和证书 |
| 安全触边/压敏装置 | 接触后触发安全停止或限制运动 | 触发力/行程、边缘长度、弯曲半径、响应、控制器兼容性、失效监控和测试条件 |
| 安全继电器/安全控制器 | 汇总安全输入并实现逻辑与输出 | 输入/输出结构、诊断、目标性能、配置、兼容器件和验证文件 |
| 安全门锁/联锁装置 | 防止人员进入危险区域或在危险运动时打开防护门 | 锁定原理、逃生/救援、旁路控制、安装和故障响应 |
| 机械防护/缓冲器 | 消除或降低接触、夹挤和碰撞伤害 | 结构强度、间隙、可达性、材料、行程、维护和最坏工况 |

普通 LiDAR、深度相机、超声波或视觉模型可以用于导航/避障，但除非其产品本身及其安装配置满足相关安全要求并经过验证，否则不能作为安全保护功能的检测装置。

## 2. 安全激光扫描仪：不能只看“最大检测距离”

核对数据表时至少记录：
- 完整型号、订货号、硬件/固件版本和证书；
- 检测能力/分辨率、可检测物体尺寸和响应时间；
- 保护距离、扫描角度、安装高度、安装方向和遮挡限制；
- 安全输出接口、诊断信息、配置工具和安全参数锁定方式；
- 保护区/警告区数量、切换条件、切换延迟和切换错误响应；
- 环境温度、振动、污染、反射材质、雨雾/粉尘等使用限制；
- 与整机速度、制动、定位误差和人员可达性的组合验证。

不能用普通导航点云的距离值替代安全扫描仪经验证的安全输出。即使同一设备同时提供安全输出与普通数据接口，也要分别定义信号用途、权限和失效行为。

## 3. 保护区与停止响应

保护区不是一个固定的“半径”。它要依据人员/机器相对运动、总响应时间、机器实测制动性能、检测能力、安装误差、可达性和适用标准计算/设定。

用于理解变量的简化表达式：

`S_total ≈ v_relative × t_response + s_braking + C + Z`

本式不是完整标准公式，也不能直接生成产品保护区。实际计算应采用适用标准和扫描仪制造商正式手册规定的方法，并通过最不利载荷、速度、地面、坡度、电池状态、温度及传感器配置下的测试确认。

速度区域切换还需验证：切换触发信号是否可信、切换期间的响应、切换失败时的安全状态、参数配置是否防止未授权修改。

## 4. 急停、触边与机械缓冲

- 急停、触边和机械缓冲器职责不同。急停是人员主动触发的紧急停止功能；触边是检测接触并触发预定反应；缓冲器可能只提供机械吸能，并不一定是安全输入。
- 不得把所有急停都设计成“直接断开电机电源”。停止行为要结合惯性、坡度、重力载荷和驱动器能力确定，必要时包含受控停止和制动。
- 急停复位不得自动重新启动危险运动；维护前不能仅依靠急停替代能源隔离。
- 触边必须核对具体产品的触发力、动作行程、边缘覆盖、响应、寿命、环境适应性和安全控制器接口，不能使用行业“典型值”直接验收。
- 机械缓冲器应对接触速度、总质量、吸能能力、可用行程、固定结构和重复冲击寿命进行计算/试验。

## 5. 器件选型与系统验证记录

| 字段 | 填写要求 |

| 预期安全功能 | 设备将实现哪项安全需求；不承担哪些功能 |

| 安装配置 | 位置、方向、盲区、保护区、机械防护和参数版本 |
| 环境/边界 | 温度、振动、污染、反射、湿度、清洁方式等 |
| 验证证据 | 测试计划、最坏工况记录、故障注入、报告和批准人 |

## 7. ISO 10218-2:2025 下的应用集成与防护边界复核（2026-11-05）

ISO 10218-2:2025（Edition 2，2025-02）面向**工业机器人应用与机器人工作单元**，不是只针对机器人本体。它覆盖应用/单元的设计、集成、调试、运行、维护、退役和处置，并涉及机器及组件集成、使用信息。机器人本体要求应与 ISO 10218-1:2025 配套理解；不能把本体制造商提供的安全功能清单当作集成单元的风险评估和防护设计。

### 7.1 适用范围必须先于器件选型

ISO 10218-2:2025 的工业环境边界是公众被排除或限制进入、允许进入的人员为工作成年人。其公开范围列出的排除用途包括水下、执法、军事、航空航天、医疗/人体健康、假肢与辅助器具、面向公众的服务机器人、消费产品、载人升降/运输，以及起重机、叉车等多用途起重设备。不能因为设备外观类似工业机械臂，就把该标准自动套用于上述产品或场景；应识别产品预期用途、工作场所、人员群体、移动底盘及配套设备，再确定适用标准组合。

标准还明确有若干未覆盖危险/应用情形，例如噪声排放、超出制造商规格的极端环境、地下/卫生/核/爆炸性环境、特定材料加工、危险载荷、公众或非工作成年人可接近等。此类排除不表示风险不存在，而是要求项目另行识别适用法规、C类标准、设备标准和专项风险控制。

### 7.2 “机器人安全”与“应用安全”是两个责任层

- **Part 1（机器人本体）**：关注工业机器人作为部分完成机械的本体安全设计、风险降低措施和使用信息。
- **Part 2（应用/单元）**：关注集成商将机器人、末端执行器、工件、夹具、外围设备、程序和工艺组合成特定应用后的风险；覆盖集成、调试、功能测试、编程、运行、维护和维修阶段的防护。
- **应用风险**：危险与风险随工件、任务程序、工艺、安装、使用和维护而变化。同一种机器人或同类应用并不意味着风险相同；风险评估必须绑定实际任务、配置和可预见误用。

因此，防护器件的检测距离、输出类型或证书只能作为系统证据的一部分。必须追踪其与危险区域、人员接近路径、响应链、停止行为、控制系统、末端工具和工件的关系，并验证安装后的实际保护效果。

### 7.3 美国项目的法规与共识标准分层

OSHA 官方说明指出，目前没有专门针对机器人行业的 OSHA 标准，但列出可能适用的一般行业法规，例如机器防护、危险能源控制（lockout/tagout）、PPE、噪声和工作场所通道要求。OSHA 页面同时把 ANSI/RIA 等国家共识标准列为指导性标准，而非 OSHA 法规。ANSI/A3 R15.06-2025 是美国工业机器人安全国家标准版本，不能将其误称为 OSHA 法规，也不能以引用该标准替代逐项识别适用的 29 CFR 要求。

OSHA 技术手册部分段落仍引用 2012 年版 ANSI/RIA R15.06 和 ISO 10218:2011。使用该手册作为风险识别参考时，必须与 2025 版标准目录和实际适用法规交叉核对，不能把旧版引用直接当作 2025 版条文解释。

### 7.4 防护器件的应用级证据链

在冻结器件型号和保护区配置前，至少建立以下可追溯关系：

1. 预期用途、工作单元边界、工艺/任务、人员类别和可预见误用；
2. 危险源、危险情境、暴露人员、风险估计及需要实现的安全功能；
3. 安全传感器/联锁/急停/安全控制器/驱动器/制动器的完整型号、硬件固件、证书和配置版本；
4. 传感器安装位置、保护区/警告区、盲区、人员接近路径、响应时间和切换逻辑；
5. 从检测、逻辑处理、通信/输出到驱动停止与机械保持的端到端响应和失效状态；
6. 最坏载荷、速度、姿态、工具/工件、地面、环境、磨损及单故障条件下的验证方案和原始记录；
7. 调试、功能测试、维护、旁路管理、复位/重启、维修和退役的作业控制与使用信息。

**边界声明：** 本节是公开标准目录、公开范围摘要和 OSHA 官方指导的文档级复核；未购买或逐条审查 ISO 10218-2:2025 / ANSI/A3 R15.06-2025 全文，未针对具体机器人应用完成风险评估、器件证书核验、保护区计算、响应/停止测试、故障注入、现场调试或合规评估。不得据此宣称任何设备或工作单元符合标准。


## 8. 代表性安全激光扫描仪：公开规格与配置依赖（2026-11-06）

本节仅建立制造商公开资料的型号族级证据样例，不构成产品排名、采购建议或应用适用性结论。具体项目必须先冻结完整订货号、硬件/固件版本、系统插头/接口、配置软件版本及证书范围，再以对应版本的正式操作说明书和证书复核。

### 8.1 OMRON OS32C：响应时间是安全关键配置，不是固定型号常数

OMRON 官方规格页（页面更新日期 2025-10-01）列出的 OS32C 系列数据包括：

- Type 3 安全激光扫描仪；官方页面声明 PL d / Category 3（ISO 13849-1）及 SIL 2（IEC 61508），具体适用仍须核对完整型号、证书和安装条件。
- 检测角度 270°；安全区距离随最小物体分辨率及具体子型号变化；带 -4M 的型号最高安全区量程可达 4.0 m，而普通型号表列的最高安全区量程为 3.0 m。
- ON→OFF 响应时间可配置为 80–680 ms（2–17 scans）；OFF→ON 响应时间还包含可配置的 100 ms 至 60 s；区域切换时间为 20–320 ms。
- 安全输出为双路 PNP OSSD；辅助输出和警告输出明确为非安全输出，不能把其状态用于替代安全输出。
- Pollution Tolerance Mode 会给每次扫描增加 6 ms；启用后必须重新核对响应时间和安全距离。

OMRON OS32C 用户手册还说明，响应时间由扫描次数决定；修改响应时间后必须重新计算安全距离，必要时重新配置保护区或重新安装。EDM 用于监视外部控制元件反馈；反馈状态未在规定时间内变化时，扫描仪进入 lockout 并关闭安全输出。项目记录必须保留最终参数导出文件和验证结果，不能只保存“默认配置”或软件截图。

### 8.2 SICK microScan3 Core I/O：扫描周期、干扰抑制和多重采样共同决定响应

SICK 官方 microScan3 Core I/O 操作说明（文档标识 8016346/1SK3/2025-07-04）列出的该产品变体数据包括：4.0 m 或 5.5 m 保护区量程选项、275° 扫描角、30/40/50/70/150/200 mm 可配置保护区分辨率，以及 30 ms 或 40 ms 可调扫描周期；该文档给出的响应时间下限为 70 ms，实际响应时间需根据扫描周期、干扰抑制设置和多重采样计算。

手册给出的计算关系为：

    t_R = (t_S + t_I) × n + t_O

其中扫描周期 t_S、干扰抑制时间 t_I、多重采样次数 n 和输出处理时间 t_O 都会影响实际响应时间。手册还要求把安全控制器处理、下游接触器等后续链路延迟计入危险状态终止时间；不能把扫描仪 OSSD 关闭时间直接当成整机停止时间。

该手册要求保护区计算考虑机器停止时间、保护装置响应时间、人员接近速度和检测分辨率，并对 70 mm 分辨率下的腿部检测和扫描平面安装高度给出条件限制。具体安装与最小距离必须依照目标地区适用标准及该完整型号的当前手册计算，不能把产品页上的最大量程当成可用保护距离。

### 8.3 跨型号比较时必须避免的错误

| 易混淆项 | 正确记录方式 |
| --- | --- |
| 最大量程 | 区分安全区与警告区；记录完整订货号、分辨率和环境/反射条件 |
| 响应时间 | 记录配置值、扫描周期、多重采样、干扰抑制、污染过滤和输出延迟 |
| PL/SIL/Type | 记录制造商声明、证书编号/范围、标准版次及证书适用边界；不得由产品系列网页推断整机达到相同等级 |
| OSSD 与辅助数据 | 双路安全输出、非安全辅助/警告输出、Ethernet测量数据分开建模；不得把普通数据接口当作安全通道 |
| 保护区切换 | 验证选择输入、切换延迟、切换失败状态、位置/速度来源及配置权限 |
| 安装与覆盖 | 检查盲区、近场限制、反射体、地面坡度、扫描平面高度、人员接近路径和机械遮挡 |
| 端到端停止 | 计入传感器、逻辑求解器、通信、驱动器、制动器和机械运动的最坏响应/停止时间 |

### 8.4 标准版次动态

截至本次复核，ISO 官方页面仍将 ISO 3691-4:2023（Edition 2，2023-06）列为已发布版本，同时列出 ISO/DIS 3691-4 第三版处于制定中/投票结束阶段（Stage 40.60），并表示未来将替代 2023 版。知识库应同时记录“现行已发布版”和“后续草案”，在新版正式发布前不得把 DIS 草案写成现行要求，也不得提前按草案替代现行版进行合规声明。
