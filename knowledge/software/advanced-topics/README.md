## 主题边界

- 本目录存放跨软件子系统的专题正文；操作系统、实时内核和车载网络专题按其主归属章节存放，本目录通过链接导航。
- 一般软件架构、构建、测试、可观测性、发布和供应链内容仍归入上一级 `knowledge/software/` 对应专题。
- PCB/EMC、机械材料和MCU外设等跨领域缺口由相应主归属章节维护，不因被扩展知识页引用而转移所有权。
- 具体技术结论以专题正文、版本锁定、官方来源和测试证据为准；“定向主张审查”不等于目标项目构建、互操作或实机验收。
