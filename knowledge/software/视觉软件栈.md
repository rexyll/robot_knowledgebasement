# 视觉软件栈

> 从相机 SDK 到深度学习推理的完整视觉链路。机器人视觉 = 标定 + 图像处理 + 感知推理 + 与导航/控制的数据闭环。

## 分层架构

```
应用层: 障碍检测/行人识别/抓取定位/缺陷检测/污渍识别 → [[视觉感知算法]]
推理层: PyTorch 训练 → ONNX → TensorRT/OpenVINO 端侧加速 → [[计算平台]]
算法层: OpenCV(基础)/PCL(点云)/Halcon(工业)/自研 SLAM → [[视觉SLAM]]
驱动层: 相机 SDK(海康MVS/Basler Pylon/RealSense)、GenICam/ GigE Vision/USB3 Vision 标准
```

## 核心工具库

| 库 | 定位 | 关键能力 |
|---|---|---|
| **OpenCV** | 视觉基础事实标准 | 滤波/特征(SIFT/ORB)/标定(calibrateCamera/stereoCalibrate)/图像几何/条码 |
| **PCL** | 点云处理 | 滤波(VoxelGrid/StatisticalOutlier)/分割(SAC 平面/欧式聚类)/配准(ICP/NDT)/Octree |
| Eigen | 线性代数（SLAM 标配） | 四元数/SO3/Lie 群（配 Sophus） |
| Ceres/g2o/GTSAM | 非线性优化（后端） | BA、位姿图优化、IMU 预积分 |
| Halcon | 商业工业视觉 | 亚像素/测量/OCR/3D 匹配，贵但强（集成案例 [[项目-Bozlin视觉框架]] 类系统） |
| mmcv/ultralytics/YOLO | 深度学习检测 | YOLOv8/11 训练-导出链 |
| TensorRT | NVIDIA 推理加速 | FP16/INT8 量化，YOLO 15-30fps@Orin |

## 标定链条（机器人视觉的地基）

| 标定 | 方法 | 精度量级 |
|---|---|---|
| 相机内参 | 棋盘格/圆点板，张正友法 | 重投影误差 <0.1px |
| 双目外参 | stereoCalibrate | 立体匹配深度误差 1-2%@2m |
| 相机-IMU | Kalibr（连续时间 BA） | 时延 ms 级 + 外参 |
| LiDAR-相机 | 靶标投影法/像素梯度法 | 2-5cm/1-2px |
| 手眼标定（Eye-in-Hand/To-Hand） | AX=XB（Tsai/Park） | 机械臂抓取精度根基 |
| 地面/安装外参 | 平面拟合+人工选点 | AMR 传感器安装校验 |

## 相机-帧同步与时戳（多传感器对齐）

- 硬触发 > 软件时间戳；GigE Vision PTP（IEEE 1588）亚毫秒同步
- ROS2 `message_filters::TimeSynchronizer` / ApproximateTime → [[ROS与ROS2]]
- 时戳错 10ms @1m/s = 1cm 空间误差，直接毁掉融合定位 → [[多传感器融合定位]]

## 工业视觉框架形态（对照 [[项目-Bozlin视觉框架]]）

```
设备抽象(Camera SDK 插件) → 采集流水线(线程池/环形缓冲)
  → 算法插件(注册表+参数模板) → 结果路由(HTTP/TCP API/PLC 信号)
  → 框架服务(HTTP Server + Daemon 守护 + 更新器)
```

- 关键设计：**算法与设备解耦**（插件注册）、**结果结构化**（JSON/结构体契约）、**守护与自更新**（Daemon/Guardian/update 模块）
- 商业对标：Halcon HDevelop + 应用壳、Cognex VisionPro、海康 Vision Master
