# 医疗器械独立软件与手术规划系统

> 本文以华科精准脑外科手术计划软件SinoPlan公开审评资料为案例，提炼独立医疗器械软件的产品边界、影像规划数据流和验证思路。案例信息不等于通用法规条款。

## 2. 典型规划数据流

以下为根据公开审评报告披露的模块和原理抽象的工程数据流，不代表SinoPlan内部实现细节：

1. **患者与序列管理**：组织患者、检查和序列关系；校验标识、序列归属、影像方向、体素间距、层间距、坐标元数据及数据完整性。
2. **多模态影像导入**：接收CT、MRI等临床影像。具体格式、协议、兼容设备和字段约束必须以注册产品技术要求及说明书为准。
3. **图像配准与融合**：建立不同模态影像间空间对应关系。设计文件应记录参考图像、浮动图像、变换方向、矩阵、插值方法和配准质量指标；实际算法类型须由产品资料证明。
4. **分割与三维重建**：提取血管、病灶和关键解剖结构。验证边界误差、拓扑连续性、细小结构保留、体积/距离测量误差及人工修订可追溯性。
5. **坐标系与头架参数计算**：审评报告提及AC-PC-IH坐标系、坐标转换准确性、关键解剖结构相对位置稳定性和显影标记解剖坐标准确性。系统应明确定义影像、患者解剖、规划和设备/头架坐标系，统一左右手系、轴方向、单位、原点及变换方向。
6. **计划生成与导出**：输出靶点、轨迹、避让结构及设备所需参数。接口格式、字段语义、单位、坐标约定、版本兼容和数据完整性需纳入接口控制文件与验证。
7. **复核与追溯**：保存操作者、输入数据版本、算法/软件版本、参数、人工修改和导出记录。

## 3. 坐标变换的工程控制

多级坐标映射应逐级定义并测试。若采用齐次变换矩阵，需明确矩阵表达的坐标变换方向及乘法次序。至少覆盖：

- 单位一致性、左右手坐标系、原点和轴方向；
- 患者体位、影像方向标记和坐标元数据；
- 正向/逆向变换一致性；
- 已知基准点的坐标转换误差；
- 关键解剖结构相对位置稳定性；
- 显影标记点定位误差和异常标记检测；
- 数值精度、舍入、边界条件及矩阵病态情形；
- 数据导入/导出后的坐标、单位和方向一致性。

平均误差不能单独代表临床可接受性；阈值需由预期用途、临床风险、测量不确定度和适用标准共同论证。

## 4. 软件验证矩阵

下列项目由CMDE个案报告披露的比较/验证维度转化而来，是工程检查清单，不表示所有医疗软件均有相同法定强制测试项。

| 验证域 | 典型问题 | 建议证据 |
|---|---|---|
| 数据输入 | 患者/序列错配、缺字段、损坏影像能否识别 | 正常/异常样本、边界用例、日志 |
| 图像配准 | 多模态影像空间对齐是否可靠 | 基准数据集、标志点误差、独立复核 |
| 图像融合 | 融合后关键结构是否偏移或失真 | 图像质量评价、结构位置测量 |
| 分割重建 | 关键结构边界和三维几何是否稳定 | 参考标注集、误差统计、专家复核 |
| 坐标系 | 坐标定义和转换方向是否一致 | 坐标系说明、基准点和逆变换测试 |
| 头架参数 | 计算结果是否与独立基准一致 | 独立计算、基准工装、误差报告 |
| 计划接口 | 导入导出字段、单位、坐标是否无损 | 接口测试、往返测试、兼容矩阵 |
| 性能效率 | 处理时间和资源占用是否满足场景 | 代表性数据规模、压力测试 |
| UI与消息 | 关键状态、警告和错误是否正确呈现 | 可用性测试、异常流程覆盖 |
| 访问授权 | 身份、授权文件和访问控制是否有效 | 权限矩阵、授权失效/恢复测试 |
| 可靠性维护 | 崩溃恢复、持久化、升级回滚是否受控 | 长稳测试、故障注入、升级验证 |

## 5. 生命周期、风险与网络安全

CMDE报告提及《医疗器械软件注册审查指导原则（2022年修订版）》和《医疗器械网络安全注册审查指导原则（2022年修订版）》。实际申报应查阅现行有效的官方指导原则、标准和法规原文，并按产品特性确定适用性。

建议建立可追踪链：预期用途→用户需求→系统/软件需求→架构设计→详细设计→实现→单元/集成/系统验证；同时建立危险情形→风险控制→设计实现→验证确认→残余风险评价的闭环。记录软件版本、配置项、第三方组件、开发工具、已知异常和变更影响分析。若具备电子数据交换、远程访问/控制或用户访问等网络功能，应评估身份认证、授权、审计、数据保护、备份恢复、更新机制及漏洞处置。

指导原则是审评指导文件，不应不加区分地称为强制性法规；个案报告中的验证项目也不能自动升级为所有产品的统一强制清单。

## 6. 最小验证闭环

1. 冻结代表性输入数据集及来源、授权、匿名化和版本哈希。
2. 为每个算法模块定义输入、输出、失败模式、性能指标和临床风险。
3. 建立独立参考值/参考流程，避免同源算法自证正确。
4. 分别测试单模块精度、端到端误差、异常输入和数据往返一致性。
5. 报告误差分布、失败样本、人工复核和已知限制。
6. 对软件升级、算法变更、操作系统和第三方库变更执行影响分析及回归测试。
7. 建立软件版本、注册版本、技术要求版本、说明书版本和部署版本的追踪映射。

## 9. 注册证纠错与证据追踪（监管流程补充）

NMPA政务服务门户“医疗器械注册证纠错”办事指南（#797）将该事项列为国家级公共服务，列出的可申请纠错情形包括：注册证、变更文件及附件打印错误；注册证编号错误；企业填报错误；审评审批工作中的其他错误。指南同时列明申请材料、审核流转和办理后由NMPA信息中心在官网公布相关信息的机制。

工程与注册档案管理上，应把“注册事项变更”和“注册文件纠错”分开建模：纠错针对文件/信息错误，不应仅因出现纠错记录就推断产品技术方案、适用范围或软件版本发生了实质变更。核验某个具体产品沿革时，至少应收集原注册证、变更文件、纠错申请/决定、被替代或废止文件、当前电子注册证及其附件，并建立字段级差异表。

#797仅为通用办事指南，不能证明华科精准国械注准20183010598个案确已办理纠错。第三方页面所述2023-12-14纠错和2023-09-22变更文件废止仍待官方个案文件确认。

### 9.1 电子注册证获取、授权与验真（#807）

NMPA信息中心《电子证照社会化应用指南》（2025年8月，#807）补充了个案证据获取路径：

- 指南将医疗器械电子注册证的持证主体定义为注册人，国产第三类器械电子注册证的接收单位也是注册人。
- 企业需在NMPA政务服务门户注册并实名认证。电子证照文件（OFD/PDF）仅支持法定代表人账户下载；法定代表人可将“我的证照”授权给经办人，经办人可查看已授权证照及制作加注件。不能将“经办人可查看/加注”误写成经办人可直接下载原始证照文件。
- 电子证照二维码可查询证照最新状态、版式及变动记录；门户支持上传OFD/PDF进行在线核验。对外接收的证照副本应保留原始文件和验真结果，不以网页摘要或第三方转录替代。
- 如电子证照无法正常获取或照面信息显示错误，指南指向“电子证照纠错联系方式”。这是电子证照文件获取/照面问题的联系路径，不等于产品注册事项变更，也不构成某个注册证的个案纠错决定。

**个案取证建议：** 请注册人法定代表人从法人空间下载对应注册证OFD/PDF，授权合规经办人查看；同步导出或保存二维码展示的生命周期/变动记录、相关变更文件及产品技术要求/说明书附件。对20183010598、20193011036、20223010024分别形成独立证据包，字段级比较注册人名称、住所、型号规格、结构组成、适用范围、附件版本和文件签发/废止关系。仓库维护者不应尝试访问企业法人空间或把公开送达清单当作原始证照。

#807仅证明通用电子证照机制，不证明华科精准具体证号的电子证照已被下载、验真或完成纠错。#797所述医疗器械注册证纠错办事指南与#807电子证照纠错联系方式应分别记录，避免混淆纸面/注册信息纠错和电子证照文件纠错。

## 9.2 电子注册证正文与附件的法律/交付边界（#813）

国家药监局《关于全面实施医疗器械电子注册证的公告》（2022年第91号，2022-10-24发布）明确，自2022-11-01起，国家药监局批准的国产第三类及进口第二、三类医疗器械注册证和注册变更文件全面实施电子证照；电子注册证与纸质注册证具有同等法律效力。**电子注册证正文不包含产品技术要求、说明书等附件**，这些附件以独立电子文件同步推送至国家药监局网上办事大厅法人空间“我的证照”栏目，推送成功即送达（#813）。

因此，针对国械注准20183010598、国械注准20193011036、国械注准20223010024取证时，应分开验收以下对象，而不能把单份OFD/PDF证书视为完整注册档案：

1. 当前电子注册证正文及其二维码/签章验证结果；
2. 产品技术要求、说明书及其他随证附件的完整文件；
3. 历次注册变更文件、纠错文件及变更对比表；
4. 法人空间的证照变动记录、送达时间和被替代/废止文件关系。

该公告确立通用电子证照交付制度，不证明任何华科精准个案的附件实际已推送、注册人已下载、纠错已完成或旧文件已被特定新文件替代。#807是电子证照社会化应用指南；#813是实施电子注册证及附件同步推送的公告，两者互补而非相互替代。
