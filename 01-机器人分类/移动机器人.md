# 移动机器人（AGV / AMR / IGV）

> 本知识库的核心主题。自主移动机器人 = 感知 + 定位 + 规划 + 控制的轮式（为主）平台。

## 概念辨析（最重要的一张表）

| 维度 | AGV | IGV | AMR |
|---|---|---|---|
| 全称 | Automated Guided Vehicle | Intelligent Guided Vehicle | Autonomous Mobile Robot |
| 导航方式 | 固定路径：磁条/磁钉/二维码/色带/激光反射板 | 自然导航（SLAM），路径较固定 | 自然导航+动态重规划，自由路径 |
| 改线成本 | 高（施工改造） | 中 | 低（软件配置） |
| 避障能力 | 停车/绕行有限 | 有 | 主动动态避障 |
| 部署周期 | 周-月 | 天-周 | 小时-天 |
| 典型代表 | 传统激光叉车 | 磁导航升级版 | 极智嘉、海康、MiR、OTTO |
| 倾向场景 | 节拍固定的流水线 | 半结构化产线 | 高动态仓储/柔性产线 |

> 行业趋势：AGV 市场份额逐步让渡给 SLAM 导航的 AMR；两者常混合部署，统一由 [[调度系统RMS]] 指挥。

## 分类补充

- 按 **应用形态** 细分 → [[仓储物流机器人]]（搬运/分拣/仓内）、[[清洁机器人]]（商用清洁也是 AMR 的一大垂直）、[[服务机器人]]（配送/酒店）

## 关键技术难点

1. 长走廊/重复纹理下的 **定位鲁棒性** → [[多传感器融合定位]]
2. 人机混行动态环境的 **避障与社交导航** → [[局部规划与避障]]
3. 多机 **死锁/拥堵** → [[多机协同与调度算法]] · [[多机调度流程]]
4. 货物/货架识别 → [[视觉感知算法]]
5. 断电/急停后的 **恢复策略** → [[功能安全体系]]

## 细节加深（V2）
- **AGV→AMR 迁移的隐藏成本**：磁条/二维码改线停产的产线，换 SLAM AMR 时「工艺节拍重排」往往比机器人本身贵——需求评审时把「换线频率」当一票否决项。
- **整机开源参考**（台账 #2/#25 已验证）：LinORobot2（Apache-2.0，Jazzy 分支）与 Articulated Robotics 系列——从0搭建的公共答案库。
- **导航方式混合部署**：反光板区（高精度对接）+SLAM 区（柔性通道）在同图共存是商用主流——[[Nav2导航框架]] 的 keepout+dock 点位配合 [[充电桩与自动充电]]。
