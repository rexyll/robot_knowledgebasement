# 轨迹优化与运动控制

> 控制栈自底向上：电流环（FOC, kHz）→ 速度环（底盘 PID, 100Hz-1kHz）→ 路径跟踪（纯跟踪/Stanley, 20-50Hz）→ 轨迹优化（MPC, 10-20Hz）。本页聚焦中层：**路径跟踪 + 轨迹优化 + 运动学/动力学**。

## 运动学模型（控制器的心智模型）

| 模型 | 约束 | 状态 |
|---|---|---|
| 差速（unicycle） | v, ω 直接可控 | [x, y, θ] |
| 阿克曼 | 最小转弯半径 R=L/tanδ_max | [x, y, θ, δ] |
| 舵轮/全向 | v 任意方向 + ω | [x, y, θ, vx, vy] |
| 动力学自行车 | 轮胎侧偏（高速才需要） | +侧偏角 |

## 路径跟踪算法对比

| 算法 | 原理 | 稳定性 | 适用 |
|---|---|---|---|
| **Pure Pursuit（纯跟踪）** | 从车体向前找预瞄点 l_d，圆弧逼近 | 平滑但切内弯 | 低速 AMR 主力（Nav2 RPP 加了速度调节） |
| **Stanley** | 前轴横向误差+航向误差几何反馈 | 高速好 | 无人车 |
| **LQR 跟踪** | 线性化误差动力学二次型最优 | 理论优 | 中高速 |
| **MPC（模型预测控制）** | 滚动时域优化未来 N 步控制序列（约束全给上） | 最强但最重 | 动态避障/满载/精细对接 |
| PID 直控（v,ω 误差） | 简单可靠 | 兜底 | 低成本机型、调试期 |

预瞄距离 `l_d = k·v`（速度越远看越远），k=0.3-0.8s 经验值——清洁机/AMR 常用 0.4s。

## 轨迹优化（规划与控制的缝合层）

- **TEB**：把路径节点做成"弹性带"，时间/速度/加速度/避障/运动学全进图优化（g2o）
- **MPC 轨迹跟踪**：`min Σ‖x-x_ref‖²_Q + ‖u‖²_R s.t. 运动学+避障+执行器约束`（OSQP/acados 求解器，1-5ms）
- 平滑后处理：B 样条/Brezier 曲线 + 速度剖面（V-t 图 + 梯形/S 曲线加减速）
- **加减速纪律**：AMR 加速度 ≤0.5-1.0 m/s²、向心加速度 ≤0.3-0.5g——超了甩货/打滑（满载再降 30%）

## 与底盘执行层的接口（→ [[底盘与运动机构]]）

```
控制栈输出: Twist(v, ω) @20-50Hz → 串口/CAN → MCU
MCU: 运动学逆解(差速/阿克曼) → 1kHz PID → FOC 电流环 → [[电机与驱动器]]
安全联锁: 心跳超时200ms刹停 / 速度限幅 / 触边优先级最高
```

## 调参速查（AMR 场景）

| 参数 | 症状→药方 |
|---|---|
| 预瞄太短 | 蛇形摆动 → 加大 l_d |
| 预瞄太长 | 切弯抄近道撞墙 → 减小 |
| 速度环 P 大 | 电机啸叫震荡 → 降 P 加 D |
| 加速度太猛 | 货物位移/报警 → 限 acc_lim |
| 停靠过冲 | 到点刹不住 → 提前减速带/降 max_vel 接近段 |

## 细节加深（V2）
- **RPP 官方文档**（台账 #66）：Nav2 的 Regulated Pure Pursuit 带曲率限速与接近减速——比教科书版纯跟踪多两层保护，重载首选。
