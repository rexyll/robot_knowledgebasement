# 卡尔曼滤波（KF / EKF / ESKF / 粒子滤波）

> 融合定位与 LIO 的数学发动机：**预测-修正**框架下，用带噪声的观测最优（最小方差）估计系统状态。SLAM、VIO、SOC 估计、目标跟踪全部用它（→ [[多传感器融合定位]] · [[激光SLAM]]）。

## 基础 KF 五公式（线性高斯假设）

```
预测: x̂ = F x + B u;    P = F P Fᵀ + Q
修正: K = P Hᵀ (H P Hᵀ + R)⁻¹     ← 卡尔曼增益(信谁多一点)
      x̂ = x̂ + K (z - H x̂)        ← 残差加权
      P = (I - K H) P
Q=过程噪声(模型多不可信), R=观测噪声(传感器方差)
```

直觉：**预测把不确定性吹大（+Q），观测把不确定性压小（×K）**，K 由双方不确定度比例决定。

## 非线性扩展（机器人全是非线性）

| 变体 | 思路 | 用途 |
|---|---|---|
| **EKF** | 一阶泰勒展开雅可比 | 简单融合、robot_localization |
| **ESKF/误差状态 KF** | 主状态(流形上的真值)+小量误差状态估计 | VINS、IMU 融合标准姿势（避免旋转角过零/万向锁） |
| **UKF** | Sigma 点无迹变换采样传播 | 强非线性、难求雅可比 |
| **粒子滤波（PF）** | 非参数采样，权重=似然 | **AMCL**（多峰假设：doorway 歧义）、Gmapping（RBPF-SLAM） |
| **迭代 EKF / iEKF** | 围绕最新估计反复线性化 | **FAST-LIO2 的 iEKF**，残差在地图上迭代 |

## IMU 预积分（VIO/LIO 关键积木）

- 问题：IMU 200-1000Hz、图像 10-30Hz，逐帧积分状态不可行
- 方案：Forster 2017 预积分——两个关键帧间的 IMU 增量**与初始状态无关**，可预先算好，PVQ/偏置变化时线性重算
- 实现：GTSAM `PreintegratedImuMeasurements`、VINS 自实现
- 深入场景 → [[视觉SLAM]]（滑窗因子）· [[激光SLAM]]（LIO-SAM 因子图）

## 可观性分析（为什么有些状态估不出来）

- 单目尺度：不可观 → IMU 加速度激励可观测（VIO 初始化的三角激励运动）
- 匀速直行：IMU 零偏与速度耦合不可分 → 需要机动
- 工程含义：初始化阶段的"8 字晃动"不是玄学，是可观性激励

## 调参经验（Q/R 治百病也坑百人）

1. **Q 过大**：信观测过头，输出抖动跟着噪声走
2. **R 过大**：信模型过头，修正迟钝漂移累积
3. 实操：静止采集传感器数据估 R（方差），Q 从小往大调至响应跟上
4. NIS/NEES 一致性检验：残差应服从理论分布，否则模型错了
5. 粒子滤波：粒子数 500-5000（AMCL adaptive 减少粒子数）；重采样防退化（有效粒子数 <1/2 触发）

- **学习路径**（中文高赞 #85/#86 已验证）：先 KF 五公式手推 → EKF 雅可比 → ESKF（旋转流形）→ 因子图（GTSAM 教程）；跳过前两步直接用库，调参时必死。
