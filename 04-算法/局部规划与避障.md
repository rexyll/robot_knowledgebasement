# 局部规划与避障

> 实时把全局路径变成对动态世界安全的速度指令（v, ω @20-50Hz）。上游 [[路径规划算法]]，下游 [[轨迹优化与运动控制]]。

## 主流算法对比

| 算法 | 思想 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| **DWA** | 速度空间采样→前向仿真→评分(朝向/距离/速度) | 简单快、成熟 | 只能低维、路径质量差 | 低速室内 AMR（Nav2 DWB） |
| **TEB** | 时间弹性带：图优化路径节点（时间+避障+运动学约束） | 轨迹质量好、倒车/掉头自然 | 优化慢(10-50ms) | 阿克曼、需倒车场景 |
| **RPP（Regulated Pure Pursuit）** | 纯跟踪+速度调节 | 极稳、无优化发散风险 | 避障弱（靠重规划） | 直道多场景、重载（甩货敏感） |
| **MPPI** | 采样式模型预测控制（GPU 加速） | 处理非线性+动态障碍强、可学习代价 | 算力大 | Nav2 新默认、中高端 |
| **VFH±** | 极坐标直方图选可行方向 | 轻量 | 精度低 | 简单机器人 |
| 人工势场 APF | 目标引力+障碍斥力 | 快 | 局部极小值陷阱 | 只做教学/兜底 |

## 动态障碍处理（人机混行核心）

```
感知: LiDAR聚类/深度相机分割 → 障碍列表(位置/速度/类别) → [[视觉感知算法]]
预测: 恒速外推(0.5-2s) / 社会力模型 / 学习预测(Trajectron++)
决策: 时间冲突检测(我到他未来的位置才减速) / 让行规则(右让左、机让人)
执行: costmap 加"预测足迹层" 或 MPC 约束里加他人轨迹
礼仪参数: 绕人距离 0.8-1.2m、不贴人后方穿行、电梯口排队
```

## 代价地图实时层（数据融合枢纽 → [[Nav2导航框架]]）

- Obstacle Layer：LiDAR 每帧写入，衰减清除（raytrace 清老障碍）
- Voxel Layer：深度相机 3D 低矮障碍（桌腿/线缆）
- Range Layer：超声波锥形投影
- Inflation：按半径+速度动态膨胀（速度快膨胀大）
- Keepout：电子围栏/单向道/限速区（与调度规则同源 → [[多机协同与调度算法]]）

## 避障性能链路预算（延迟决定安全）

```
LiDAR 10-25Hz(40-100ms) + 感知处理 20-50ms + 规划 20-50ms + 通信 10-30ms + 底盘响应 100-300ms
总回路 ~200-500ms → v=1.5m/s 时刹停盲走 0.3-0.75m
→ 依赖 [[安全防护器件]] 硬件层兜底(独立回路 <10ms)
```

## 死锁与震荡（工程最常见毛病）

| 现象 | 原因 | 药方 |
|---|---|---|
| 左右摆头 | DWA 评分对称 | 加朝向滞后项/降低采样噪声 |
| 原地转圈 | 目标在膨胀区内 | xy_goal_tolerance>inflation_radius |
| 对堵死锁 | 两机互让协议缺失 | 优先级仲裁/调度器重排 → [[多机协同与调度算法]] |
| 门口反复横跳 | 窄道通过性不足 | Rotation Shim(先转向再过)/窄道限速区 |

## 细节加深（V2）
- **官方插件文档三件**（台账 #65/#66/#67）：MPPI（动态强，GPU 友好）/ RPP（稳，重载首选）/ TEB（倒车窄位）——选型口诀「直道重载 RPP、动态密集 MPPI、需要倒车 TEB」。
- **TEB 仓库**（#67 BSD-3，ROS1/2 双支持）：调参文档在 wiki——`max_vel_x_backwards`、`min_obstacle_dist` 是阿克曼机型前两个要动的参数。
- **MPPI 是"采样式 MPC"**：不需要求导/凸化，代价函数随便写（学习型代价也能插）——这也是它与 [[学习型机器人算法]] 的接口点。

## 两个高频工程误区（V3 · 附件整合）

> 来源：用户附件 PDF（DeepSeek 会话，2026-11-01 导出）。

1. **膨胀半径不是"速度相关量"**。它由**机器人外接圆 + 控制精度 + 感知延迟**共同决定，而不是"开得快就调大"。高速场景真正该提高的是**控制频率与感知更新率**；盲目增大膨胀半径会在窄走廊制造"假死路"（明明过得去却规划不出）。
2. **局部代价地图的"滚动窗口"必须与速度匹配**。窗口太小 → 高速时看不到足够远的障碍；太大 → 局部规划计算负担上升，且可能把远处无关障碍纳入战术决策。经验准则：**窗口前向覆盖 ≥ 当前速度下的制动距离**（与 [[底盘与运动参数]] 的制动距离公式联动）。
