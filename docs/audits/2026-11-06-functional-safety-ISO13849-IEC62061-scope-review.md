# 功能安全体系：ISO 13849-1 与 IEC 62061 范围主张定向复核

- 审查日期：2026-11-06
- 资产：`knowledge/architecture/workflows/功能安全体系.md` §10
- 风险类别：P0 功能安全/法规边界
- 结论：公开范围与版次主张完成定向复核；整篇资产仍未完成 claim-level 验收

## 1. 核验范围

| 主张 | 官方公开证据 | 结论与限制 |
|---|---|---|
| ISO 13849-1 版次 | ISO 官方产品页：ISO 13849-1:2023，Edition 4，2023-04，Published | 只确认产品页元数据，未审读全文。 |
| ISO 13849-1 设计对象 | SRP/CS 设计与集成方法，包含软件 | 不能将其视为所有安全相关产品组件的完整产品标准。 |
| ISO 13849-1 运行模式 | 官方摘要明确高需求/连续模式适用，不适用于低需求模式 | 低需求模式应按 IEC 61508 系列及适用标准处理。 |
| PLr 分配 | 官方摘要明确不规定特定应用的安全功能或所需 PLr | PLr 必须由具体风险评估和适用 C 类标准确定。 |
| IEC 62061 版次 | IEC 合并版页面列 IEC 62061:2021+AMD1:2024+AMD2:2026 CSV，Edition 2.2，2026-03-20，290页 | 只核验页面元数据；未取得合并版全文。 |
| IEC 62061 范围 | 机械安全相关控制系统的设计、集成和验证；IEC 61508 框架下的机械行业标准 | 公开摘要指出主体面向高需求/连续模式；复杂可编程电子子系统或子系统元素的设计不在该标准范围内。 |
| 排除边界 | IEC 页面明确指出电气控制设备本身电气危险由 IEC 60204-1 等处理，机器级其他防护要求及具体网络安全措施不由 IEC 62061 覆盖 | 不能以功能安全控制系统标准替代整机防护、电气安全和网络安全审查。 |

## 2. 正文修订

新增 §10，包含两项标准的比较、适用模式、工程选用步骤、PLr/SIL边界及禁止推导事项。明确标准选用应结合机器类别、目标市场、风险评估和 C 类标准；不得直接换算 PL/SIL 或把组件等级等同整机等级。
