# 迈步机器人康复外骨骼产品线与医疗器械注册状态复核（2026-11-15）

## 1. 审查范围与结论摘要

本报告针对迈步机器人（MileBot）公开展示的 H/B/A/C 系列医疗康复产品，复核其注册人主体、第二类医疗器械注册证线索、型号映射、有效期和公开产品页之间的关系。只进行公开资料静态核验；未取得企业法人空间电子注册证、注册变更/延续附件、完整产品技术要求或说明书。

**最重要的新证据：** 湖南省药品监督管理局《2026年第44号公告》附件1将“湘械注准20262190524”列入2026年9月首次注册第二类医疗器械产品目录：注册人迈步机器人科技（长沙）有限公司，产品名称“下肢外骨骼康复训练机器人”，批准日期2026-09-24，有效期至2031-09-23。该事实来自省药监局官方公告和原始PDF附件，而非第三方转载。

**关键边界：** 20262190524属于2026年9月“首次注册第二类医疗器械产品”目录中的新注册记录，不是该公告所称的“延续注册”。它与旧证湘械注准20212190586具有相同的产品通用名称，但目前没有电子证照/附件证明它是旧证续证、变更、换证或仅覆盖旧证型号的延续关系。因此不能写成“旧证已自动续期”，也不能用新证反推旧证在2026-04-25后继续有效。

## 4. 主体、生产地址与注册人分离

2026年9月官方注册目录将注册人列为“迈步机器人科技（长沙）有限公司”；当前MileBot官方网站页脚标注的版权所有主体为“深圳市迈步机器人科技有限公司”。本轮没有获得市场监管登记档案、委托生产合同、注册证附件或授权关系文件，无法确认两主体之间的股权、控制、授权或生产关系。

采购和供应商建档应分别核对：
1. 注册人/备案人法定名称及统一社会信用代码；
2. 实际生产企业、生产地址和生产许可证；
3. 产品品牌运营主体、销售主体及其授权关系；
4. 质量管理体系覆盖的实际场地和产品；
5. 注册证变更、委托生产及受托生产信息。

不得把品牌相同或同一官网展示的产品，视为同一注册人或同一生产主体。

## 5. 注册状态与适用范围结论

1. **可以确认：** 湘械注准20262190524已被湖南省药监局2026年9月首次注册第二类医疗器械产品目录列出，注册人、产品通用名称、批准日期和有效期字段均有官方公告证据。
2. **不能确认：** 新证是否承接旧证湘械注准20212190586、是否涵盖BEAR-H1/H2或EXO-H1/H3/H4、是否改变了适用人群/范围、是否覆盖当前H系列展示的六关节配置。
3. **旧证边界：** 湘械注准20212190586第三方列示有效期2026-04-25已过；官方遗失声明证明曾申请补发，但未查到补发决定和现行电子证照。因此旧证当前状态和沿革仍待官方核验。
4. **其他证照：** 20222192120与20222192119只作为第三方证书线索，不升级为已核验证照；A/B系列具体映射、C系列注册状态仍待核实。
5. **临床边界：** 注册目录不披露具体适用范围、禁忌症、患者体重/身高约束、训练模式和风险控制细节。厂商网页所列规格不得直接当作对应注册证技术要求或临床适用范围。
