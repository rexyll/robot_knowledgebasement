- 风险类别：P0 硬件/功能安全边界

## 1. 核验的主张

| 主张 | 证据与结论 | 限制 |
|---|---|---|
| 当前出版物版次/状态 | IEC 官方页面列出 IEC 61800-5-2:2016+AMD1:2026 CSV，Edition 2.1，发布日期 2026-10-30，状态 Valid，167 页。 | 只核验官方产品页元数据，未取得标准全文。 |
| 标准的产品范围 | IEC 官方摘要将其定位为可调速电力驱动系统 PDS(SR) 的功能安全设计、开发、集成与验证要求，并说明其为产品标准。 | 准确产品是否属于 IEC 61800 系列范围，仍须按设备规格和 IEC 61800-2 判断。 |
| PDS(SR) 与应用集成边界 | ANSI/UL 公开预览的 IEC 61800-5-2:2016 基础版第 1 章说明，标准所称 integration 指 PDS(SR) 本身，不是将其集成进安全相关应用。 | 预览不是 2026 合并版完整文本；仅作基础版范围证据。 |
| 应用风险分析/初始 SIL 分配 | 基础版范围预览列明标准不规定特定应用的危险与风险分析、应用安全子功能识别和初始 SIL 分配。 | 具体机器/装置仍须按适用法规/标准和风险评估确定。 |
| 被驱动设备、制造过程、信号有效性、安全访问 | 基础版范围预览列明被驱动设备（接口安排除外）、次生危险、PDS(SR) 制造过程、输入信号/命令有效性和 security aspects 的范围边界。 | 不能据此省略驱动器、机械负载、控制器和网络的系统级验证。 |
| 电气/热/能量安全 | 基础版范围预览明确由 IEC 61800-5-1 覆盖。 | 需按目标产品及市场核验 IEC 61800-5-1 的适用版次。 |
| 低需求模式 | IEC 2026 官方摘要说明修订版增加了为何低需求模式不由本标准覆盖的范围理由；基础版预览说明低需求模式要求应参考 IEC 61508 系列，且高需求/连续模式实现的安全子功能可用于低需求模式。 | 未审读 2026 合并版全文，不能断言修订后条文逐字不变；Annex F 的 PFDavg 指导不能替代完整低需求模式要求。 |
| 术语更新 | IEC 官方摘要列出将 safety function 术语替换为 safety sub-function。 | 具体设备证书/手册可能仍使用旧术语，需按声明版次解释。 |

## 2. 已实施的正文修正

1. 进一步区分 PDS(SR) 自身产品级集成与机器/应用级安全集成。
2. 将应用危险/风险分析、应用安全子功能识别、初始 SIL 分配、被驱动设备、制造过程、输入信号/命令有效性和网络安全等边界分开列明。
3. 补充电气、热和能量安全由 IEC 61800-5-1 覆盖。
4. 将低需求模式表述修正为：本标准主要面向高需求/连续模式；低需求模式要求依据 IEC 61508 系列，不能因有 Annex F 估算指导而宣称完整覆盖。
