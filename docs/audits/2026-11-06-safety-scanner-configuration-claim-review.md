## 1. 本轮范围

针对安全防护器件文章中“不能只看最大检测距离”“响应时间/保护区必须按完整配置核验”“安全输出与非安全数据接口必须区分”等主张，复核 OMRON OS32C、SICK microScan3 Core I/O 的制造商公开资料，并复核 ISO 3691-4:2023 与 ISO/DIS 3691-4 的官方生命周期状态。

本轮不对两款产品进行横向排名，也不将产品系列的认证声明外推为目标整机或工作单元的 PL/SIL 结论。

## 2. 已核验事实

### 2.1 OMRON OS32C

OMRON 官方规格页（2025-10-01 更新）对 OS32C 系列列出 Type 3、PL d/Category 3、SIL 2、270° 检测角、按型号/分辨率区分的安全区量程，以及 80–680 ms 的 ON→OFF 响应时间配置范围；双路 PNP OSSD 为安全输出，辅助输出和警告输出明确标为非安全输出。页面还指出 Pollution Tolerance Mode 每次扫描增加 6 ms。OS32C 用户手册说明响应时间修改后必须重新计算安全距离，并记录 EDM 对外部控制元件反馈的监视及异常 lockout 行为。

**审查结论：** 文章必须要求记录完整型号、分辨率、响应时间、污染过滤模式、区域切换配置和输出用途；不能把 80 ms 当作所有配置的固定响应时间，也不能将非安全辅助输出当作保护信号。

### 2.2 SICK microScan3 Core I/O

SICK 官方操作说明标识为 8016346/1SK3/2025-07-04。该文档针对 Core I/O 变体列出 4.0 m/5.5 m 保护区量程选项、275° 扫描角、30/40/50/70/150/200 mm 分辨率、30/40 ms 扫描周期以及不低于 70 ms 的响应时间。响应时间由扫描周期、干扰抑制和多重采样共同决定；手册要求把控制器处理和下游接触器等延迟纳入危险状态终止时间。保护区最小距离计算还取决于机器停止时间、人员接近速度和检测分辨率。

**审查结论：** 不得把扫描仪 OSSD 关闭时间等同于整机危险运动停止时间；不得将不同 microScan3 变体、不同量程或不同版本手册的数据拼接成一个通用型号规格。

### 2.3 ISO 3691-4 版次状态

ISO 官方页面将 ISO 3691-4:2023（Edition 2，2023-06）列为已发布版本；另列 ISO/DIS 3691-4 第三版处于制定中、Stage 40.60，并表示将替代 2023 版。

**审查结论：** 当前知识内容必须区分已发布的 2023 版与尚未发布的 DIS 草案；不得把 DIS 当作现行标准，也不得在新版正式发布前宣称已按新版完成符合性评估。
