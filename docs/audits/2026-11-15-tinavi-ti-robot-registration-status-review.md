## 3. 法规解释边界

依据《医疗器械注册与备案管理办法》：

1. **如果2024年CQX2300679属于变更注册**，第81条规定变更文件与原证合并使用，且有效期截止日仍与原证相同；因此2024-01-25的批准日期本身不能把第三方列示的2026-11-13到期日自动延长五年。
2. **如果2024年CQX2300679属于延续注册**，则应结合第82条及第84条核对延续申请时间、审批时间和新有效期起始日；现有NMPA送达清单没有写明事项类别，无法作此认定。
3. **即使第三方所列2026-11-13到期日准确**，第82条仍使“到期日已过”不足以单独证明证书失效：若注册人在规定期限内提交延续申请，且不存在第83条不予延续情形，监管部门逾期未决定时依法视为准予延续。当前缺少是否按期申请以及是否存在例外情形的原始证据。
4. 因此，不得把“第三方页面到期日已过”写成“已注销/已失效”；同样不得把“有2024年NMPA送达记录”写成“已续证/当前有效”。

## 4. 本轮结论

**结论状态：未闭合。**

截至2026-11-15，**国械注准20163012280的当前注册状态仍未能由公开证据闭合**。现有材料分别证明了公司披露的2021年延续注册沿革、NMPA于2024-01-25对同一注册证编号作出的批准证明文件送达记录，以及第三方页面曾列示的2026-11-13有效期；但未取得CQX2300679事项类别、审批决定、当前电子注册证和附件。不能据此判定其已失效，也不能判定其当前有效。

本轮仅完成公开网页与既有来源台账的静态复核；NMPA验证码查询未得到具体证书记录，未取得企业法人空间证照，未对具体型号、生产许可、产品技术要求或现场临床应用进行验证。
