# 柏惠维康重庆迁址：第三类医疗器械生产许可与8张注册证迁移复核

> **快照日期：2026-11-15。** 本报告是公开资料证据审查，不构成法律意见、行政许可证明、医疗器械采购准入或临床应用结论。重庆第三类医疗器械生产许可证原件、可读取的许可信息附件，以及完整8张产品注册证电子证照/迁移附件尚未取得。

## 1. 本轮问题与结论摘要

2026-09-04《中国工业新闻网》转载《巴渝都市报》的报道声称，柏惠维康（重庆）机器人股份有限公司自2025-06落户涪陵后，两个月内取得第三类医疗器械生产许可证，并完成8张手术机器人第三类医疗器械注册证迁移；报道同时称12款手术机器人系列产品同步落地。该报道提供了明确的项目进展主张，但没有列出生产许可证编号、许可范围、有效期，也没有公开8张注册证号清单（链接台账#881/#1037）。

企业官网现自称拥有神经外科、骨科和口腔三大产品品牌、累计获批8张手术机器人产品注册证；官网同样没有给出8张证的逐证清单（#836/#875）。

**本轮结论：媒体及企业自述支持“公司公开宣称已取得生产资质并完成8证迁移”，但监管证据尚未闭合。** 目前未取得重庆市药监局发出的生产许可证编号/电子证照、生产范围、生产地址和有效期；仅识别到7个候选产品注册证编号，尚未识别出足以闭合企业“8张”口径的完整官方清单。部分第三方记录已显示重庆主体/地址，但不同证号的变更时间、状态和原始附件不能互相代替。

## 2. 许可证与产品注册证的法规边界

### 2.1 第三类生产许可证与第三类产品注册证是两类不同的行政许可

- 《医疗器械监督管理条例》第十三条规定第一类产品备案、第二类和第三类产品注册；第十六条区分第二类和第三类产品注册申请的受理机关；第三十二条要求第二类、第三类医疗器械生产企业向所在地省级药品监督管理部门申请生产许可，并提交拟生产产品的注册证（官方法规，来源#1753）。
- 《医疗器械生产监督管理办法》（市场监管总局令第53号）第四条、第十条进一步规定第二类、第三类生产活动应取得生产许可证；第十四条规定许可证正、副本记载许可证编号、企业名称、统一社会信用代码、法定代表人、住所、生产地址、生产范围、发证部门、发证日期和有效期限，许可证有效期为5年；第十五条规定生产地址变更或生产范围增加须向原发证部门申请生产许可变更；第十六条规定企业名称、住所等登记事项变更时限；第十八条规定跨省设立生产场地应向新设场地所在地省级药监部门申请生产许可（官方法规，来源#1752）。
- 《医疗器械监督管理条例》第四十二条规定第三类医疗器械经营许可。经营许可证与生产许可证用途不同，不能用经营许可申请或经营许可证明替代制造资质（来源#1753；涪陵区2026-08-14公告#835/#895）。
- 医疗器械注册人/备案人可以自行生产，也可以依法委托符合条件的企业生产（《条例》第三十四条）。因此，注册人名称/住所变更、产品注册信息中的生产地址变更、受托生产企业变更及生产企业许可证变更必须分别核查，不能把其中一项概括成“8张证迁移已完成”。

### 2.2 生产许可证原件必须核对的字段

| 字段 | 核验目的 |
|---|---|
| 许可证编号、发证部门 | 确认是重庆市药监局颁发的医疗器械生产许可证，而非经营许可证、第一类生产备案或一般工业产品生产许可证 |
| 企业名称与统一社会信用代码 | 确认许可证持有人为柏惠维康（重庆）机器人股份有限公司，并核对统一社会信用代码连续性 |
| 住所、生产地址 | 确认法律住所和实际生产场所均对应涪陵工厂；不能只核对公司注册地址 |
| 生产范围 | 确认所覆盖的第二类/第三类产品类别和具体生产范围，不能从公司经营范围或产品注册证反推 |
| 发证日期、有效期 | 确认许可当前有效及后续延续情况 |
| 副本变更记录、产品登记/备案附件 | 核对生产地址、范围、产品注册证和委托生产关系是否在许可范围内 |

## 5. 关键时间线差异

1. 媒体报道把“8张注册证迁移”描述为自2025-06落户后约两个月内完成（#881/#1037）。
2. 重庆市药监局2025-08-25公告确实存在当周医疗器械生产许可信息附件（#1751），与媒体所述时间窗口相近；但XLS附件本轮未读到，不能确认它是否列有柏惠维康。
3. 对国械注准20203010244，ByDrug记录的注册人名称/住所变更日为2026-06-15，生产地址变更日为2026-08-07（#871/#877/#1040）。该第三方日期与“该证在2025-08前已完成所有登记变更”的表述并不吻合，但不排除更早存在未被该页面记录的行政步骤，因此只能列为**时间线差异待原件解释**。
4. 国械注准20253012151由NMPA于2026-02-02批准时，送达记录上的申请人仍为北京柏惠维康（#729/#777/#854）。批准后的注册人/住所/生产地址是否另行变更仍待查；不能用这一批准记录直接否定或证明2025年原有的8张证迁移主张。
5. 官网“累计8张”是公司当前自述；旧展会材料、不同时间点的第三方缓存和NMPA批准送达数据统计口径可能不同，不可直接比较或相加。

## 6. 本轮审计判断

- **重庆第三类医疗器械生产许可证：** 媒体已明确报道获证，官方许可公告附件路径已找到，但许可证编号、范围、有效期、发证日期和电子证照未取得；状态记为“报道声称已取得，监管原件待核”。
- **8张产品注册证迁移：** 当前可识别7个候选证号；只有20203010244有较完整的第三方注册人/住所/生产地址变更时间线，20183010127当前第三方字段显示重庆但缺变更日期；其余5项迁移状态未闭合。企业声称的8张清单尚未形成。
- **注册人与生产地址：** 必须分别核验注册人法定主体、住所、生产地址、生产许可证持有人/范围及委托生产关系；不能只看公司官网地址或工商登记地址。
- **运营许可：** 2026-08-14经营许可证申请公示不等于获证，更不等于生产许可。
- **总体状态：** 第21章21-02保持“进行中”。本轮仅完成公开来源及第三方数据的静态比对，未获得行政许可原件、NMPA电子注册证、变更备案附件，也未完成生产质量体系、现场生产线、12款产品BOM/产品注册范围或临床应用验收。
