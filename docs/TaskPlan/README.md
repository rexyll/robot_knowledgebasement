## 使用方法

1. 先阅读仓库根目录的 [TaskPlan.md](../../TaskPlan.md)，尤其是 Guide、Limit、任务状态和验收规则。
2. 按章节计划维护具体任务，不要在子计划重复定义或改写全局规则。
3. 每个节点必须包含必做、禁止、依赖、交付物、验收标准、证据和状态。
4. 新增节点追加在章节计划末尾，保持 ID 唯一；不要删除或复用历史 ID。
5. 旧版 `local` 分支 TaskPlan 已归档，仅用于追溯历史，不作为当前项目状态依据。
