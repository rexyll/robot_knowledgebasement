# 24｜知识管理检索与工具链 — 章节任务计划

> 本文件统一继承仓库根目录 `TaskPlan.md` 的 Guide、Limit、状态和验收要求；本章不另设 Guide/Limit。特殊例外尚未获用户批准。
>
> 目标知识目录：`src/robot_knowledgebase/、docs/、knowledge/`  
> 依赖章节：00 为治理前置；所有章节提供数据与知识输入  
> 现有基础：已有 Python 包、Markdown loader、chunker、Embedding/Retriever Protocol、CLI、配置示例和 CI  
> 初始状态：待执行；现有内容需按本计划逐项复核。

## 1. 本章目标与边界

将知识库建设成可持续维护和机器可读的知识基础设施，支持导入、解析、校验、检索、RAG、评测和后续机器人研发 Agent 使用。

**覆盖范围：** Markdown/PDF/HTML/Office/数据表导入、解析质量、元数据 Schema、文档版本/去重、Chunk 策略、Embedding 模型、向量库、全文/BM25、Hybrid Search、Rerank、权限过滤、引用、RAG 评估、Agent/工具接口、审计、增量更新、监控和部署。

**边界说明：** 技术事实由各知识章节负责；本章建设知识内容工程和检索服务，不替代外部业务系统或控制机器人本体。

## 2. 交付物

- 知识导入和解析流水线
- 统一文档/Chunk/来源 Schema
- Embedding、向量库和混合检索适配层
- 带引用的 RAG 服务与评估基准
- 知识质量/权限/更新自动化工具

## 3. 任务节点

### 24-01｜知识源接入与解析

- **任务范围：** 扩展 Markdown loader，规划 PDF、网页、HTML、Office、代码、CSV/表格和日志导入。
- **必做：** 保存来源 URL/路径、版本、时间、文件哈希、解析器版本、页码/标题和解析置信度。
- **严格禁止：** 不得将扫描/OCR 低置信文本无标记入库；不得绕过访问控制采集受限内容。
- **依赖：** 先完成本章资产盘点；其余依赖按根计划第 6 章执行。
- **交付物与验收：** 每类格式有解析样例、失败处理和抽样质量报告。
- **状态：** 未开始（存量待审计）

### 24-02｜文档 Schema、版本与 Chunk 管理

- **任务范围：** 设计文档/段落/Chunk/实体/引用/关系的结构化模型。
- **必做：** 支持增量更新、稳定 ID、来源追溯、删除/更新传播、去重、版本差异和适配中文/英文。
- **严格禁止：** 不得只按固定字符数切块而忽略表格/标题/代码语义；不得丢失页码和来源锚点。
- **依赖：** 先完成本章资产盘点；其余依赖按根计划第 6 章执行。
- **交付物与验收：** Schema 规范和 chunking 评测集及测试完成。
- **状态：** 未开始（存量待审计）

### 24-03｜Embedding 与向量数据库适配

- **任务范围：** 支持可替换的本地/云端 Embedding 和向量存储后端。
- **必做：** 记录模型、维度、语言能力、许可证、归一化、批大小、延迟、成本和索引配置。
- **严格禁止：** 不得把不同维度/模型生成的向量混在同一索引空间；不得把 embedding 相似度当作事实正确性。
- **依赖：** 先完成本章资产盘点；其余依赖按根计划第 6 章执行。
- **交付物与验收：** Provider 接口、至少一个可运行适配和迁移策略完成。
- **状态：** 未开始（存量待审计）

### 24-04｜关键词、混合检索与重排序

- **任务范围：** 建设全文/BM25、向量、元数据过滤、实体/图谱检索和 reranker 融合。
- **必做：** 建立检索评测集，测量 Recall@K、MRR、nDCG、延迟和过滤正确性。
- **严格禁止：** 不得只展示主观问答结果；不得忽略版本、权限和来源过滤。
- **依赖：** 先完成本章资产盘点；其余依赖按根计划第 6 章执行。
- **交付物与验收：** 检索基线、参数和对比报告可复现。
- **状态：** 未开始（存量待审计）

### 24-05｜RAG、引用与回答约束

- **任务范围：** 实现查询改写、检索上下文、答案生成、引用定位、拒答和不确定性说明。
- **必做：** 答案必须能回溯文档/段落/页码；区分检索证据与模型推断；高风险问题增加人工审核路径。
- **严格禁止：** 不得无来源生成具体参数或法规结论；不得将模型生成补全内容伪装为知识原文。
- **依赖：** 先完成本章资产盘点；其余依赖按根计划第 6 章执行。
- **交付物与验收：** RAG 服务具备引用验证、无答案测试和幻觉评估。
- **状态：** 未开始（存量待审计）

### 24-06｜权限、安全与知识更新

- **任务范围：** 处理知识分级、项目/租户权限、敏感信息、审计和增量索引。
- **必做：** 建立读写授权、删除传播、日志脱敏、数据保留和索引回滚机制。
- **严格禁止：** 不得将私有项目资料暴露给未授权用户；不得在日志记录机密或个人敏感信息。
- **依赖：** 先完成本章资产盘点；其余依赖按根计划第 6 章执行。
- **交付物与验收：** 权限用例、更新/删除一致性和安全审查完成。
- **状态：** 未开始（存量待审计）

### 24-07｜质量评估、CLI/API 与 Agent 接口

- **任务范围：** 完善 CLI、API、自动化流水线、检索评测、反馈收集和后续 Agent 工具接口。
- **必做：** 保持接口文档、版本兼容、异常响应、可观测性和自动化 CI；Agent 操作必须受工具权限约束。
- **严格禁止：** 不得让检索 Agent 自动修改权威知识或触发物理机器人动作；不得无评测发布。
- **依赖：** 先完成本章资产盘点；其余依赖按根计划第 6 章执行。
- **交付物与验收：** 端到端回归集、API 文档、CI 和发布检查清单通过。
- **状态：** 未开始（存量待审计）



## 4. 本章完成条件

1. 文档解析和 Chunk 能保留完整来源与结构。
2. 检索/RAG 有客观评测、引用定位和权限控制。
3. 工具链可自动增量更新并为未来研发 Agent 提供受控接口。
