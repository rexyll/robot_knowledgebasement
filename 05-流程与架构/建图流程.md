# 建图流程（部署期）

> AMR 交付的第一个工程环节：把场地变成机器人的地图+路网+区域配置。质量决定后续一切（→ [[SLAM总览]] 是算法原理，本页是作业流程）。

## 标准作业流程（SOP）

```
阶段1 场勘(0.5-1天)
  ├─ 平面图收集: CAD/消防图, 楼层/电梯/坡道/门清单
  ├─ 环境评估: 玻璃面/镜面/长走廊/人流高峰时段/地面材质
  ├─ 施工需求确认: 反光板?充电桩位置?电梯对接? → [[移动机器人]] 导航方式选型
  └─ 危险点清单: 台阶/坡道/悬空(电梯口) → 电子围栏预留

阶段2 建图采集(0.5天)
  ├─ 首选: 人工遥控建图(手柄/APP) 速度≤0.5m/s, 绕场覆盖+关键回环
  ├─ 回环设计: 大环套小环, 每 30-50m 回访一次旧区域
  ├─ 同层多机一致: 同一起点同一路径风格
  └─ 算法: [[激光SLAM]](2D Cartographer/slam_toolbox; 3D FAST-LIO2)

阶段3 优化与评审(0.5天)
  ├─ 回环闭合检查: 位姿图残差, 手动加回环约束
  ├─ 地图清理: 动态噪点(人流鬼影)擦除, 墙面对齐
  ├─ 尺度校验: 与 CAD/卷尺实测比对 (<2%)
  └─ 输出: 占据栅格(5cm) + 3D点云(如有) → [[SLAM总览]] 地图表示

阶段4 语义标注(0.5-1天)
  ├─ 路网编辑: 走廊图/单向道/超车区 → [[多机协同与调度算法]]
  ├─ 电子围栏: 台阶/玻璃/危险区(Keepout) → [[局部规划与避障]]
  ├─ 限速区: 人流区/坡道/弯道
  ├─ 点位库: 停靠位/充电桩对接位/待命区/电梯口
  └─ 楼层绑定: 多层地图+电梯切换关系 → [[多机调度流程]]

阶段5 试运行验收(1-3天)
  ├─ 定位稳定性: 24h 连续运行重定位成功率 >99%
  ├─ 全点位到达测试: 精度 ±5-10cm, 无超时
  ├─ 多机压力: 满编队跑 2h 死锁=0
  └─ 地图版本发布: 版本号+SHA, 云端分发 → [[云平台与IoT通信]]
```

## 两种部署模式对比

| 模式 | 流程 | 适用 |
|---|---|---|
| **工程建图**（上面 SOP） | 工程师到场 2-5 天 | 商用/工业交付（主流） |
| **自主建图/免部署** | 机器人自己走一圈（SLAM+探索）或扫图机/手机扫描 | 家用扫地机、轻商用快速部署 |
| 混合 | 预建图(BIM/CAD 矢量化)+现场校准 | 大型项目缩短周期 |

## 地图运维（长期运行的真实问题）

- **环境变化**：货架挪动/装修 → 增量更新（slam_toolbox 续图）或重扫
- **鬼影**：临时障碍被固化 → 定期人工清理或动态滤除算法
- **多机地图一致性**：云端单源分发+版本管理，禁车端各自改图 → [[云平台与IoT通信]]
- **备份**：每次发布保留 N 个历史版本，可一键回滚 → [[云端协同与OTA流程]]

## 验收指标（→ [[性能指标体系]]）

| 指标 | 标准 |
|---|---|
| 地图尺度误差 | <2%（10m 实测比对） |
| 回环闭合残差 | 2D <5cm |
| 重定位成功率 | >99% @24h |
| 点位到达精度 | ±5-10cm（对接位 ±5mm 级另测） |
| 路网完整性 | 单向道/围栏覆盖全部危险点（checklist 制） |

## 细节加深（V2）
- **工时基准**（行业交付经验）：1000 m² 单层 — 工程建图 2-5 天（含语义标注与试运行验收）；自主建图方案可压到半天但回环质量需人工复核。
- **地图评审四查**：墙线直不直（回环）、门框在不在（特征）、鬼影擦没擦（动态物）、尺度对不对（CAD 比对 <2%）。
