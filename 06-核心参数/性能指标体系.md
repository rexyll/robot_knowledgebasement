# 性能指标体系（KPI 全集）

> 机器人系统的验收与运营度量。分四层：**部件级 → 单机级 → 车队级 → 业务级**，上层指标由下层支撑。

## 部件级

| 部件 | 指标 | 参考值 | 详解页 |
|---|---|---|---|
| LiDAR | 量程/精度/点频 | 见 [[传感器参数对比]] | [[激光雷达]] |
| SLAM | 建图回环残差 | 2D <5cm, 3D <10cm | [[激光SLAM]] |
| 定位 | 重定位成功率 | >99% @24h | [[多传感器融合定位]] |
| 电池 | 循环寿命/SOC 误差 | LFP ≥2000 次; SOC ±3-5% | [[电池与电源]] |
| 电机 | 温升/噪声 | 外壳 <70℃ | [[电机与驱动器]] |

## 单机级（整机验收）

| 指标 | 定义 | 商用 AMR 目标 |
|---|---|---|
| **到位精度** | 停靠点横向/纵向误差 | ±5-10cm（对接 ±5mm） |
| **到位时间** | 50m 路径含加减速 | ≤45s |
| **导航任务成功率** | 含恢复行为后完成比例 | >99.5% |
| **MTBF** | 平均无故障时间 | >2000h |
| **MTTR** | 平均修复时间 | <30min（远程可解） |
| **可用率** | Uptime/总时间 | >99%（车队折算单机 >98%） |
| **连续运行** | 满电连续作业 | ≥8h 或到充电策略要求 |
| **噪声** | 1m 处 | <65dB（清洁 <70dB 作业） |
| **防护** | IP 等级 | IP54 室内标准 |

## 车队级（调度与运行）

| 指标 | 定义 | 目标/经验 |
|---|---|---|
| **整场吞吐** | 任务/小时 | 线性段：车数×单车效率×0.7-0.85（调度损耗） |
| **单车效率** | 车/h | 潜伏式 15-25；清洁 1500-3000 m²/h |
| **拥堵率** | 等待时间/总时间 | <15%（超=扩容信号） |
| **死锁次数** | 需人工解锁 | =0（自动解锁不算） |
| **任务等待 P50/P95** | 排队时间分布 | P95 <3×P50（尾部异常检测） |
| **充电桩占用** | 同时充电比例 | 30-60%（>80% 桩不足） |
| **在线率** | 可调度车辆/总数 | >95% |

## 业务级（客户视角）

| 指标 | 清洁场景 | 物流场景 |
|---|---|---|
| 覆盖率 | ≥95%（验收核心） | — |
| 有效清洁度 | 尘埃度/目视评级 | — |
| 人效替代 | 单机替代 2-3 人（三班制 3-5 人） | 拣选人效 300-600 行/h（GTP） |
| 回本周期 | 12-24 个月（租赁模式按月） | 18-30 个月 |
| 订单履约 | — | OCT（订单完成时间） |
| 库存准确率 | — | >99.9%（RFID/扫码闭环） |

## 指标测量方法学（数字从哪来）

1. **到位精度**：激光跟踪仪/高精度全站仪抽样 20 点测量，或 AprilTag 真值对照
2. **成功率**：连续 7 天运营日志统计（排除计划维护）
3. **吞吐**：WMS 出入库回执时间戳差分
4. **MTBF**：故障工单按起因分类（软件/硬件/环境），只算"非计划停机"
5. **回本**：`(人工成本节省 − 运维费用) / (设备价+部署费)`，注意隐形成本（培训/场地改造）

## 常见指标陷阱

- "最大速度"≠运营速度（含转弯/避障，实际利用率 60-80%）
- "理论清洁效率"是理论（有效覆盖打折）→ 合同里写**有效覆盖率**
- 可用率口径：含充电时间与否要约定
- 成功率分母：按任务还是按里程，差别巨大
