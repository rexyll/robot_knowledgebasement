# 09-07 软件栈搭建（从0搭建 · 第七步）

> 目标：主脑装好 ROS2 Jazzy + DDS 调优 + 工作区 + 底盘驱动桥；MCU 侧打通串口协议。装完验收标准：`ros2 topic echo /odom` 能看到真实轮速。

## 1. ROS2 安装（Jazzy · Ubuntu 24.04 专属）

```bash
# 官方 Debian 安装路线（来源: docs.ros.org Jazzy 安装页，快照 2026-11-01）
sudo apt install software-properties-common
sudo add-apt-repository universe
sudo add-apt-repository ros2-testing  # 不需要 testing 可跳过
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
  http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | \
  sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
sudo apt update && sudo apt install ros-jazzy-ros-base ros-dev-tools
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
# 验证: ros2 run demo_nodes_cpp talker / listener 双终端对讲
```

> ⚠️ ROS1 Noetic 已于 2025-05-31 EOL（官方 Wiki 转存档）。新项目一律 ROS2；维护 ROS1 存量见 [[ROS1与迁移]]。

| 实现 | 角色 | 何时选 | 链接 |

```bash
# WiFi 下关组播风暴: Cyclone 用 Discovery Traffic 或直接 Zenoh bridge
```

## 4. 底盘驱动桥（MCU ↔ ROS2）

两条路线：
1. **自写串口协议桥**（初学者推荐——同时学会协议设计）：MCU 帧格式 `0xAA | type | len | payload | CRC16`，Jetson 侧 Python/C++ 节点解析出 `/odom`（nav_msgs）并订阅 `/cmd_vel` 下发轮速。参考实现 → [[10-代码实例-底盘串口桥]]（G 组入库）。
2. **micro-ROS / ros2arduino**（进阶）：MCU 直接成为 ROS2 节点（XRCE-DDS over 串口）。链接：micro.vulcanexus.org（#11）、ros2arduino（#23）、OpenCR 固件参考（#24）。低成本平台的标准姿势：高层计算（Nav2/AMCL）跑在 Linux 主控，底层实时控制在 MCU（ESP32/STM32），**主控运行 `micro_ros_agent`** 桥接——MCU 发布 `/scan` `/imu/data` `/wheel_ticks`、订阅 `/cmd_vel`，这些话题对 Nav2 完全透明，如同原生节点。

差速底盘不要重复造轮子的部分：**diff_drive_controller**（ros2_control 官方，cmd_vel→轮速+里程计发布+限幅，台账 #35）——自研桥跑通后可以对照它的行为（打滑/加速度限幅处理）。

## 8. 细节加深（V2）
- **`rosdep` 装依赖**：`sudo rosdep init && rosdep update`（国内网络走鱼香 ROS 一键安装 `wget http://fishros.com -O fishros && . fishros`，台账 #44 官网已验证）。
- **DDS 第一坑复现率最高**：订阅收不到 90% 是 QoS 不匹配（发布 BestEffort+订阅 Reliable）或 DDS 网卡选择错误——多网卡机器用 `ROS_DOMAIN_ID` + Cyclone 的 `network_interface` 配置锁定。
- **环境自检脚本**：写 `check_env.sh`（ROS 版本/RMW/域 ID/设备节点权限 udev）纳入仓库——新机器 10 分钟复现环境。
