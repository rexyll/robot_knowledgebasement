# 09-02 机械结构设计与材料选型（从0搭建 · 第二步）

> 目标：把 09-01 定下的差速底盘变成**可加工的结构**：构型布置 → 材料选择 → 加工工艺 → 标准件采购。初学者最容易犯的错是"先买零件再想结构"——顺序应该反过来。

## 1. 差速底盘布局设计（60×40×25cm 样机参考）

```
俯视图:                       侧视图:
┌────────────────┐            ┌──────────────┐
│ LiDAR(顶部居中,  │            │ LiDAR 离地 15-25cm(安装面避 LiDAR 盲区) │
│ 远离电机防震)    │            ├──────────────┤
│ Jetson+24V电源  │            │ 万向轮(前后各1, │
│ (中部,重心低)    │            │ 承重分配 30-40%)│
│ 电池(底层前部)   │            ├──────────────┤
│ MCU板+驱动器     │            │ 驱动轮(中轴)   │
├────────────────┤            │ 直径 125-150mm │
│ 驱动轮(两侧中轴) │            └──────────────┘
└────────────────┘
要点: ① 驱动轮放中轴 → 原地旋转稳定  ② 万向轮前后分置 → 防翘头
     ③ 电池置低 → 降低重心  ④ LiDAR 远离振动源+避安装支架遮挡
```

## 2. 材料选型表（机器人结构常用）

| 材料 | 密度 g/cm³ | 屈服强度 MPa | 加工 | 成本 | 用途 |
|---|---|---|---|---|---|
| **6061-T6 铝合金** | 2.7 | ~275 | CNC/钣金/焊接 | 中 | 底盘主框架、电机座（首选） |
| 5052 铝板 | 2.68 | ~190 | 钣金折弯优 | 低 | 外壳、罩板、电池仓 |
| Q235 碳钢 | 7.85 | ~235 | 焊接/机加工 | 最低 | 重载支架（重，易锈，样机少用） |
| 304 不锈钢 | 7.93 | ~215 | 难加工 | 高 | 清洁机水接触件 |
| PA12 尼龙 3D 打印 | 1.01 | ~45 | 打印 | 低 | 传感器支架、卡扣、小件 |
| PLA（打印） | 1.24 | ~60 | 打印 | 最低 | 只做验证件（夏天车内会软） |
| 碳纤维板 | 1.6 | ~600(各向异性) | CNC/激光 | 高 | 轻量上层板（顶盖/层板） |
| 亚克力/PVC | 1.2-1.4 | 低 | 激光切割 | 最低 | 临时罩板、教学样机 |

**选型口诀**：主承力用 6061 钣金或型材（欧标 2020/2040 铝型材对初学者最友好——打孔免攻丝、T 螺母随意装）；外观件 5052 折弯；传感器支架 3D 打印 PA12；**样机期禁用 PLA 做受力件**。

## 3. 加工工艺与渠道（初学者实操）

| 工艺 | 适用 | 打样周期 | 渠道示例 |
|---|---|---|---|
| 铝型材+角件 | 框架（免画复杂 CAD） | 当天购 | 淘宝/1688「欧标铝型材」 |
| 钣金（激光切割+折弯） | 底板/外壳 | 3-7 天 | 1688/嘉立创钣金（在线报价，支持 DXF/STEP 上传） |
| CNC | 电机座/精孔位 | 5-10 天 | 嘉立创/精进/本地机加厂 |
| 3D 打印（PA/树脂） | 支架/壳件 | 2-5 天 | 淘宝代打/自家 FDM |
| 激光切割（亚克力/胶合板） | 原型层板 | 1-3 天 | 淘宝「激光切割定制」 |

> 快照 2026-11-01；渠道价格随行情浮动（台账原则：只记「渠道类型」，不锁死价格）。

## 4. 标准件清单（样机必买）

- 驱动轮 150mm（充气或 PU 实心）×2 + 万向轮 3-4 寸 ×2
- 直流无刷轮毂电机或「电机+减速器+轮」一体（250-350W，24V，带编码器）×2
- 铝型材 2020/3030 若干 + 角件/T 螺母；M3-M6 内六角螺丝包
- 减震：橡胶减震垫（LiDAR 用）、电机 U 型抱箍
- 防撞条（门窗密封条替代）+ 急停按钮（→ [[09-03-电子电气设计]]）

## 7. 细节加深（V2）
- **LiDAR 安装三原则**（反爬调试血泪总结）：① 高度 15-25cm（避地面杂物回波+家具底沿覆盖）；② 周围 5cm 内无支架遮挡（近场盲区叠加）；③ 加减震垫（轮振动会让扫描匹配抖动，→ [[激光SLAM]] 时间同步与振动问题）。
- **重心经验值**：空载重心高度 < 轮距的 1/2；满载加速 1 m/s² 时前后轴荷变化 <20%（防翘头，计算式见 [[底盘与运动参数]]）。
- **公差纪律**：3D 打印孔缩 0.2-0.4mm 或直接按「孔径=轴径+0.3」；钣金孔位以电机座实测为准（电机本体公差 ±0.5mm）。
