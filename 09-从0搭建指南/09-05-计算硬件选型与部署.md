# 09-05 计算硬件选型与部署（从0搭建 · 第五步）

> 目标：确定「双脑分工」（Jetson 主脑 + STM32 小脑），完成两块板子的点亮与烧录。本页只做「选型+部署动作」，OS 细节在 [[09-06-操作系统选型与内核裁剪]]。

## 1. 双脑分工表（样机基线）

| 层 | 硬件 | 跑什么 | 为什么不是另一个 |
|---|---|---|---|
| **主脑** | Jetson Orin Nano 8GB（¥3000 级） | Ubuntu 24.04 + ROS2 Jazzy、LiDAR 驱动、Nav2、可视化 | Linux 生态+GPU，但**不是硬实时** |
| **小脑** | STM32F405（¥30） | 1kHz 速度环 PID、运动学解算、里程计积分、急停链 | 需要 μs 级确定性（→ [[实时系统与嵌入式]]） |

**为什么必须双脑**：Linux 内核抖动毫秒级 → 电流环 20kHz 在 Linux 上必炸；反过来在 MCU 上写 SLAM 也不现实。中间靠**串口心跳协议**连接（→ [[实时系统与嵌入式]] 双脑架构节）。

## 2. 预算分档（整机算力）

| 档位 | 配置 | 能做什么 | 参考价（快照 2026-11） |
|---|---|---|---|
| 入门 | 树莓派 5（8GB）+ STM32 | 2D SLAM+Nav2 低帧率 | ¥800 + ¥30 |
| 均衡 ★ | Jetson Orin Nano Super（8GB）+ STM32F4 | 2D/轻 3D SLAM+视觉避障 | ¥3000 + ¥30 |
| 进阶 | Jetson Orin NX 16GB + STM32H7 | 3D LIO+多相机感知 | ¥6500 + ¥60 |
| 通用 | x86 工控机 + CAN 卡 | 重载调度/仿真回放 | ¥4000+ |

## 3. 部署动作清单（点亮顺序）

```
Step1 Jetson:
  刷 JetPack(含 Ubuntu 24.04) — 用 SDK Manager(PC 端) 或 SD 镜像
  → 首启配置: 用户/网络/远程 SSH/固定 IP
  → 安装 ROS2 Jazzy (→ [[09-07-软件栈搭建]])

Step2 STM32:
  工具链: STM32CubeIDE(免费) 或 PlatformIO(VSCode 插件)
  → 最小程序: LED + 串口回环 (验证烧录链路)
  → 底盘固件: 编码器读取+PID+串口协议 (→ 10-代码实例)

Step3 联调:
  USB 连接 → Jetson 上 minicom/pyserial 发 'v 0.2 0' 看轮子动
  → MCU 回传里程计帧 → 解析正确 → 心跳机制打开
```

## 4. 烧录与调试工具链（V2 加深）

| 工具 | 用途 | 要点 |
|---|---|---|
| STM32CubeIDE | STM32 官方 IDE（HAL 生成） | 免费，SWD 烧录 |
| PlatformIO | VSCode 内嵌嵌入式开发 | 初学者更快；支持 Teensy/STM32/ESP32 |
| ST-Link V2 克隆 | SWD 烧录器（¥20） | 比 USB 串口 bootloader 可靠 |
| SDK Manager | Jetson 刷机 | 主机需 Ubuntu 22.04/24.04 PC 或虚拟机 |
| Balena Etcher | SD 卡镜像写入 | 树莓派/Jetson SD 方案用 |

## 7. 细节加深（V2）
- **Jetson Orin Nano "Super" 版**：2024.12 起同一硬件经 JetPack 6.1/6.2 更新解锁至 67 TOPS（原 40），旧板免费升级——买旧板+刷新包是性价比打法（快照 2026-11，来源 NVIDIA 官方发布）。
- **树莓派 5 方案的坑**：官方 OS 是 Debian 不是 Ubuntu；ROS2 Jazzy 官方预编译包不含 Debian arm64（Jazzy 仅 Ubuntu 24.04 有 deb 包），树莓派上要么用 Ubuntu Server 24.04 镜像，要么源码编译——初学者选后者会卡 2 天，选前者省心。
- **MCU 固件工程结构建议**：协议层（帧/CRC/心跳）与控制层（PID/运动学）物理分开成两个 .c 文件——后期换底盘只改控制层。
