# 仿真平台

> 机器人开发的第二战场：算法验证、虚拟调试、RL 训练、多机调度压力测试。选型分**物理仿真**与**训练仿真**两条线。

|---|---|---|---|---|---|

## 仿真用途金字塔

```
        RL 训练(Isaac Lab 万级并行) ← [[学习型机器人算法]]
      虚拟调试+数字孪生(Isaac Sim)
    系统集成测试(Gazebo + ROS2 全栈)
  算法单元验证(轻量仿真/回放) ← [[构建与CI工具链]]
```

## 与 ROS2 对接

- Gazebo：`ros_gz` 桥（topic 双向映射；注意部分消息 API 缺口）
- Isaac Sim：ROS2 Bridge（native ROS2 节点，DDS 直连）
- 仿真时间：`use_sim_time=true`，TF 与传感器时间戳统一——仿真一致性第一坑

## 工程实践要点

1. **Sim2Real 差距**：摩擦/延迟/噪声建模 → 域随机化（质量±20%、摩擦±30%、延迟 0-50ms）→ [[学习型机器人算法]]
2. **传感器仿真保真度分级**：LiDAR 用 GPU Ray（10 万点级实时）、相机 RTX、IMU 加噪声即可
3. **CI 中的仿真**：headless 模式 + 冒烟断言（到位精度/耗时/碰撞次数）→ [[构建与CI工具链]]；两内部项目都有脚本化冒烟（`capability_smoke_stability.sh` 等）
4. **合成数据**：Isaac Replicator 生成带真值标注的数据集 → 训练 [[视觉感知算法]]，标注成本降 10-100 倍

## 细节加深（V2）
- **Gazebo Harmonic 是当前 LTS**（2023.09-2029.05，安装文档台账 #37）：配 Ubuntu 22.04/24.04；Classic 已 EOL 勿再用于新项目。
- **Isaac Lab 双许可**（仓库台账 #76）：主体 BSD-3、mimic 等部分 Apache-2.0——RL 训练万级并行环境的入口。
- **仿真时间纪律**：`use_sim_time=true` 必须 launch 全链一致，否则 TF 报 Extrapolation（初学第一坑，→ [[09-08-算法集成与调参]]）。
- **传感器仿真保真度分级实操**：2D LiDAR 用 GPU Ray（够真够快）；深度相机 RTX 渲染；IMU 加高斯噪声+偏置即可——按"测试目的"选保真度，别全上 RTX 浪费 10 倍算力。
