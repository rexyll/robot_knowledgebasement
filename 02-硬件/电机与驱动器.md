# 电机与驱动器

> 机器人的"肌肉"。移动机器人主驱动 = BLDC/PMSM 无刷电机 + FOC 驱动器；机械臂 = 交流伺服 + 谐波/RV 减速。

## 电机类型谱系

| 类型 | 特点 | 控制方式 | 机器人用途 |
|---|---|---|---|
| 直流有刷 | 便宜、易控、寿命短（碳刷） | PWM 调压 | 玩具、教具 |
| 步进电机 | 开环定位、低速扭矩好、易失步 | 脉冲+细分 | 3D 打印、小云台、轻载直线轴 |
| BLDC/永磁同步(PMSM) | 高效(>90%)、长寿命、功率密度高 | **FOC 磁场定向控制** | AMR 轮驱、无人机、关节模组 |
| 交流伺服 | 编码器闭环+高响应，绝对定位 | 位置/速度/转矩三环 | 工业机械臂、精密轴 |
| 空心杯电机 | 无铁芯、响应极快、功率密度高 | FOC | 灵巧手、云台、微型关节 |
| 舵机 | 电机+减速+控制板一体 | PWM 占空比角度 | 教育机器人、玩具 |
| 直线电机 | 直接直线推力、零背隙 | 伺服 | 半导体设备、高速桁架 |

## 核心参数（选型公式链）

1. **负载力矩需求**：`T = (m·a + m·g·sinθ + F_滚动) · r_wheel / (i_gear · η)`
2. **功率**：`P = T·ω`；峰值功率看加速需求（一般 3-5 倍额定）
3. **扭矩密度**：人形关节模组要求 >50 N·m/kg（含减速器）
4. **额定/峰值电流**：驱动器按 3 倍过载选
5. **编码器**：增量 2500 线 或 绝对式多圈
6. **防护/IP 与散热**：轮驱 IP54+，关节自然散热 vs 水冷

## 驱动器（电机怎么被"驾驭"）

| 环节 | 内容 |
|---|---|
| 功率级 | 三相逆变桥（MOSFET/SiC），母线 24-80V |
| 控制算法 | **FOC**：Clarke/Park 变换 → 电流环(10-20kHz) → 速度环 → 位置环 |
| 传感 | 霍尔/编码器/无感（观测器）；力矩≈电流×Kt |
| 通信总线 | CAN(1Mbps, CANopen)/EtherCAT(100Mbps, 分布式时钟)/RS485/DDS 上层 |
| 安全功能 | STO（安全转矩关断）、限流、堵转保护 |

## 机器人总线选择

| 总线 | 带宽 | 节点数 | 同步性 | 场景 |
|---|---|---|---|---|
| CAN/CANopen | 1Mbps | 110 | 弱 | 底盘电机、低成本（[[项目-清洁机器人]] 常用） |
| EtherCAT | 100Mbps | 65535 | <1μs 分布式时钟 | 机械臂多轴、力控高频 |
| RS485/Modbus | 115.2kbps | 32 | 弱 | 慢速外设 |
| 自研 SPI 直驱 | 数十 Mbps | 板级 | 强 | 一体化关节内部 |

## 与其他组件的耦合

- 电机后必须接减速器匹配扭矩/转速 → [[减速器]]
- 电机+驱动器+编码器+制动器=**关节模组**（人形/协作的核心 BOM）
- 编码器是里程计源头 → [[编码器与里程计]]
- 电流环数据可用于碰撞检测（协作机器人）→ [[功能安全体系]]
