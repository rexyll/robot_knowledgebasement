# 充电桩与自动充电

> AMR 续航的另一半答案：不换更大电池，而是"随停随充 + 自动化"。回充是 [[多机调度流程]] 与 [[多机协同与调度算法]] 的一等公民任务。

## 充电方式谱系

| 方式 | 功率 | 对接精度要求 | 优点 | 缺点 | 应用 |
|---|---|---|---|---|---|
| **接触式自动充电桩**（弹片/插头） | 1-6kW（48V/20-120A） | ±1-3cm | 效率 >95%、便宜、成熟 | 触点磨损/氧化（寿命 1-10 万次） | 主流（海康/极智嘉标准配置） |
| 顶升对插式 | 3-6kW | ±5mm | 位置固定可靠 | 需精确定位 | 海康充电桩 |
| **无线充电**（磁感应） | 0.2-12kW | ±5-10cm | 无触点磨损、可嵌入地面 | 效率 85-93%、贵、发热 | 恶劣环境、清洁机（洗地水汽） |
| 换电站/热插拔 | — | 站内定位 | 3 分钟满血、7×24 | 站成本高、需备用电池池 | 重负载/长班次（Walker S2 双电池热插拔、海康模块化换电站） |
| 人卫有线 | 3kW | 人工 | 最便宜 | 非自动 | 小规模过渡 |

## 自动回充全流程（→ [[导航流程]] 叠加）

```
1. 触发: SOC < 阈值(20-30%) 或 调度器前瞻(下一任务电量不够)
2. 预约: 调度器查桩位占用, 排队/改派 → [[调度系统RMS]]
3. 导航: goal = 充电桩对接位(地图预存) → 粗定位 ±5cm
4. 对接: 慢速 0.05-0.1m/s + 反光柱/二维码/激光桩体特征 → 微调 ±5mm
5. 握手: BMS↔桩 CAN 协议(电压/电流/温度/握手帧) → 闭合继电器
6. 充电: CC-CV 曲线, 桩端风扇/温度监控, 0.5-1C
7. 完成: SOC≥95% 或调度器叫醒 → 断电握手 → 驶离
8. 异常: 对接失败重试 N 次 → 上报故障 → 人工介入 → [[云端协同与OTA流程]]
```

## 桩侧核心参数（采购看这几条）

- 输出电压范围：40-58.5V（48V 平台）/ 84-96V（80V 平台）
- 最大电流：30-120A（功率 = 电压×电流）
- 充满时间：1.5-2.5h 全充（0.5C）；机会快充 10-15min 补 20-30%（2C 快充电池前提）
- 通信：CAN 2.0B / RS485 / MQTT 上云
- 防护：IP54 桩体、充电触点镀银/镀金
- 安全：过流/过温/反接/绝缘检测，灭火片（气凝胶）选配

## 无线充电要点

- 频段：85kHz（SAE J2954 车规标准）为主
- 对齐方式：低频 RFID 引导 + 一次线圈位置自适应
- 效率：85-93%（对齐好时），发热需散热设计
- 国产覆盖 60W-12kW、最大 200A，1 小时充满级；Figure 03 足底 2kW 磁感应自充电 → [[人形机器人]]

## 多机充电调度策略（→ [[多机协同与调度算法]]）

1. **阈值回充**：简单但容易扎堆
2. **机会充电**：空闲窗口就充，延长电池日历寿命
3. **前瞻规划**：调度器带电量模型（任务能耗表），把"电量不够的任务"提前派桩
4. **峰谷电价**：夜间谷电充满 + 白天快充补充（电费降 30-50%）
