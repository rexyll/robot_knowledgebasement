# 毫米波雷达与超声波

> 两条"廉价冗余"测距线：超声波管 20-600cm 近距，毫米波管 0.1-100m 中远距+测速。都不怕黑、不怕部分粉尘，是 LiDAR/相机的互补兜底。

## 超声波传感器

| 参数 | 典型值 | 说明 |
|---|---|---|
| 量程 | 20-600cm（盲区 2-25cm） | KS103/US-100/HY-SRF05 |
| 精度 | ±1-3cm | 温度影响声速（0.6m/s/℃），高精度需温补 |
| 波束角 | 15-60° | 大波束=分不清方向，小波束=贵 |
| 更新率 | 5-20Hz | 受声速物理限制 + 多机串扰需错频 |
| 接口 | GPIO 脉宽/UART/I2C | MCU 直连 |

机器人用途：
- 近距防撞补盲（LiDAR 近场盲区 0.05-0.3m）
- 防跌落（清洁机器人悬崖检测，朝下安装）
- 透明/黑色物体（玻璃、镜面）检测兜底——LiDAR 穿透玻璃、相机拍不到纯黑
- 典型布置：AMR 四角 4-8 只；参考 [[项目-清洁机器人]] 硬件目录

## 毫米波雷达（mmWave Radar）

| 频段 | 特点 | 用途 |
|---|---|---|
| 24GHz | 近距（<50m），便宜 | 盲区监测、液位 |
| 60GHz | 人存在感知（呼吸/心跳） | 服务机器人识人 |
| 77-79GHz | 远距（>200m），分辨率高 | 车载主频、机器人前沿方案 |

关键参数：探测距离（0.1-100m）、距离分辨率（4-15cm，77G 优）、速度精度（±0.05m/s，多普勒直接测速）、FOV（水平 60-120°）、点云稀疏（传统 2D 目标级）vs 成像雷达（4D 点云）。

机器人用途：
1. **测速真值**：AMR 满载打滑时轮计失效，雷达多普勒测真实地速 → [[多传感器融合定位]]
2. **雨雾粉尘冗余**：光学传感器失效场景的唯一活口 → [[特种机器人]]
3. **静止人体检测**（60GHz）：充电区/休息区安全监测 → [[功能安全体系]]
4. 4D 成像雷达（点云式）：低成本替代 3D LiDAR 的路线（Arbe、承泰）

## 与其他传感器的组合逻辑

```
玻璃门/镜面: LiDAR× ✗  相机×(反射)  超声波 ✓
强阳光:      LiDAR ✓   相机 ✗        毫米波 ✓
粉尘/雨雾:   LiDAR ✗   相机 ✗        毫米波 ✓ 超声波 ✓
低速精细:    LiDAR ✓   相机 ✓        超声波 ✓（1cm 级）
```
