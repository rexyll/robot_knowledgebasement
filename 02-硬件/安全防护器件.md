# 安全防护器件

> [[功能安全体系]] 的硬件执行层。原则：**软件避障会失效，最后一道防线必须独立于软件**（独立供电、独立断路路径、冗余通道）。

> 双重身份：安全扫描仪同时是 **[[安全防护器件]]（认证的）** 和 **导航数据源（未认证的）**——ROS 驱动里两者要分开处理，不可用未认证数据充当安全功能。

## 分区响应模型（速度-距离联动）

```
警告区(3-5m, 可配置):   降速 50%        → 软件层(规划减速)
保护区(1-3m):            停车 + 保持     → 安全层(扫描仪内部硬逻辑)
触边(<0.05m 或接触):     Cat.1 停止(断驱动+受控刹车) → 硬件回路
急停:                    Cat.0 停止(直接断动力)     → 硬件回路
```

- ISO 3691-4 的核心思想：速度越高，保护区越大（v=2m/s ≈ 保护区 ≥2.5m，依制动距离计算）
- 区域集（field sets）：一个扫描仪可存 32-128 套区域配置，随机器人速度/模式切换 → [[多机协同与调度算法]] 的区域限速联动

## 与导航系统的接口

- 触边/急停 → MCU 硬件层直接断驱动，同时上报 ROS（`/safety_status`）让导航状态机进入恢复
- 安全扫描仪保护区 → 驱动器使能信号（硬线）
- 软件代价地图只是"预防"，不是"安全功能" → [[局部规划与避障]] 与安全层的边界
