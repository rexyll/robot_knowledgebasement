# 电池与电源管理

> 机器人唯一能量来源。选型化学体系 → 成组 → BMS → 充放电策略 一条链（充电端 → [[充电桩与自动充电]]）。

## 化学体系选型（2025-2026 共识）

| 体系 | 能量密度 | 循环寿命 | 安全 | 成本 | 机器人用途 |
|---|---|---|---|---|---|
| **磷酸铁锂 LFP** | 130-180 Wh/kg | 2000-6000 次 | 好（热失控 270℃+） | 低（~0.4 元/Wh） | **AMR/AGV 首选**（海康/极智嘉全系）、清洁机 |
| 三元 NMC/NCA | 200-300 Wh/kg | 1000-2000 次 | 一般（200℃ 热失控） | 中 | 人形机器人、四足（重量敏感） |
| 磷酸锰铁锂 LMFP | 180-230 Wh/kg | 2000+ | 好 | 中 | LFP 升级路线 |
| 半固态/固态 | 350-500 Wh/kg | 试用中 | 更好 | 高 | 2026-2028 人形导入期 |
| 钛酸锂 LTO | 60-110 Wh/kg | 15000+ | 极好 | 高 | 快充/低温特种 |

> 机器人行业快照（2025-2026）：AMR 固定场景 LFP 统治；人形/足式用 NMC 换重量（Figure 03 用 2.3kWh 结构电池=电芯参与承力）；Walker S2 用双 LFP 热插拔换电（→ [[人形机器人]]）。

## AMR 电池组核心参数

| 参数 | 典型值 | 说明 |
|---|---|---|
| 电压平台 | 24V / 48V / 80V | 48V 为主流（≤60V 免高压安规）；叉车 80V |
| 容量 | 30-100Ah（1.4-5kWh） | 对应 6-10h 混合工况 |
| 放电倍率 | 1-3C 持续，5C 峰值 | AMR 加速尖峰 |
| 充电倍率 | 0.5-1C 常规；快充 2C | 1C=1h 充满 |
| 循环寿命 | LFP 2000 次@80%DOD | ~4-6 年日历寿命 |
| 工作温度 | 充电 0-45℃，放电 -20-60℃ | 冷库 AMR 需加热膜（-25℃ 冷链方案） |
| 防护 | IP54-IP67 | 洗地机要求高 |

## BMS（电池管理系统）职责

1. **三包**：电压/电流/温度采样（电芯级 ±5mV、±1℃）
2. **SOC 估算**：安时积分 + OCV 修正 + 卡尔曼滤波（算法同源 → [[卡尔曼滤波]]）
3. **SOH 估算**：容量衰减模型，上报云平台做预测性维护 → [[云平台与IoT通信]]
4. **保护**：过充/过放/过流/短路/过温，二级保护（MOS+继电器+保险）
5. **均衡**：被动均衡（电阻泄放，≤200mA）为主
6. **通信**：CAN（SMBus/UART 小系统）、上报帧含 SOC/SOH/故障字

## 续航计算模型（AMR 实用公式）

```
平均功耗 P_avg = 驱动均方功耗 + 算力外设功耗
驱动: P = m·g·f·v / η   (f 滚动摩擦系数 ~0.02, η ~0.75)
例: 400kg 整机, v=1.2m/s 工作比 60% → 驱动 ~75W; 算力+传感 ~50W
P_avg ≈ 125W → 48V/30Ah(1440Wh) → 理论 11.5h, 打 7 折工况 → 8h
```

充电配比：每 6-10 台 AMR 配 1 桩（机会充电 10-15min 补 20-30%）→ [[多机调度流程]] 里调度器要建模充电窗口。

## 电源架构（整机）

```
电池组 48V
 ├─ 48V → 底盘电机驱动器（峰值 30-60A）
 ├─ DCDC 48→24V → 安全器件/外设
 ├─ DCDC 48→19V → Jetson/工控机（110-220W 峰值）
 ├─ DCDC 48→12V/5V → LiDAR、相机、屏幕、4G
 └─ 充电输入口（CAN 与 BMS 握手协议）→ [[充电桩与自动充电]]
```

## 安全与合规

- UN38.3 运输认证、GB 38031（车规借鉴）、IEC 62619（工业电池）
- 低温充电锁死（0℃ 以下禁充，防锂枝晶）→ BMS 硬件保护
- 热失控报警上报（烟感/温度突变）→ [[功能安全体系]]
